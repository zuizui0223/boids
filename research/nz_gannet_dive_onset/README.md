# 海鳥が潜り始めた区間で、魚群は採餌深度から離れるか

## ニュージーランドの37魚群

Admiralty Bay・Current Basinのハラジロカマイルカの採餌時に撮影された魚群が対象。オーストラリアシロカツオドリの飛び込み回数は2分ごとに集計され、図1には、ある2分区間の飛び込みが5回以上だった魚群に鳥の写真が付いている。矢印は最初の飛び込みが起きた2分区間の左端。最初の接水時刻はその区間内で不明である。4 mを比較の目安にしたのは、同地域の鳥の観察で85潜水中71回が4 m未満だったため。水深は魚群中心であり、鳥が捕れる魚の割合とは異なる。[原図1・原図3](https://people.it.tamu.edu/~j-packard/publications/Vaughn_etal2009.pdf)・[鳥の潜水深記録](https://mro.massey.ac.nz/server/api/core/bitstreams/47f2dd0b-6365-4dda-b82b-40002de87962/content)

原図1の全37パネルを、上昇群A1–A10、概ね一定群C1–C18、下降群D1–D9とし、各区分内で上段左から順に付番した。7群に矢印があり、A6・A10・C4・D5・D8では観察開始と矢印が重なる。D6・D9には直前の記録があるが、D6では矢印直後の曲線が欠けている。前2分と開始区間2分を同じ魚群で比較できるのはD9だけだった。残る30群は最初の飛び込みの時刻が特定できない。これらを飛び込みゼロの群には分類していない。[原図読取の照合記録](depth_vaughn_source_audit.md)

滞在秒数は原図の測定点間の直線補間で推定した。最初の接水時刻や閾値を横切った秒は実測されておらず、潜水開始からの潜時は算出できない。鳥の潜水がなかった場合の同じ魚群の軌跡も観測されていない。図3の記載には2分以内に33回の飛び込みと8 m以深への下降があるが、魚群IDが付いておらず、図1と別の反復には数えない。[原著](https://doi.org/10.1111/j.1748-7692.2009.00317.x)

開始前が欠けた5群でも、最初の2分内の方向は分かる。A6は約10→8 m、A10は約8→2 m、D8は約10→7 mと浅くなり、D5は約8→12 mと深くなった。C4は約1 mに留まった。D8は著者の全観察での分類では下降型だが、鳥の潜水が始まった2分間には上昇している。全経過の下降型は多頻度飛び込み表示のある群で4/7、表示がない群で5/30。これはバウト全体における粗い関連であり、鳥が浅い群れを選んで集まること、イルカの行動、魚群サイズなども関係し得る。群全体についての因果効果や短縮時間を推定できる設計ではない。

補助的に、潜水開始表示のない30群から、魚群中心が先行2分の間ずっと2 m以内にあり、その次の2分も観察できた最初の時点を1群1回選んだ。この条件を満たす13群では、次の2分も図の曲線はすべて4 m以内にあり、4 m以内の滞在時間の差はすべて0秒だった。先行深度を1 m以内にすると10群、3 m以内にすると14群となり、どちらも結果は同じ。曲線で観察できる浅い状態が常にすぐ終わるわけではないことを示す記述的な比較である。13群のうち10群が著者分類の概ね一定群であり、D9の反実仮想を測れたわけではない。[魚群別の参照区間](bird_dive_nz_reference.csv)

## 海域間の照合

豪州One Tree Reefではベンガルアジサシの362回の飛び込みに魚群の急速な拡大が観察された。鳥は水深43–58 cmで底の直前まで達し、魚は主に水平面で逃避した。群れが反応しても下方に逃げる空間が限られる例である。NZと同じ深度指標で前後2分を再計算できるデータではない。[原著・水中観察](https://www.marineornithology.org/PDF/49_1/49_1_159-166.pdf)

南アフリカStony Pointの鳥による追跡10事例では、魚群の初認深度と追跡時刻はあるが、同じ魚群について鳥の追跡後の深度が得られたのは0件だった。連続水深はペンギン側の値である。[区間注釈照合](depth_stony_point.md)・[原著](https://doi.org/10.1098/rsos.190333)

## 上からの攻撃を加えたBoidsとの照合

Lettらの魚群モデルをもとにした部分再実装で、100尾・32個の共通乱数初期条件を使って、上から入水する鳥1羽と無攻撃を比較した。入力をNZの33潜水に合わせて学習したモデルではない。攻撃開始時の中心深度を1.6 mとした場合、開始後2秒間の中心深度の平均は攻撃あり2.82 m、無攻撃2.23 m。いずれも2秒間は中心が4 m以内にあった。開始後10秒で見ると4 m以内の累積時間は3.49秒対4.00秒（差−0.51秒）、5 m以内では5.20秒対5.62秒（差−0.42秒）。水面境界への反発で無攻撃時にも魚群が沈むため、同じ初期配置の対照との差を記載した。時間刻みを0.1秒から0.05秒に変えたとき4 mでの差は−0.49秒。攻撃時の中心深度が10 mの別条件では、10 m以内滞在への単発攻撃の効果は測定窓を2秒から10秒に延ばすと符号が変わる。したがって、浅い群れへの上からの攻撃で一時的に浅層時間が短くなるという方向はD9と整合し、普遍的な短縮や野外の69秒を予測することまでは示していない。[原モデル](https://doi.org/10.1007/s12080-014-0213-0)・[反復別出力](bird_dive_boids_runs.csv)・[再計算コード](bird_dive_boids.py)
