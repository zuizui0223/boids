### Question / primary estimand

**Does acoustic gaze predict future 3D flight heading BETTER THAN the bat's current position and prior movement would predict, when the test animal has never been seen in training?** This is stricter than authors' prior directional agreement and explicitly tests incremental sonar information beyond kinematic inertia. It is still INTRA-STUDY generalization, not an independent new species population.

### Frozen target, geometry, model and control (do not tune after opening original outcomes)

1. Original source real flights. For each call at `t`, use **past-only** 3D track geometry sampled by linear interpolation at times `t, t−0.05s, t−0.20s, t−0.25s` to calculate heading(t) via atan2 of most-recent 0.05s planar motion, previous heading via `t−0.20s` minus `t−0.25s`, recent wrapped change, speed and source x,y,z. If any interval is outside the *same trial*, drop that candidate call; never extrapolate.
2. **Primary lead**: future heading at `t+0.20s` using the short prior window `t+0.15s` to `t+0.20s` (DO NOT use future track in predictors); target `Δθ=wrap_to_pi(heading_future−heading_now)`. Two fixed secondary leads: +0.10s (future difference window t+0.05 to .10s) and +0.30s (future window t+.25 to .30s). No inference of true prey capture or head orientation angle without a verified sensor beam.
3. Only include calls with matching original trial track, finite original HDF5 numeric arrays, original pulse times strictly increasing, source beam `fitR>=0.30`, and nonzero planar movement over both heading-derivative intervals. No arbitrary speed/curvature/outcome-based filters. Original trial or bat sources missing any required field => mark missing source trial and report, with an **eligibility STOP** if fewer than six biological bats (of eight) each contribute ≥2 original trials and ≥20 eligible calls at all three horizons. This source availability criterion was set without seeing outcomes.
4. Three fixed **forward** predictors for each test bat's future wrapped heading change:
   - **G0:** no change (Δθ=0).
   - **G1 geometry:** weighted ridge regression (unpenalized intercept, α=0.01 after training-fold feature standardization) on **seven past/current motion features**: source x,y,z, sin(current heading), cos(current heading), wrapped previous 0.20s heading change, current 0.05s displacement speed. No future target data or original annotated turns in predictors.
   - **G2 geometry+sonar:** identical G1 features plus signed original `beam.rel_deg` in radians at the call. No source future gaze or turn angle labels used as predictors.
   - **G2_shift control:** identical G2 but source sonar cue replaced by deterministic **half-trial circular rotation of the valid call sonar sequence** (floor(N/2), same policy for source train/test). Preserves bat/trial marginal source acoustic cue distribution but destroys exact call-to-flight time alignment; it is a temporal-alignment diagnostic only, NOT randomized animal control.
5. Training and predictions: leave **one entire biological bat** and all its trials out; train exclusively on other bats. Standardize each feature using training data ONLY (sd=0 features set to 0 after centering); original trial rows weighted equally within each bat×trial, original trials equally within bat, each TRAIN bat equally in ridge. Each bat has one heldout fold; no within-bat training. Use the exact same accepted call/time rows for all four models to prevent source availability leakage. No hyperparameter fitting, feature addition, model selection, or condition filtering after looking at the result.
6. Scores: angular absolute error `|wrap_to_pi(Δθ_observed−Δθ_predicted)|` in degrees. Average errors within source trial, then equally across trials within bat, then equally across biological test bats. **Primary** contrast G2−G1 for **+0.20s**, negative=incremental acoustic gaze utility; secondary G2−G1 at +0.10/+0.30s and G2−G2_shift. Report bat-level wins, n actual bat folds, n source trials and calls, original quality exclusions, bootstrap 5000 entire-bat resamples seed **20261115** for purely descriptive mean contrast CI. No call-level p-values, no number of source trials treated as 30 independent animals.
7. **Negative or ineligible output remains published**, no retrospective rescue. Even if G2 improves source-heldout error, source author original paper already established prospective acoustic gaze; the new evidence is only incremental heldout prediction versus a kinematic model in the same original Carollia dataset, not evolutionary novelty or independent cross-species/ecological adaptation.
8. Neither echo masking nor other bat acoustic interference was experimentally manipulated in this corridor dataset; **do not call this proof of conspecific jamming avoidance**, high-density capture benefits, long-term memory or wild 3D niche partitioning. The 2025 JHU five-bat moving-target archival API was verified to return HTTP403 in the current execution environment; no numerical outcomes from it were accessed.
