# Original-bat independent source admission gate (after IF double holdout)

**2026-11-05 · Source discovery & structural preflight only.** No new bat measurements, acoustic-call readings or paper submission are authorized.

The internal Hase 2026 `Miniopterus fuliginosus` IF-response double holdout failed to transfer a reproducible stimulus-only linear rule across other bats/levels (18/24 tested source-window×method×experiment group summaries worse than a constant-training-mean baseline; not independent n=24). Rather than retune more source models, seek an **independent bat species and study** with already-published acoustic interference and potentially target-approach/foraging behavior.

FIRST CANDIDATE: **Amichai, Blumrosen & Yovel 2015**, `Pipistrellus kuhlii`, *Proceedings of the Royal Society B* DOI `10.1098/rspb.2015.2064` (Calling louder and longer: how bats use biosonar under severe acoustic interference from other bats); original Dryad DOI **10.5061/dryad.8f0v4**. The provider page lists original source `Dryad.xlsx` approximately **1.81 MB**, observational acoustic parameters of emitted calls from playback experiments with search and target approach. Published authors already report increases in emitted sound intensity/duration/call frequency and slight spectral shifts not reducing overlap; those are PRIOR ART, not a new discovery.

**Pre-outcome source-only gates:**
1. Resolve official Dryad dataset DOI metadata, version, file listing, license, file ID, file size, provider checksums. Cite official original source.
2. Make only a bounded HEAD and 4,096-byte HTTP Range request to the publisher's original file link. If HTTP401, another source access STOP or no valid signed download, record STOP; do not bypass access control or rehost original source.
3. If and only if provider grants raw file access, a later independently frozen step may inspect XLSX sheets and header names to verify original biological individual ID, interference treatments, call duration/intensity/frequency, target-approach/actual catch outcomes, and independence from Hase 2026. Original source original IDs/individual calls stay outside GitHub; analyze with author-appropriate caveats and strict biological study units.
4. This is an **independent source-feasibility gate**, not evidence that `Pipistrellus` has an acoustic strategy generalizable to `Miniopterus`. The 2015 source's acoustic patterns are already published, and there may be no target/prey-capture outcome to link the physics models.

Decide source admission based on source structure, not whether the result is positive. Do not merge unrelated published acoustic effects into a fictitious multi-bat causal validation. Maintain PR #36 as Draft and freeze its prior source-provenance ledgers.
