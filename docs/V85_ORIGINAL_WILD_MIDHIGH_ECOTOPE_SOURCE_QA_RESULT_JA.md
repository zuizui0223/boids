## 4. 主要な科学的意義と次の具体的な解析

- **過去の肯定結果は保持**：v63真の元GPS潮相次方向T正、v70二島×二年で実測潮位×日照の低潮位時間差（ほぼ同じ日長で398/660が≥1h違い）、v75 Schierの元モデル潮汐曝露指数の空間利用高順位、v76/v77の同じ鳥×月×潮位での潮相×昼夜4条件関連、v82元6〜12月Schier D+0.049979元18鳥bootstrap95[0.022379,0.083132]とAmelandD+0.005274元10鳥bootstrap95[−0.034101,+0.054690]。**元の二島の独立鳥D差は +0.044705 95%[−0.013253,+0.096582]で不確定**。これらはモデルの全格子内順位という旧定義に限定しており、v85で新しい生息地のみの順位を確認したことにはならない。
- **本当に直接観測した新しい生息地情報**：WMR地図で定義された中位・高位潮間帯のGPS位置がSchier20,507、Ameland10,146あった。しかし、これだけでは元の潮位・明暗ごとの十分な元個体条件が揃わない。**本物の生態学的な機構検証には、潮間帯に入る/出るという二値の利用状態を全GPS位置で扱う**と、干潟外の休息や移動地点を捨てず、同じ実測潮位×太陽高度の条件下で潮間帯利用**確率**の差の差を比較できる可能性がある。ただしこれは元のモデル順位Dとは**異なる新しい後続の探索的応答**なので、v86として別の固定仕様を作り、源GPSの潮位×明暗条件を**先に**全原本で確保する必要がある。
- **新しい潮間帯利用の二値応答**は季節的な標識・観測機会、ポルダー（Ameland）vs塩性湿地（Schier）、実際の採餌/休息、局所の低潮位遅れ、GPS機器の時刻精度、地図の分類不確かさや航路などの観測外の機構に影響され得る。真の因果/普遍性までは主張しない。元Mendeleyの訂正済みv2版未認証という出典問題を明記しておく。
