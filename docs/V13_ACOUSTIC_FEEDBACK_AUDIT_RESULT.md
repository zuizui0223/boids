# v13 — Acoustic Boids の持続性・機構・先行研究監査

**2026-11-21 JST / SYNTHETIC_ONLY_NOT_FIELD_RESULT**

## 結論

平均場モデルでは、仮定した方程式の下で二つの安定固定点とヒステリシスを確認した。一方、個体ベースの Boids で「短い再生刺激が、一般的に長期の高発声状態を作る」とはまだ言えない。早い刺激の平均差は長い観察窓でほぼ消え、遅い刺激の平均差はほぼ 2/24 シードに集中した。実測魚群の双方向フィードバックを示す新しいデータは追加されていない。

また、刺激終了後の魚の発声増加は既に報告されている。「刺激後にも発声が続く」だけを新規性や集団フィードバックの証拠にしない。検証対象を、同じ現在条件で履歴に依存する集団状態と、その状態を維持する具体的な相互作用に絞る。

| 機構 | 音響操舵の係数 | 受音→発声の係数 |

| 両方あり | 5 | 3 |

| 受音→発声なし | 5 | 0 |
| 両方なし | 0 | 0 |

各機構に刺激なしと遅い刺激を用意し、両方ありの機構には早い刺激も用意した。同じ無刺激軌跡を、早い刺激と遅い刺激の比較で共有した。

## 2. 長い観察窓では何が残ったか

差はすべて「刺激あり − 刺激なし」。発声率は0–1の個体割合であり、鳴き声の個数ではない。面積は任意の距離単位の二乗である。

| 条件 | 終盤の発声率差 | シード・ブートストラップ95%区間 | 終盤の面積差 | 95%区間 |
|---|---:|---:|---:|---:|
| 両方あり・早い刺激 | −0.002398 | [−0.100026, +0.077802] | +1.056972 | [−4.849690, +9.076086] |
| 両方あり・遅い刺激 | +0.058645 | [−0.000009, +0.155004] | −3.274096 | [−8.811393, +0.019123] |
| 音響操舵なし・遅い刺激 | 0 | [0, 0] | 0 | [0, 0] |
| 受音→発声なし・遅い刺激 | 0 | [0, 0] | +0.076384 | [−0.215272, +0.342452] |
| 両方なし・遅い刺激 | 0 | [0, 0] | 0 | [0, 0] |

同じ新規24シードに限ると、早い刺激の発声率差は終了直後の +0.043555 から終盤の −0.002398 へ変化した。面積差も −21.534811 から +1.056972 へ変化した。この条件で、短期の増加・集合を長期の刺激依存状態へそのまま読み替えることはできない。

遅い刺激では、終盤の平均発声率は無刺激0.939652、刺激あり0.998297だった。しかしシード1010の差 +0.905313 と1014の差 +0.502188 が平均差のほぼ全てを説明する。残る22シードの最大の正の差は +0.000125 にすぎない。中央値は0で、正8、負5、完全一致11シードだった。平均と区間を示すと同時に、この偏りを残す必要がある。

無刺激でも、群れは時間とともに高い発声率・小さい面積へ移っていた。したがって、刺激群だけを見て「高発声が続く」と結論するのは不適切である。ただし、この有限時間の実験だけから、全ての条件で差が消える、微視的双安定性が存在しない、定常分布が一意である、と結論することもできない。

## 3. 対照実験で分かった機構の範囲

音響操舵を0にすると、刺激が運動方程式へ伝わる経路がなくなり、対応する二条件の面積履歴は厳密に同じになる。受音→発声係数を0にすると、刺激終了後の発声確率は履歴に依存しなくなり、共通乱数の下では発声履歴が直ちに一致する。後者でも運動の履歴差は残り得るため、面積まで直ちに一致するわけではない。これらをコードと全24シードの出力で確認した。

**「音響操舵が高発声の必要条件」とは言えない。** 音響操舵なしでも終盤の発声率は0.793061だった。この条件で消えたのは刺激あり・なしの差であり、高い発声活動そのものではない。

事前指定した交互作用は、各シードの刺激効果について

\[
\Delta_{\mathrm{full}}-\Delta_{\mathrm{no\ motor}}
-\Delta_{\mathrm{no\ hearing}}+\Delta_{\mathrm{neither}}
\]

で計算した。終盤の発声率交互作用は +0.058645、区間[−0.000009,+0.155004]。面積交互作用は −3.350480、区間[−8.719984,−0.058620]だった。後者の区間は0をわずかに外れるが、副評価・未調整のシミュレーション比較であり、主評価を肯定結果へ置き換える理由にはしない。実際の魚の因果媒介効果ではない。

これらの区間は、指定した人工モデルでシードを変えたときの変動を表す。生物学的母集団の信頼区間、効果ゼロの同等性検定、野外の効果量ではない。

## 4. 平均場モデルで厳密に言えること

元の二状態モデルは

\[
g_{t+1}=\alpha g_t+(1-\alpha)(kp_t+\chi B),\qquad
p_{t+1}=\sigma(\theta+\beta g_t+\eta p_t+\phi B)
\]

である。一定の入力 \(B\) に対して

\[
L=\beta k+\eta,\quad h=\theta+(\beta\chi+\phi)B,
\qquad p_*=\sigma(h+Lp_*).
\]

\(L>4\) とおき、\(\delta=\sqrt{1-4/L}\)、

\[
A=\frac{L\delta}{2}-2\operatorname{atanh}\delta,\qquad
h_-=-L/2-A,\quad h_+=-L/2+A
\]

とすると、三つの異なる固定点が存在する必要十分条件は

\[
h_-<h<h_+.
\]

したがって、\(L>4\)だけでは十分ではなく、基礎発声傾向と外部入力も重要になる。\(L=6,B=0\)では

\[
-3.41509291<\theta<-2.58490709
\]

が三固定点の範囲になる。

\(\theta=-3,\alpha=0.65,k=1,\beta=4,\eta=2\)では、固定点は約0.070720、0.500000、0.929280。外側二点の主要固有値は約0.789759、中央は約1.171343で、二つの安定点と不安定点が存在する。

完全な二状態写像のヤコビ行列は、\(s=p_*(1-p_*)\)として

\[
J=\begin{pmatrix}\alpha&(1-\alpha)k\\\beta s&\eta s\end{pmatrix}.
\]

\(0\leq\alpha<1,\beta,k,\eta\geq0\)の範囲で、線形化の固有値がすべて単位円内にある条件は \(Ls<1\)。これは局所指数安定性を保証する。等号の場合は非線形解析が必要であり、単に「不安定」とはしない。

さらに、\(\theta\)を−4.5から−1.5へ、また逆方向へ変化させ、各点で完全な二状態写像を収束させた。402/402点で固定点残差 \(10^{-11}\) 以下を満たし、上昇時の跳躍は−2.595→−2.580、下降時は−3.405→−3.420で起きた。解析的な二つの境界をそれぞれ挟む。この往復で、仮定した平均場方程式のヒステリシスを確認した。

これは基礎発声傾向 \(\theta\) の掃引である。再生音量 \(B\) の掃引とは異なる。静的な \(B\) の折り返し点は約±0.296495だが、負の再生強度は物理的な刺激として解釈しない。また、静的な境界を有限時間パルスの最小必要振幅とも解釈しない。

根の探索も、符号変化だけを探す格子法から、単調区間を用いて接する根も扱う方法へ改めた。v12コードは保存し、v13内の別モジュールで実装した。詳しい導出と境界条件は [数理監査](V13_MEANFIELD_DERIVATION.md) を参照。

## 5. 先行研究に基づく修正

| 原著 | 今回の解釈への影響 |
|---|---|
| van Oosterom et al. 2016 [1] | 同種声の再生による集合・発声増加は既知。面積指標は水槽面積に占める割合なので、本文の4.3%は図3から約4.3パーセントポイント減と解釈する。229回/群れ/10分の増加は著者報告値。 |
| Remage-Healey & Bass 2005 [2] | 5分の刺激終了後にも、5分の観察区間で発声増加を報告している。発声中の縄張り雄に対する促進であり、移動する魚群の集団双安定性を同定したものではない。 |
| Jordão et al. 2012 [3] | 再生への反応が開始時の発声活動に依存することも既知。初期活動による応答差だけをヒステリシスの証明としない。 |

2016年の実験は24尾の4群を使い、10分ON・10分OFFを7回反復していた。OFFの観測は存在するが、回復の時系列や同じ現在条件で異なる履歴を比較する解析は確認できなかった。今回の限定的な確認では、その生データを再解析できる公開アーカイブは見つからなかった。「データがどこにも存在しない」という意味ではない。[1]

この範囲の文献検索は、音響操舵・発声・集団状態の維持を同時に同定した証拠を与えなかった。網羅的な新規性証明ではなく、「初めての魚の音響フィードバック」「初めての刺激後発声増加」とは主張しない。

## 6. 実証で区別すべき予測

残る仮説は、移動する群れで、発声が配置を変え、その配置が受音と発声を変える循環が、外部刺激終了後の状態維持に寄与するか、である。少なくとも以下を区別する必要がある。

1. **個体の遅い回復。** 個体内部の記憶・興奮が減衰するだけでも、一定時間の発声増加は残る。集団フィードバックを含まない記憶モデルを対照にする。
2. **直接的な発声促進。** 音を聞いて鳴くだけでも高活動になる。配置を介した経路が追加で必要なのかを比べる。
3. **配置と受音の循環。** 現在の外部条件を揃え、異なる刺激履歴・初期配置で状態が分かれ、想定した経路を弱めるとその差が短くなるかを調べる。

音響マスキングは、それ自体で集合行動を変える可能性があるため、フィードバックだけを切る純粋な操作とは扱わない。同じ群れの個体軌跡・発声帰属・刺激時刻を対応づけ、独立した群れを単位として検証する必要がある。v11の編集済み合成動画だけではこの要件を満たさない。
