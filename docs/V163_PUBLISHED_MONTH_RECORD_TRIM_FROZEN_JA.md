# v163（結果前の凍結案）：Paper Table A1の月内レコードだけ保持した場合、自己音響持続の結果はどう変わるか

2026年11月16日。ネズミイルカv160〜v162の結果を既に見た**探索的なSOURCE感度分析**。元論文Table A1の開始・終了年/月を本誌オンライン表と再照合し、元Data S2真正126,231行のうち**20,315行（16.09%）が掲載年月外**であると確認済み。紙面の記載がすべてのデプロイを網羅していない可能性があるので、これを「誤った録音」とは決めつけない。

## なぜv162の追加検定か

v162は年月外の行を1件でも持つ**6 SITEを丸ごと削除**する最も保守的な感度。結果はICEで地点保留12/13正、年保留2/2正、SWEは地点保留3/3正だが、年保留1/4正、平均+0.00000053 nats/click陽性時間まで低下した。

しかしHONOは公開された2022-10〜2023-09期間の中にも実元CSVレコードを持ち（元23,374行のうち4,745行は掲載年月内）、他の不一致SITEにも公表期間内の記録がある。**不一致SITE全部を除くか、論文掲載の年月内の実際のレコードだけを使用するか**によって頑健性の結論が変わる可能性がある。今回は新しいSITEを追加して結果を良くするためではなく、SOURCE定義の両極を固定した比較である。

## 新しいSOURCEルール（モデル成績を開く前に固定）

- 元の真正Data S2をEurope PMC公式で再取得し、元CSVメンバーSHA256 \`972b43b0313cb29aa485733b2892fba1f42aea5543da08ab87f8389bb3b7addf\`、元43 SITE×6 GROUPを完全チェック。
- 論文Table A1の本物の元年月から、**行のsource \`year\`, \`YDAY\`, \`hr\`が掲載開始〜終了の暦年月に含まれる場合だけその元行を保持**。機器の実際の設置・撤収「日」は不明なので、同じ開始/終了月のすべての日を含める。元のクリック陽性観測があっても月外ならモデルから除外するが、原元CSVや先行推定値を変更しない。
- 元合計 **126,231 − 20,315 = 105,916行**をサンプルにする。全43 SOURCE SITEは掲載期間内のクリック陽性行があるため残る。ただし新サンプルに入れる実データ行数とSOURCE陰陽はすべて記録し、予測効果の後選択には使わない。
- **先に行を取り除いてから**、SITEごとに\`t-1h\`・\`t-24h\`が本当に元CSVにあるかチェック。もしクリップした元時間を挟むなら自己状態・24h状態を未知として扱う。外部のC-POD未記載時間を補完して陰性にしない。
- v160（同じGROUPの他SITEだけ学習し、SITE全期間を保留）、v161（同じSITEで厳密に過去の元暦年のみ学習し、後の原暦年丸ごと保留）の**全固定モデル、陽性/陰性の元入場閾値、log-lossスコア、L2 C=.25**をそのまま使用。SOURCE停止も全43 SITE×全暦年、前日対照も全候補を保存する。
- 本v163はv162のstrict SITE exclusionとの対比により、**測定メタデータ品質が結果をどれほど変えるか**を定量化する目的。後から不都合なSITEを除外・再び戻すなどのSOURCE選別は行わない。

## 解釈に必要な注意

掲載期間内に残った行でも原CSVのSITEが真の同じC-PODと一致する保証はない。特に元のHONO 2015–2018などと論文の2022–23だけのラベルをどの程度同一SITEと認めるかは別途著者確認が必要。元の出典と論文の地理を直接照合できる機器台帳はまだない。

結果が前段の「地点保留で自己状態は予測的」「年保留では効果不安定」の主張をどう変えるか**双方を必ず報告**し、2つの定義のどちらかを有利な方に選んで主効果に格上げしない。元のCLICK陽性だけに条件づけているため、ネズミイルカの存在・不在や生物学的な個体記憶、潮汐×太陽の物理因果は推定しない。
