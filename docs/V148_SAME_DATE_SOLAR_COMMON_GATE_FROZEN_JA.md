# v148：同日・同日×太陽昼夜の条件付き期待を、v145の同じ136,032録音時間に適用する

2026-11-15。**v145とv147の地点/年別成果を既に見た後の探索的検証**。事後に注目した音型組は数値を読む説明例に限り、検定群は原本の**全9地点×全10音型ペア（90）**を事前に入れる。

## 科学的問い

v145では「年・月・時刻を維持しながら、録音の完全24時間プロファイルを日単位で循環移動する」と、Bocaccio×UF440にO/E>1が6/6地点で残った。

しかしこの方法では、**特定の日の環境**（水温・湧昇・騒音・月や潮汐）の共有変動を破壊する。二音型が同じ日によく記録されることだけが原因なら、年別の残差持続性と当日1時間単位での同時発声は区別されない。

そこで源データを全く同じにして、共起時間Oを以下と対比する：

- **E_shift**：v145の同一年月連続7日以上の完全日を整数日循環させる厳しい帰無の厳密な平均。相手音型Bの日内24時間のプロファイル、ほぼ全ての日跨ぎ継続時間を維持し、特定の日の共有環境は維持しない。
- **E_date**：同じローカル暦日の録音時間数、A/B各陽性時間数をそのまま保持した条件付き独立期待値（24時間中の重なりを固定周辺頻度で計算）。
- **E_date×solar**：その日の**同じ天文学的昼夜区分**まで保持した条件付き独立期待値。太陽高度<-0.833°をnight、それ以外（薄明を含む）をdayとし、各日の各区分の陽性頻度で独立期待値を算出。
- **E_yearmonth×hour**：v144の考え方に沿って、v145と**同じ13万6000時間**の「現地年×月×時計時刻」で条件づけた追加の共起期待値を再計算。

全て同じ録音時間の観測Oが必ず一致しなければ不採択。年別のOと期待値も全期間の90ペアの値へ加法的に戻らなければSTOP。

**注意：帰無モデルは同じ識別対象を推定していない。E_date/E_date×solarは音型Bの連続発声時間を維持せず、時刻選好や未観測日内環境を残す。E_shiftとの差を「何%が日環境による」と因果寄与率へ変換できない。p値は生成しない。**

## 解釈の判定

- E_shiftでは正、E_date×solarではO/E≈1：元の残差は「共通日環境・観測状態による同日活性化」と両立。社会相互作用の根拠をさらに弱める。
- E_shiftもE_date×solarも明瞭に正：年月・日中夜間の条件付きでも同時刻の余剰を記述的に確認。ただし昼夜内の細かい時刻選好、継続性、潮汐、海水温、録音可聴性は残る。
- 符号が不安定、またはnullの違いで逆転：単一の方向を生態学的普遍則にしない。
