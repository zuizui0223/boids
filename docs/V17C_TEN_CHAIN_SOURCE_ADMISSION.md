**Registered 2026-10-28 JST, before any target GPS trajectories, movement predictions or forecast outcomes from this source are opened.**

## Motivation and independent source

The earlier Taylor et al. 2019 source revealed only **five** experiment-wide four-bird connected social units in the original PLOS S3 assignments. The confirmed >=8 network threshold **failed**. Do not retune those already examined data or reclassify its phase-2/3 dyads as independent across both phases.

**New candidate:** Valentini et al. (2021), *Naïve individuals promote collective exploration in homing pigeons*, *eLife* 10:e68653, [DOI 10.7554/eLife.68653](https://doi.org/10.7554/eLife.68653). The publication describes **ten independent pair-based transmission chains**, each with five generations and up to twelve flights per generation (5Hz pigeon GPS), and 343 retained paired flights, plus solo/fixed-pair controls. These are **published study-design statements**, not yet confirmed in the source archive.

Published data/code resource: [Figshare record 14043362](https://doi.org/10.6084/m9.figshare.14043362), linked in eLife data availability. The underlying original flight data may also originate from Sasaki & Biro (2017), so deduplicate any source-overlap with archived other pigeon data before describing it as a fully independent *bird* population. It is a **different candidate resource** from Zenodo 5026107 / 2019 Taylor, Zenodo 4943714 / 2016 Watts and Zenodo 21092705 / 2026 Huang.

## Stage C1 source-only eligibility

1. Request official `https://api.figshare.com/v2/articles/14043362` and require exact article ID, source DOI, stable title, publication metadata and license. Save all original file names, provider MD5, sizes and source URLs. Never invent checksums or change IDs after inspecting outcomes.
2. Download only named archival files directly from provider-listed download URL when ≤200MB each and cumulative total ≤350MB. Verify published byte length and MD5, compute new SHA256. Preserve all raw bytes temporarily on CI; **no original animal tracks are published in GitHub**. If source is unavailable or offers non-archived external links, report STOP rather than fabricated source access.
3. Inspect ZIP/CSV **file names and column headers only**, not GPS coordinate values, directions, movement targets or published outcome labels. Count and parse *a priori* chain/generation/release structures using stable identifiers; avoid inferring a social chain from the observed movement trajectories.
4. **Minimum for further source admission:** at least **8 independent externally labeled transmission chains**, each with ≥3 recorded generations, distinct release sessions, stable within-chain unique animal or partner IDs across generations; original source time and lat/lon/route columns must be documented before fast/slow analysis.
5. Wind gating remains **not admitted** until the new data show independently dated weather or a valid external meteorological source with known UTC alignment. A social-route experiment with 10 chains alone cannot prove any wind×neighbor or solar-visibility effect.
6. If files are already processed into symbolic turns without original timestamps, restrict outcomes to a preregistered route-history endpoint and do NOT claim raw-GPS present-versus-stale force predictability.
7. Group training/test must leave **whole transmission chains** disconnected. Do not put generations from the same chain into training and test when estimating independent transfer; within-chain historical releases can be used only as prospective context with no future leakage.
