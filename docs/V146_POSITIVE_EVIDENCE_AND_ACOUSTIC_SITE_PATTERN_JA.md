## 3. 次の主要仮説：共通時間ゲートと相互作用の切り分け

**H0（共有環境ゲート）**：季節・潮汐・水温・夜間照度・波や騒音が複数音型の検出/発声機会を同時に変え、相互作用がなくても同時出現と位相ずれを生む。

**H1（ゲートを超える残差）**：同じ年・月・局所時刻・潮汐・太陽・月・水温・湧昇流・録音努力・可聴性を制御しても、別音型の観測は対象音型の外部日付/海域ホールドアウト予測を改善する。ただし改善しても共有未観測環境・観測バイアスが残りうるため、魚同士の直接行動相互作用とは断定しない。

**H2（本来のBoids機構）**：個体GPS/3D軌跡が同時に記録され、局所環境と自分の慣性を保持したときだけ、実パートナーの進行方向・距離による追加予測を検証する。魚の音響ログからBoids力を当てはめない。

## 4. 元データ検定の入場条件（次の環境結合解析用）

1. まず採用音型ペア・観測対象海域・時間窓・QC・4帰無（時計、季節/個体、物理環境、別音型）を**新しいアウトカムを開く前**に凍結する。v146の二組は既知結果なので次回は独立年または別海域で評価。
2. 水位高さ、上げ下げ位相、大潮小潮係数、局所太陽高度、月面照明率、夜間実測照度を**別変数**として格納する。Roscoffの月面照明率は月光ルクスではなく、NOAA沿岸観測所の水位は沖合音響地点の実潮位と同一ではない。
3. 録音努力を明示し、Off effort・Noise・可聴性の不明を未検出=不在へ置換しない。期間丸ごと保持のholdoutと日付/配備/サイトの依存性処理を必須にする。
4. 予測増分を同じ応答定義・同じ物理曝露・同じ独立海岸単位で抽出できる場合だけメタ解析へ入れる。v134の118文献/311数値、v135の6沿岸系は**まだ統合可能な3独立効果量ではない**。全球の平均交互作用は引き続き **NOT_ESTIMATED**。
