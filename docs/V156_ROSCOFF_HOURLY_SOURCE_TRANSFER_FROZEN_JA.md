# v156：独立Roscoff沿岸への自己状態・音型間情報モデルの転移入場監査（結果前設計）

**原本と前提**：Ethève et al. 2026（DOI 10.1186/s12862-026-02521-z）原XLSX 299,726 bytes、v139公開元source SHA256 \`2df8fac5749d804b8d16d98db065ba19dc3796a4a01ce1cfa87c56f5d622d0d0\`。フランスRoscoff海藻藻場の**1音響観測地点**、元の著者が選んだ20の正午から翌正午の24時間期間。480予定時間のうち421時間のみアノテーション、**59時間は潮流雑音に関連して除外**。26音型・6,172件の注釈があるが、音型は個体・種と1対1ではない。

**最大の注意**：前分析v139では、高水位側240時間のうち58時間がフロー雑音でマスクされる一方、低水位側は1時間のみ。マスクをBocaccio/音型無しの0と補完することは禁ずる。Noon-to-noon期間は暦日や独立海岸ではなく、20回の選定日を5組に分けて保留する。

## 今回の明示的入場条件（新しいRoscoffモデル結果はまだ開かない）

1. v139の元XLSXを再取得し、厳密SHA検証。Table S1の26音型（P–AO列）と全421音響時間のAP総音数/AQ音型richnessの元値が一致。元20期間の期間ID×0–23時位置を構成して、同じ期間で直前の**実測1時間**が本当に存在する場合だけ自己状態を定義。マスク欠測を発声陰性に置換しない。
2. 5foldはv139のまま**1foldに潮汐係数区分Low/Medium/High/Very Highの4つの元24h期間を必ず含む**。ソース分割だけ固定し、新しいロススコア・音型間の追加予測をまだ評価しない。
3. 全26元音型を列挙。各foldで保留側に陽性≥3、陰性≥3、学習側に陽性≥20、陰性≥20、さらに6つ以上の元選定24h期間で陽性なら、その音型を翌段の探索モデル候補へ入場。**この選別はラベルの観測可能性によるもので、音型間の関連や予測改善で候補を選ぶのではない**。ただし標本中の陽性頻度を使うので完全にアウトカム非依存ではなく、そのため確認的な新規外部実証ではない。
4. 入場した音型を元の陽性時間数の降順、同数なら元の音型名順で並べ、最多を次段のA、次点をBの基本比較とする。入場が2未満なら、**Roscoff単独では同じ2音型モデルの検証不可**として停止。結果を見て人数基準を緩めない。
5. 源の音型数、採用できた自分の直前1h録音数、各fold音型の陽性/陰性とマスクを全件レシートに保存。モデルを推定していないソースQAを「生物学的な有意結果」と呼ばない。

## 次の分析の転移の限界

成立すれば、**同じ階層的問い**をRoscoffの音型陽性で評価する：M0自然条件（元実測水位/夜/潮汐係数）、M1＋自分の前の音型陽性、M2＋別音型の同時陽性、および同じ時計時刻を保持する別の24h観測期間からの音型Bなど。ただしRoscoffは20選定日×1サイトの5foldであり、カリフォルニアの数年ホールドアウトに比べて短く、同一単位の独立した2沿岸メタ解析効果量ではない。
