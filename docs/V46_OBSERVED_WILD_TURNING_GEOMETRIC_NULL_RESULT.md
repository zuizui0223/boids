# v46 — 幾何学的平均回帰を補正すると、野外ミヤコドリの見かけの方向乖離は消え、相対的な正の旋回超過が残る

**2026-10-31 JST。実際の野外GPS × 公式潮汐の探索的・事後数理帰無検証。** これは[元のv45で観測した負の近隣相対収束](../docs/V45_OBSERVED_FOCAL_TURN_CONVERGENCE_RESULT.md)を見たあとに設計した**幾何学的な条件付き帰無**であり、未開封動物・独立調査地・社会的介入実験ではない。[v46検証条件](V46_GEOMETRIC_INERTIAL_TURNING_NULL_PROTOCOL.md)を新しい幾何学補正後の動物効果を計算する前に凍結し、結果に合わせた方向・旋回角閾値や鳥の再選択は行わなかった。

## 1. 全旧結果・元ソースの厳格な再現

7年分の野外原GPS（Zenodo 10053970 v4、元の公開MD5と事前SHA固定）、オランダRijkswaterstaat公式 `schiermonnikoog.waddenzee` の2008～2014年全天文潮WATHTE（10分刻み、NAP基準cm）を再取得し、元v41/v42の時間・空間同時存在、v33-D、v39、v40、v43、v44の全部の元数値、さらに**v45の全個体・月・年および100回の旧時刻シャッフル結果まで許容差1e−12以内で再現した**。

原v44の近鳥≤200mと遠鳥≥1kmの方向がともに過去5分以内にある18鳥・68,232未来元GPS区間を出発点に、元v45の固定適格条件（焦点鳥の独立した過去GPS移動、未来GPS移動がどちらも≥50m、近鳥・遠鳥の単位平均ベクトルの合成強度≥0.25）をそのまま使用。方向定義できた候補4,667件から、各鳥≥10区間の規則を通過した**17鳥・4,660未来区間、11暦月、2010～2011年**を**全モデルと完全同じサンプル**とした。

**この方向差は連続した飛行のコーナーを観測したものではない。** 過去と未来の2つの別GPS移動対は測位点を共有せず、その間には5～360分の観測ギャップがある。したがって「旋回」とは、二つの別々のGPS移動区間の方位角の差であり、単一時点の旋回加速度ではない。

## 2. v45の負の結果は、初期方向の一致が生む数理効果で説明できる

前の焦点鳥単位方向を `u_prev`、未来の移動方向を `u_future`、元の近鳥と遠鳥の過去単位方向をそれぞれ `n` `f` とする。観測した相対収束 `C_obs=(u_future−u_prev)·(n−f)` は、鳥が**元から近鳥に比較的近い向きを向いていれば**、左右対称の旋回だけで負になりうる。

観測した方位角の**絶対差**を `θ`、元の方向の相対一致度を `B=u_prev·(n−f)` とした条件付きの正確な幾何帰無は：

```
C_geom = (cos θ − 1) * B
C_excess = C_obs − C_geom
```

`cos θ − 1 ≤ 0`。実際、元の4,660区間のうち**2,833区間**は元の方向がNEAR優位、**1,827区間**はFAR優位。平均等鳥Bは **+0.234490**。過去と未来の移動区間間の元の平均絶対方位角差は**75.10度**（別移動区間間、実際の瞬間旋回角ではない）。そのため**純幾何学的な収束の負の期待値は、観測された負効果よりむしろ大きい**。

## 4. 元の旋回角を保持した1000回の数理的左右シャッフル

全同一17鳥・4,660区間で、各源GPS区間の**実際の絶対旋回角・元の焦点向き・近鳥と遠鳥の方向のペア**をすべて固定し、左右の曲がり方だけを等確率にして1000回合成した。

- 元の観測C_NF：**-0.097949**。
- 左右ランダム旋回のC_NF平均：**-0.135244**、1000回の5～95%数理分布 [-0.155062, -0.116319]。
- 左右ランダムの**幾何補正後**C_excessの平均：0.000234、5～95% [-0.019584, 0.019159]。
- 元の観測 − 帰無合成の平均：**+0.037295**。

元の観測されたマイナス値は、条件付き幾何帰無が生む負の値よりも**相対的に近鳥方向へ寄る**。ただし**1000乱数反復は1000野外個体群ではない**。帰無の左右対称性が自然の移動路線・風・潮流のもとで成り立っているかは独立には検証できていない。

## 6. Boidsの因果的な解釈へはまだ進めない

今回の純数学的な帰無は「旋回の左/右を選ぶ力が、元の近鳥と遠鳥方向とは無関係」と仮定する。**帰無超過が正でも、近鳥への社会的な追従が実測されたとは断言できない**。同じ航路上の鳥は、同じ海岸線、干潟露出、潮汐・風などの空間環境が実際に曲がる方向を決めるため、初期方向を揃えても左/右非対称が生じ得る。さらに外部鳥自身の運動向きが移動路線上の特徴を反映するため、外部鳥の過去方位が他の物理環境の代理変数にもなる。

**安全な到達点は「v45の負の数値を忌避と読まないことが必要で、初期方向・観測されている旋回角を補正すると相対的な方向超過が逆符号になる」こと。** これはBoidsの局所alignment、分離、凝集のいずれかを識別したわけではない。

**次の検証で必要なのは、実際の移動経路・海岸地形・潮汐条件と観測努力にそろえた方向シャッフルと、別個体群での事前モデルの外部予測。** 現在の一集団の後ろ向き帰無だけでは、局所社会力か地域共有運動かを選べない。
