- 元v139と同じ潮汐係数Low/Medium/High/Very Highから各1期間を丸ごと保留した5fold。保留音響機会は折ごと**76 / 78 / 77 / 79 / 77時間**。

## 重要な偏り

Roscoffの59欠測はランダムではない。v139の元監査で高水位側240時間から58時間、低水位側240時間から1時間が除外されていた。よって採用387時間に条件づけた予測モデルは**流れ雑音のため検出できなかった状態を含まない**。カリフォルニアの135,757時間とRoscoffの387時間の効果量は、観測機会・選別・分類内容と折構造が違うため**同一メタ効果量へプールできない**。
