# 潮汐 × Boids：2026年11月5日 研究成果の統合

**証拠の最上位は野外GPSと独立したRWS実測潮位の年外予測。ただし、予測的な関連であって物理的な潮汐前線・採餌・社会的相互作用を原因として同定したわけではない。** v29の前線ABMは理論上の十分条件を示す模擬実験、v30–v43の野外GPSは記述・予測的関連とデータ可観測性の評価であり、同一水準の証拠ではない。

## 研究としての中心的問い

**「周期的に開閉する環境の状態は、他個体の動きを直接追跡せずとも、鳥の移動の速度・進行方向・集合の見かけをどこまで組織化するのか？」**

現時点で実測で支持できるのは**前二者に対する潮相の追加予測情報**の部分まで。局所資源の移動、集団の見かけの同期、社会的Boids力を一括して「実証」と呼ばない。

## 生態学上の暫定的な結論

> **潮位が同じであっても、潮が満ちているか引いているかという環境の時間的状態は、移動速度だけでなく、直前の移動履歴を考慮した次の移動方向にも予測情報を持つ。その情報量は個体群・年・観測される移動軸に依存する。**

この主張は単純な「干潮だと活発になる」より具体的。現時点で示したのは**潮相に条件付けられた移動方策**の予測情報であり、干潟の採餌境界を追う物理的力を計測したのではない。Boidsの環境項 `F_tide` を観測で制約できる可能性はあるが、その符号や方向の空間ベクトル場を一意に推定したわけではない。

## 次に必要な検証

1. **同じ原本GPS三点区間に限定した速度と方向の二標的モデル比較**：位置・潮位・時刻・過去方向をそろえ、潮相の予測増分が運動軸ごとに異なるかを、鳥/週推定量の分母を合わせて検証する。これはv43までの結果を見た後なので**探索解析**と明記。
2. **地形と実際の資源前線**：公式にアクセス許可された同時期のNAP海底/干潟標高を取得し、RWS局所潮汐の伝播と季節的地形変化を補正。実際の濡れ/乾き境界への相対方向、採餌の状態、滞在や探索時間を説明・年外予測する。2014 AHNとの時差を感度分析で明示。
3. **独立した鳥集団・種での確認**：同じWadden海のミヤコドリだけで普遍性を主張せず、別地点の独立追跡個体・WATLASコオバシギなどで位相×移動方向を、学習済みパラメータ調整なしに外挿検証する。
