# v46 実測GPS × 歴史的AHN2標高の空間重複（生態学的効果を推定する前の原本品質監査）

**2026-11-05 JST。原本GPS・歴史的DTMのSOURCE-ONLY観測支持、潮位との効果は未推定。**
2010年の原本GPSだけから個体×日数の多い2km四方8区画を固定。歴史的AHN2（2007〜2012）公式WCS、EPSG:28992のFloat32 DTM候補バンドと正規化された補助バンド≥0.999（意味未確証）を使用。AHN2元の0.5m標高グリッドではなく**256px/2km ≈7.8125m再標本化**。2011/2012の原本GPS三点A→B→C（各30–120min、両区間0.4–120km/h）のC位置が2010固定区画にある場合に原本有効標高が取得できるかを監査。**RWS潮汐時刻・水位はこの分析で一切結合していない。**

## 何が判明し、何が未検証か

実測GPS到着地点と、同年代（AHN2測量期間2007〜2012）の地理参照付き標高候補を**両島の2011年について照合可能**なことが実際に確認できた。しかし**出発点Bの標高やB→Cの高度差、タイドステージの水位との関係はまだ推定されていない**。2011のCのみで1,018・1,243件が確保できたからといって、BとCの両標高が同時にある区間や新たに露出した場所への移動が十分あるとは限らない。

2024年Dryadの2014地形ZIP（HTTP401）ではなく、公式AHN2 WCS original patchが取得できた。AHN2の場所ごとの正確な測量年、海水面の欠測/反射の品質、浮き砂・干潟へのLiDAR非到達、補助Float32の正式な意味はなお未検証。公式AHNの一般的な点群精度と、再標本化したDTM個々の画素の誤差は同一ではない。±0.05m付近など境界での乾湿判定を不用意に行わない。

**次**：同じ2010年固定8区画と原本2011年三点GPSを用い、BとC両方の有効なAHN2 NAP値がある組数・異個体数・区画数・週数をチェックする *v47 source-only gate*。この結果を見てから「実測潮位と地形から新規露出への移動」を事前固定する。これまでのv44速度vs方向結果を修正・消去しない。
