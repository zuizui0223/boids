## 2. 本研究のマクロ論文としての主題

**Global tidal–solar opportunity landscapes: how coastal tidal rhythms and astronomical daylength structure ecological time**

中心は「別々の時計（太陽の明暗、月・太陽の潮汐）が干潟生物の環境への到達可能性をいつ・どこで開閉するか」。先に生物を離れて元の**海面水位と実際の太陽高度の重なり**を地球規模の外生的物理環境として定量化し、その後に独立した複数種・複数地域のGPS・実測行動・生息地を第二階層で検証する。既存ミヤコドリは**一つの特定地点事例**であり、生態学的な普遍効果を示す主サンプルではない。

### 必要な区別

- **海面水位が低い時間と太陽が出ている時間の重なり**：世界中の元UHSLC品質管理済み毎時潮位×緯度経度×UTC天文太陽高度。これは一般化できる**実測物理機会**だが、干潟の個別ポリゴンが本当に干出した時間ではない。
- **本物の地理的な干潟の面積分布**：全球の [Global Intertidal Change v1.2](https://www.intertidal.app/download) 30m衛星由来マスク、1999〜2019年。全球の干潟の存在・変化を検証可能だが、独自地形標高×その瞬間の潮位がなければGPS地点での干出面積を作れない。
- **生物の時間・空間ニッチ／移動／Boids環境強制**：公開の野生GPSと実測採餌、現地の生物相や生息地特性が独立に揃うときに限り、潮汐・太陽の外部物理機会からの行動応答を検定する。異なる種の元位置数を独立な個体として数えない。近同種のリアルタイム位置がなければ社会的Reynolds力を推定しない。

## 3. 前もって固定した全球の物理指標と統計単位

各元観測所s×元年yで、真正の元水位時系列h(t)の年内25%分位`Q25`以下を相対的な低水位時間とする。時刻tの太陽高度`alpha_s(t)`（元駅緯度経度・UTC）>+3度を昼として、低水位時間が昼と重なる割合`O`を計算する。さらに元の昼時間比`A`を減じ`O−A`とすることで、長い日長だから昼の低水位が単純に多いという既知の幾何学を意識して比較する。**低水位25%は実際の干出地形標高や安全な餌場面積を示す物理閾値ではない**。

旧v70が示した「ほぼ同じ日長でも、昼と低水位の重なり時間が異なる」という実測の2島の機会差を、全球の観測所×月×年で拡張する。潮位の満ち引きの複数周期、極地の昼夜、緯度、季節、spring-neapの14.77日周期、地域・大陸差を同じ物理指標で解析する。共通の正負符号を仮定しない。

対象観測所の元の2019年以降の潮位実測が十分な年を先に確保し（少なくとも年/月80%を観測した元の毎時レコード）、まず2019年の地理層別パイロット、次に**2000〜2024年の支持された全球全観測所×元年**へ拡大する。元年×潮位原観測所×沿岸地域がサンプル単位、数百万個の時刻を独立な海岸実験と扱わない。実際にあらかじめ地域を留保して地理的予測の再現性を検証し、最初のオランダ2島に含むGPSはマクロ物理環境パネルの全体結果と別に示す。
