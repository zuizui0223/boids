# v34 pre-result original-source gate — 2026 fish VR/robot social-rule intervention datasets

**Frozen 2026-11-24 JST BEFORE opening any original figshare file, trial-level treatment or fish movement response.** The preceding original v33b 2021 EIDC source results and counterexample are known; v34 is a new **independent experimental-source admission** inquiry, not a new effect until author files are authenticated and treatment assignment is reconstructible.

## Motivating source-verified v33 result

MacGregor & Ioannou (2021) true 12 original experimental shoals, complete 84 EIDC native fish trials, found **12/12 positive** for local-neighbor present velocity conditional on global group velocity, true nearest3 velocity-to-position assignment versus a fixed one-shift other-fish velocity permutation, and nearest3 versus farthest3, both 0–0.2s and 0.6–0.8s future movement windows. Short near beyond global: MSE +29.3105, relative 0.876%; delayed +140.1293, relative 1.652%. Pre-result original v33 froze 6 panels/12 group holdouts; v33b only sharded source data after original single 48min job was cancelled before computing any v33 effect. [Full observed result](V33B_ORIGINAL_84_TRIAL_TWELVE_SHOAL_LOCAL_POSITION_ASSIGNMENT_RESULT.md). Analytic [zero-fish-social-arrow spatial environmental input counterexample](V33_NO_SOCIAL_ARROWS_SPATIALLY_CORRELATED_COMMON_INPUT_EXACT_COUNTEREXAMPLE.md) shows all three local predictive advantages can occur with externally correlated water flow and no fish-fish causal edges. Source v33 therefore CANNOT identify causal Reynolds/Boids force.

## New original closed-loop intervention sources, published identifiers (only metadata verified so far)

1. **Primary: Kang et al. PRX Life 4, 043007, published 2026-10-29, DOI 10.1103/18qw-sfyd**: closed-loop **real rummy-nose tetra + four virtual conspecifics**; virtual agents' number of influential neighbors manipulated (`k_V=1,2,4`). The journal's [official Data Availability](https://journals.aps.org/prxlife/abstract/10.1103/18qw-sfyd) specifically links original figshare **DATA DOI 10.6084/m9.figshare.31378621** and original **CODE DOI 10.6084/m9.figshare.31386349**. Do NOT assert that those figshare records actually contain identity-resolved fish trajectories or correct session IDs before inspecting their file manifests.
2. **Independent experimental family: 2026-08-03 bioRxiv preprint, Closed-loop robotic interactions reveal dynamic social filtering in schooling fish, DOI 10.64898/2026.08.03.742553**: four real fish + one closed-loop robot fish in five-member school, robot uses influential `k=1` or `k=2` neighbors, original article states [data DOI 10.6084/m9.figshare.33086195](https://doi.org/10.6084/m9.figshare.33086195). Preprint evidence, not a peer-reviewed confirmatory replication. The experimental manipulation is of the ROBOT's response rule, NOT randomized deletion of real fish's lateral line or full fish-to-fish effects. Need direct, verified source file metadata and trial units.
3. **Secondary historical methodological family: Escobedo et al. 2026-08-03 PLOS Computational Biology, DOI 10.1371/journal.pcbi.1014544**, closed-loop 3D real+virtual fish. Author original dataset DOI **10.6084/m9.figshare.30539666** from published Data Availability; initially source/conditions not yet known. Related research group/pipeline may overlap with primary, so DO NOT call it independent animal-population replication absent original subject/session crosswalk.

None of these original figshare data/code files has been fetched or authenticated as of this pre-registration. Links from journals are evidence of **declared data availability**, not data access/admission.

## Frozen source-only protocol, no biological outcome access

- For exactly these four original figshare API article IDs: `31378621` (primary DATA), `31386349` (primary CODE), `33086195` (independent robotic), `30539666` (3D), issue exactly `https://api.figshare.com/v2/articles/{id}` GET with HTTPS only, up to 3MiB JSON and short timeout. Reject redirects to unrelated hosts, malformed JSON, HTML login/error messages and HTTP200 API permission/error envelopes. Verify numeric response `id` matches requested article ID, DOI field matches 10.6084/m9.figshare.{id} or its documented equivalent variant, published record title and nonempty original file list.
- Record immutable response body SHA256, original published DOI/record ID, publication and modification timestamps if supplied, title, licensing metadata, original file array **names, bytes, supplied MD5/sha1 fields if any, and original direct download URLs** (only unchanged URLs actually returned by provider, no guessed URLs). Record whether a file is marked external/link-only; cap metadata outputs to 50 files per record and explicitly count all files, no infinite inventory. If file count >50, source STOP unless a separate source-only plan is made. Also output a conservative list of **candidate trajectory/trial log/condition/code filename patterns**, but NEVER claim the actual schema from names alone.
- Do NOT fetch original file contents; no CSV rows, no fish original position, no robot trajectory, no treatment outcomes, no claimed causal estimate in v34. Do NOT download large video, ZIP, private/restricted sources. Any provider URI must be source-authoritative and on approved original figshare host; print no auth credentials.
- Source family registration separates **VR paper/data**, **VR code**, **robotic-fish preprint**, and **3D prior paper**. The "VR virtual neighbor k" manipulation is controlled but its original fish experimental session randomization, repeated subject/group ID and treatment comparison are NOT verified yet. Publication conclusions are author claims, not original empirical findings produced by our code.
- Test source gating with fabricated JSON: correct article ID, metadata DOI, file list, allowed original download URL, hash, ID mismatch, 200 permission-envelope and login HTML, zero-file record, external/download URL. Output only manifest JSON status `AUTHOR_FIGSHARE_ORIGINAL_METADATA_VERIFIED`, `PARTIAL_SOURCE_METADATA_STOP`, or `SOURCE_ACCESS_STOP`. No numerical fish ecology effect measured.
- Next separate protocol only if original metadata admitted: download **small original README or study-level trial-manifest files only** with provider size/checksum and inspect whether trial/session/animal ID, intervention condition k, camera timestamp and true/virtual agent identity are explicit. Without all keys, stop before any treatment effect. Detailed causal experimental reanalysis would have to freeze exposure, outcome, cross-over and grouping before opening original outcome values.

**Authorship / novelty limitation:** Original authors have already experimentally studied selective social filtering and k; do not describe "a single influential neighbor" as a novel mechanism discovered here. A meaningful new inquiry could compare the **same v33 information-strength versus age-persistence diagnostics** under externally controlled virtual group rules, on matched original physical time scales and original experimental session units, if original data support it.
