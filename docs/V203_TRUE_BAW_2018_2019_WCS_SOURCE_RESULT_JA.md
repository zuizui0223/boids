## 研究主張の絶対的な上限
今回のSOURCEが`topography_inter_supratidal`で、intertidalだけでなくsupratidalを含む。収録面積＝干潟利用可能面積と主張できず、さらに「鳥が使える時間」でもない。元標高の鉛直datumはBAW 2025論文のNHN（NAP相当）説明という製品level証拠があるが、原TIFFのnative垂直datum属性・実地測量日・RWS観測局との校正は今回確認できていない。

原2018/19海面WMSはv197で**17/24 plausible数値候補と7/24 extreme NoData候補**。原WCS地形の0値も、元WMSのNoDataも、干出面積や採餌ゼロを直接意味しない。今後の年別干潟**面積**の推定には、native高潮・低潮線の向き/閉合・年高低潮位と地形の鉛直datum整合を確認して、morphology/areaのsource maskをまず同定する必要がある。

生物GPS地点ごとの局所海面とzの差、真の干出/露出、過去研究で確認した2018-fit/2019-testミヤコドリACC応答の増分、太陽/潮汐の相互作用、社会的Boidsパラメータは**新規に推定していない**。v182の元20m Deltares DEM実測日・垂直基準と局所潮位転送のSOURCE STOPを保持する。

次の機構向けの反証可能なsource仮説は、**有効画素の失われ方が空間的に集中しているのか、潮汐地形境界付近に限られるのか**である。ただし原BAW年次モデル更新のマスキング差を地形浸食と解釈しない。
