# v165：本物の潮汐はミヤコドリの直前15分の行動状態を説明した後にも情報を持つか

2026年11月16日。**v127–v130の2018/2019ミヤコドリACC×GPS行動分類と実測港潮位の結果をすでに見た後の探索的検証**。以下の原本・SOURCEの入場条件・モデル・偽位相・判定を新しいv165結果を開く前に固定。

## 生態学的問い

v130ではミヤコドリ35羽の2018年6〜9月、元193,088個体×15分観測binで、時計・天文昼夜に真正RWS Vlieland Haven実測潮位を加えると、誤った+3/+7/+11日の潮位よりよく採餌「加速度計分類比率」を予測した。ただし**同じ鳥が直前15分にも採餌分類されていたか**をモデルに入れていなかった。元の個体状態が持続しているだけで潮汐の増分を一部代弁する可能性がある。

元のSOURCEは[Zenodo corrected O_VLIELAND record 10053988](https://zenodo.org/records/10053988)、2018 GPS 1,787,112行、2018 ACC 2,675,982行、2019 GPS個体匿名照合とv128元MD5/SHA256。真正RWS vlieland.haven 2018年6〜9月10分実測17,569時点の4か月プロバイダSHAもv129元値と一致させる。元v130の**193,088個体15分共通元観測**と35羽/17暦週/4か月を再構成する。

## ソース入場（応答Yを使わずに固定）

元v130の各観測bin（個体、元UTC t）に対して、**同じ標識個体のt−15分が実際に記録された場合**のみ入場。元GPSやACCの欠測を採餌割合0で埋めない。またtとt−15を**同じISO暦週に限定**して、学習foldの説明変数がテスト週のYを跨いで参照するのを防ぐ。ただしテスト週の観測済み前時刻Yを使うため、これは**オンライン条件付きnowcast**であり週開始前の週単位前向き予測ではない。

最低SOURCE条件：真の連続15分bin≥25,000、元標識鳥≥20、元ISO暦週≥12、6〜9月4か月すべて、5foldの各foldに≥2週、昼/夜ともに元採用binの15%以上。SOURCEが足りない場合は停止して、良い効果が出るように敷居を後から下げない。元の匿名個体IDやGPS原時刻・座標は配布しない。

## 固定したモデル（すべて同じ新SOURCE観測bin）

応答 Y＝実測ACC分類の forage事象数／(forage＋inactive事象数) であり、**真の摂食時間・摂食成功や実際の採餌量ではない**。

| モデル | 内容 |
|---|---|
| SOLAR | 鳥IDダミー・月・時計調和3次数・月内日付とGPS位置の天文昼夜。v130と完全一致 |
| MEASURED_TIDE0 | SOLAR＋真正RWS水位・潮汐上昇/下降・相互作用（v130の5項） |
| HISTORY | SOLAR＋**同個体の実測15分前のACC採餌分類事象割合** |
| HISTORY_TIDE0 | HISTORY＋真正実測港水位の5項 |
| HISTORY_TIDE3/7/11 | HISTORY＋3/7/11日後の実測港水位の同じ5項。実際の鳥の元時刻・太陽・Yは動かさない |

元v130と同じRidge λ=20、インターセプトのみ無罰則、元尺度、予測0〜1クリップ。UTC ISO暦週%5の5foldを固定し、1週内で実タグ鳥の平均MSEを鳥等重み、その週の鳥平均を計算、17週を週等重み。元週の組合わせに対して1万回の記述的bootstrap（seed 20261116）、多重モデル選択なし。

必須コントラスト（正の差＝改善）：**SOLAR−HISTORY**、**HISTORY−HISTORY_TIDE0**、**min(HISTORY_TIDE3/7/11)−HISTORY_TIDE0**。最後は「潮汐が真の位相であること」の補助診断で、3つの偽位相のうちよりよいものに対しても本物が勝つ必要がある。

## 主張の限界

元と同じ実測個体・元2018年の探索的再解析であり、別地理・別年・別種の確認実験ではない。直前15分のACC分類値はテスト週に観測済みとして使うため、HISTORYモデルは**真の週前予測ではない**。港潮位は鳥のGPS地点から最大25km離れた代理であり、局所の干潟標高と真の冠水を直接示さない。元ACCは分類事象比率であって真の採餌時間ではない。**直接Boids整列/分離/凝集、潮汐×太陽の因果交互作用、全球メタ平均はNOT_ESTIMATED**。

## 原本と機械再計算

v128の匿名原本SOURCE artifact run 43463270204、v129の2018 RWS実測/行動原本 artifact run 43579877533からSOURCE元SHA台帳のみ取得し、**Zenodo元GPS/ACC、2018 RWS元水位を実際に再取得**して照合する。

Python synthetic fixturesで原15分実測、無観測ギャップ、週境界、週×鳥平均MSEを固定。GitHub Actionsの全元行を使い新しい匿名SOURCEの観測数と予測損失を計算する。結果は元行動時刻・個体・GPSを含まず、説明用SOURCE-safe集計、初回SHAレシート固定後厳密CIへ切替。
