## Why this is mandatory

The original D1 [CI 40841206422](https://github.com/zuizui0223/boids/actions/runs/40841206422) scored **492 original `birdyear` tokens, 188,812 chronologically later paired used/aggregated-available profiles**. M0 log loss `ln(2)=0.693147`, M1 common environmental profile `0.046256`, M2 species interactions `0.038612`, M3 personal history `0.040400`. The primary source-profile log-loss improvement M1−M3 was `+0.005855`, 330/492 positive, whole-birdyear bootstrap 95% `[+0.004147,+0.007591]`. But **all M1/M2/M3 ranked the original case TRUE above FALSE for literally 100% of heldout source profile pairs**.

Such complete separation across four species, nine original calendar years and all 492 scored birdyears is **scientifically suspicious**, possibly arising from the way authors constructed the original aggregated available profiles or the TRUE/FALSE summaries, even though the source was independently MD5/SHA256 verified and the target birdyear rows were held out during coefficient fitting. Absolute log loss below 0.05 does not prove biological predictive ability if the task is structurally trivial.
