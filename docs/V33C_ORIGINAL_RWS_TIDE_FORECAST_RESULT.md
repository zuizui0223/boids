# v33-C：Schiermonnikoog実際の天文潮データとミヤコドリ日次空間利用

**結果（2026年10月31日 JST）：日ごとの予測可能な潮差の変化だけでは、翌日のGPS空間的な広がりへの追加予測力は確認できなかった。** これはv32の既知の結果を受けて設計した探索的追加検証。元のv32の肯定・不支持の各結果を変更しない。

## 外部環境データ取得成功と元資料照合

オランダRijkswaterstaat（RWS）の公式水位観測点カタログで、**Schiermonnikoog, Waddenzee：code `schiermonnikoog.waddenzee`、53.468937 N、6.202908 E** を独立確定した。[公式API資料](https://rijkswaterstaatdata.nl/waterdata/)を使用し、`WATHTE`（水位）・`ProcesType=astronomisch`（太陽・月による計算潮位）を **NAP基準 cm** で2008～2014年の７年すべて取得した。各年UTCの10分スロットの **100%** が有効。データは元APIで表示された**オランダ固定冬時間 +01:00（夏時間への自動切替なし）**からUTCへ変換した。2,557日すべての天文潮日系列が完全条件を通過。

`ProcesType=meting` の**実測水位**は2010年１日の原ソース検査で別途取得できることを確認したが、**本予測には使用していない**。未来の実測水位の提供は時間的情報漏洩となるため、暦により事前に予測できる天文潮だけを使用した。

GPSはv32元資料Zenodo 10053970（2008–2014）の原本MD5/SHAを再照合。前日値MP、3–14観測日履歴MI、その50:50混合MHの全個体・全日MSEとモデル評価を凍結済みv32の数値JSONに対し**全項目絶対誤差1e−12以内で一致**させた。

本研究の比較対象は元の**36個体・7,086将来個体日**とまったく同じ。潮位が欠落して別の有利な鳥・日を選んだケースはゼロ。

## 探索的な事前固定比較

あらかじめ[追加プロトコル](V33C_FIXED_TIDAL_INCREMENT_FORECAST.md)で固定し、**新しい全年潮位曲線を開く前**にモデルと合成テストをGitに登録した（潮汐データ取得前だが、v32のGPS結果は既知）。

固定した潮汐入力は、各UTC日の水位範囲 `T_t=max(h)-min(h)`（m）の**前暦日から当日への変化 `T_t−T_{t-1}`**。これは「当日の満潮・干潮の時間帯」を表さず、主に大潮・小潮に伴う日間潮差の変動に関連する。固定ridge係数は以前の日に観測済みのGPS残差のみから逐次推定し、当日の個体全員の予測が終了するまで当日の結果を更新しない。βの正則化20、最初の100個体日はウォームアップとして追加項0。結果に合わせたモデル選択なし。

- **主比較、MH−MH+潮差**：+なら潮汐の予測力追加。実際は **-0.000039794**、36個体bootstrap 95% [-0.000170676, 0.000043122]、潮差追加で改善 **16/36個体**（非ゼロ33個体）。改善を支持しない。
- **季節対照（季節のみ−季節＋潮差）**： -0.000042015、95% [-0.000179115, 0.000045266]。年周期を入れても潮差の増分を支持しない。
- **７日ずらした天文潮のplacebo**： 0.000062301、95% [-0.000010383, 0.000144354]、非ゼロ33個体のうち18個体が改善。正の小さい点推定でも区間が0を含み、本来の潮汐との比較で真の潮差を特異的に支持することはできない。

### 生態学的な意味

- **「潮汐は移動に関係ない」とは言えない。** 1日2回の干潮・満潮に合わせて採餌／休息場所を移動する現象は、24時間のGPS空間的広がりへ集約すると相殺され得る。
- 本モデルで使ったのは**日間の潮差の変化**という１つの特定予測量だけ。潮差そのもの、実測した高潮・低潮時の位置差、潮位の上昇／下降、干潟の局所水深は検証していない。
- 公式天文潮は天体周期から得られた**単一観測点の指標**で、GPS位置ごとの干潟露出時間や餌量を直接測ったものではない。個体ごとの潮汐行動・空間的な潮汐環境の差を捉えていない。
- すでにv32で同じ36個体のGPS結果を見ており、これは完全独立な動物行動実験ではない。鳥のbootstrapも多数の独立した海岸を意味しない。
- 生物学的により直接的な次の固定検証は、[v33-Dサブ日尺度プロトコル](V33D_SUBDAILY_TIDE_MOVEMENT_ASSOCIATION_PROTOCOL.md)に基づく、**局所25 km内の原GPSに限定した高／低潮位下の移動速度**。同一個体×年・月×UTC時間帯を対応させて、時計時刻の影響を減らす。
