## Observed ecological question on the original field cohort

At the GPS animal's **recorded position**, how does a native NIOZ numeric `time_expo` **model** index compare with all native model grid cells in its **immediate 1-km neighborhood**? Does the animal tend to be detected in locally higher-valued model cells, and how much does this descriptive contrast differ between *astronomical* daylight and darkness? This is NOT actual observed feeding, RWS tidal phase, local accessible prey area, use/availability proven for animals, or learned behavioral adaptation. The source index 0..1 has **unknown exact documented time unit** despite README acknowledging a *tidal flat exposure time* field. Treat it as a **numerical ordinal model index only**. A detected GPS event is not a sampled foraging time.

## Boundaries

The full Wadden/NIOZ product is **modelled 200m monthly spatial exposure** with original units undefined, not an observed local NAP bathymetry model with a full 10-min tide clock. Its first original grid has 2010 latitude valid while Jan 2011 original latitude is missing. The actual astronomical low-water daylight window computed from measured RWS in v70 remains a different physical measurement. Original Schier source GPS visible fixes represent tagged locations, not confirmed foraging, and the hourly selection reflects recording and site movement. One winter month/one animal species/one Wadden region does not prove cross-species/daylength generality. This new original field check is intended to identify whether the real GPS can access a meaningful independent monthly tidal-habitat index before attempting truly temporal habitat/daylight ecology.

No full raw NIOZ raster, original GPS records, bird tags, exact lat/lon/times, original bird-specific contrasts, hydrodynamic modeled pixels or individual behavioral targets will be serialized. No regression coefficients from original future B→C headings, no social interactions, and no causal inference. A null/failed source keeps previous tide-only positives intact.
