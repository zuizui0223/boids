# v178：実GPSが2016年地形に対応しない問題を、過去6年の最新有効な標高層で検証する（結果前固定）

2026-11-17。元Vlieland 2018・2019年ミヤコドリGPS・ACC行動とRWS港湾水位の解析v169では、2018年だけで係数学習したモデルが2019年の保留データに対し、**自己の直前15分行動の後でも港水位の高さに予測追加情報**を持つと確認された。ただし、この「水位の高さ」が局所干潟の冠水・干出アクセスの結果かは不明。v177で原2016年ラベルNetCDF層に元GPSを対応させた結果、実SOURCE入場の2018 **8,311/157,863（5.26%）**、2019 **6,681/125,241（5.33%）**しか元z/isource非欠測ではなく、事前に固定した各年20,000源観測に未達で**SOURCE STOP**となった。大部分の元鳥GPSはタイル範囲内だが、2016年層自体に標高値がない。

## なぜ6年間に広げるか

Rijkswaterstaatの[公式モルフォロジー観測説明](https://waterinfo-extra.rws.nl/monitoring/morfologie/)では、Wadden Sea・沿岸・デルタの海底・干出干潟の標高は**3年または6年のサイクル**で測量し、20×20 m格子へ加工される。よって単一の2016年SOURCEに全セルの標高が揃うことは期待できない。最近の2025年統合地形を2018/19へ適用するのは測定年が未来になり不適切だが、**実行動時より過去に実測されたセルの最も新しい有効標高**を使うことは、歴史地形推定の妥当な前処理になり得る。

この補正はv177の失敗数値を見てから設計した**事後SOURCE感度**であり、独立確認的追試ではない。新SOURCEの判定閾値・設計はv178元結果を開く前に固定する。

- 各鳥の元2018年GPS×ACC観測に対しては、**2012-01-01〜2017-12-31**のSOURCEラベルに限る。2019年観測に対しては**2013-01-01〜2018-12-31**のSOURCEラベルに限る。この6暦年上限は**RWSの最大6年サイクルに基づき結果前に固定**し、都合よく何十年も前の地形で補完しない。

## 未解決の本質的な測定条件

1. 元NetCDF\`time\`の2016-01-01などは**年単位のラベルであって、そのセルをその日測量した証拠ではない**。元\`isource\`も、数値だけで実測年月日へ変換できるとは限らない。この版でいう「6年以内」とはSOURCEの**時刻ラベルの古さ**であり、現地フィールド実測日の不確実性を別途扱う。
2. EPSG:28992は水平座標系。RijkswaterstaatのVaklodingen測量は一般に**NAP基準の20m標高製品**だが、今の元NetCDFの\`z\`の鉛直基準と港の本物の水位データの単位・鉛直オフセットを個々に証明するSOURCEは未完了。**\`h_\mathrm{harbor}-z_\mathrm{GPS}\`を行動の局所水深として計算してはならない**。
3. 元GPS地点は最大25kmの広いVlieland範囲で、港湾水位との位相・振幅差、局所干潟DEMの補間誤差、2012〜2019年の地形変動が残る。SOURCEと対応しても個体の実採餌成功/餌密度・干潟アクセスそのものを証明しない。
4. 2019年の自己前15分ACC分類値はその時刻の前に実観測されているオンライン条件付きnowcast変数であり、2018年から2019年全未来予報ではない。
