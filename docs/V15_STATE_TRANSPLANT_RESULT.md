## 5. 音による運動を切ると、位置の効果はどう変わるか

位置の挿入を100−000、位置の除去に対応する差を111−011と定義しました。「除去の差」は、位置だけを無刺激由来に戻したときに失われる量の符号で表しています。motor_cutでは、分岐後に音響運動の重みだけを0にし、受音→発声の重み3を残します。下表のDIDはmotor_cutの差からintactの差を引いたものです。

## 9. 結論の範囲と次の論点

今回の96シードでは、有限時間の刺激効果は平均として正でしたが、大きさは少数のシードに強く依存しました。速度を分けて交換すると、位置だけを「記憶の担い手」とする説明では捉えられない差が現れました。XとCの平均Shapley配分は近く、X−Cの区間から優劣は決まりません。

このモデルには独立した潜在的な内部記憶変数はありません。Cは各個体の直前の二値発声を並べたベクトルです。各個体の受音量を計算するときは、その個体自身の発声を除きます。本監査が示すのは指定した更新式の中での状態交換の帰結であり、生物学的記憶、魚群一般の機構、自然な媒介効果、定常状態の一意性の証明ではありません。

追加の検証を設計するなら、速度由来の効果が大きかった例と成分間の非単調性を、さらに独立したシードで事前に定めた比較として確認することが論点になります。今回の結果を見てシード、時間窓、閾値を追加した解析は主結果に混ぜていません。実測との結び付きについても、新しい共同観測データによる検証は本版では行っていません。
