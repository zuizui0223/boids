# v134 diagnostic log after first model run

The prefit specification remains unchanged. The first completed run showed all primary model losses above `log(2)`, the fractional cross-entropy of an unfit constant prediction of 0.5. Consequently a postfit calibration diagnostic was added: report both this fixed 0.5 comparator and a constant prevalence estimated only from training animals, with equal total weight per animal. These diagnostics do not change any model, held-out folds, thresholds, clock shifts, masks, regularization or result-selection rule. Their purpose is to prevent a relative improvement over an inadequate baseline being presented as useful predictive performance.

During output reconciliation, the original-zero-node sensitivity unexpectedly had the same window count as the conservative analysis, despite 39 windows touching such nodes. A focused failing regression test showed an in-place NumPy mask operation was mutating the shared `common_support` input. Taking an explicit mask copy corrects the source-state mutation. The primary result is unaffected; all sensitivities were rerun from the exact saved derived inputs after the fix. The original-zero-node analysis must now contain 3,373 windows versus 3,334 in the conservative primary sample.
