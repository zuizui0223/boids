# v33-D：潮位が低いほど、同一ミヤコドリの移動速度が大きい（観測上の対応関係）

**2026年10月31日 JST。独立したRWS天文潮と元のSchiermonnikoogの野外GPSを時刻結合した探索的な結果。** 既知のv32動物GPS結果を見た後の研究だが、潮位値と結合する前に[高・低潮位のquartile定義、25 km地域範囲、GPS観測間隔、鳥×年月×時刻マッチング、支持条件、比較方向](V33D_SUBDAILY_TIDE_MOVEMENT_ASSOCIATION_PROTOCOL.md)を凍結した。旧v32結果およびv33-Cの日次潮差予測を変更しない。

## 結論

*「24時間の広がりへの潮差増分」は不支持だが、「1日内での水位によるGPS移動速度差」は明確な負方向*。**高潮位側 − 低潮位側**の事前固定対比は、log(1+km/h)尺度で**-0.215357**、全鳥等重み bootstrap 95%区間 **[-0.240182, -0.190023]**、**36/36個体で負方向**（高水位側でより遅い、低水位側でより速い）。中央値 -0.230644。オリジナルの36鳥は１つの地域・観測方法を共有するため、36の独立した生態系ではない。

本比較は**当日の水位と既観測の移動速度の関連**であり、未来の移動速度の独立した予測、干潟への採餌、獲得した餌、ねぐら選択や潮汐の因果機構を示すものではない。固定モデルの符号検定は**「高水位の方が速い」という正方向**について設計されており、正方向片側p=1。結果に合わせてこれを「低水位側優位の確認的検定」に置き換えない。95%両側区間が0を含まないという**探索的な負方向効果**として報告する。

## データと解析単位

オリジナルミヤコドリGPS：Zenodo 10053970 version v4、2008～2014年の7 gzip、公開元MD5と事前固定SHA256一致。全602,396行、元のvisibility/outlier規則で16行除外、個体×UTC重複ゼロ、602,380有効GPSfix。独立環境資料：Rijkswaterstaat公式WATHTE `schiermonnikoog.waddenzee`、`ProcesType=astronomisch`、単位cm、NAP基準。2008～2014の全7年のUTC 10分グリッドに欠測なし。水位の高さは各GPS地点の局所水深を意味しない。

RWSが観測している全７年の天文潮位から動物GPSを使わずに事前定義した源データの分位数：**低水位下位25% ≤ -0.69 m NAP**、**高水位上位25% ≥ +0.76 m NAP**。中間50%は比較設計上除外した。

固定したGPSペア条件：同一個体の隣接する**原観測の2fix**、経過5～180分、両fixが正式潮位点（N 53.468937, E 6.202908）から25km以内、ペア中点UTCを最も近い原RWS 10分値へ±5分内で結合。移動速度はGPS二地点間の最短距離（haversine）/原観測時間差、log(1+km/h)に変換。経路の真の総移動距離・歩行／飛翔の識別ではない。

- 有効潮位と局地GPSに対応した隣接fixペア：**473,317**。そのうち高・低水位の固定分位に分類：**239,864**。
- 同じ**個体×観測年月×UTC時刻帯**の中で高・低どちらも２ペア以上ある比較可能階層：**5,435**。さらに各鳥８階層以上の事前支持条件を適用し、**5,422対応階層・36個体**が最終対象。
- 解析時の除外理由：GPSペア観測間隔の条件外 98,041、25km範囲外 30,983、中間潮位 233,453。除外数は一部段階別で、全原fix数からの単純引き算ではない。

各階層内でhigh−lowの平均log速度差を算出し、その階層差を個体内等重み平均、最後に全36個体等重みに平均した。**239,864ペアや5,422階層を独立研究のnとして検定していない。** 10,000回個体単位対応bootstrap、種内の一生態系・固定季節内の相関は残る。

## v33-Cとの組合せで新たにわかったこと

**v33-C：** 全36個体・7,086個体日の予測可能な天文潮**日間潮差変化**を入れても、前日＋過去履歴のMH予測は改善せず：MSE(MH)−MSE(MH+潮差)=**−0.0000398**、95% [−0.0001707,+0.0000431]。[全結果](V33C_ORIGINAL_RWS_TIDE_FORECAST_RESULT.md)。

**v33-D：** 同じ島の半日潮汐周期の**高水位側では移動速度が低く、低水位側では高い**という対応が36/36個体で見られた。相互に矛盾しない。日間潮差差分で24h空間的広がりを予測するモデルは、個体の数時間尺度の潮位条件と移動速度の共変動を直接捉えていない。

**生態学的仮説：** 低潮位で干潟利用・採餌活動が増し、高潮位で休息地滞在が増すような*時間的活動機会の切り替え*と整合的。ただし餌場／休息地の位置・滞在・姿勢・採餌・潮汐の原因は本解析では観測していない。短いGPS間隔の分布、移動時間間隔と潮位の交絡、潮汐に同期した捕獲・記録スケジュール、日周行動、風浪・年季節の変化を完全に取り除いていない。

高低の**潮位水準**と、潮位上昇・下降（ebb/floodの向き）または大潮・小潮の**振幅**は異なる。今回実測したのは**水位の上位／下位quartileの比較**。次に検証できるのは「同じGPS観測間隔をもつペアで再現するか」「異なる年に再現するか」「実測潮位と天文潮の差がどの条件で大きくなるか」。これらは今回の主比較の事後診断としてラベルし、確認的な証明へ格上げしない。
