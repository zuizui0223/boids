## Critical data validity: literal 2016 projection differs from canonical EPSG28992

Original RWS 2016 GeoTIFF WKT contains PROJECTION "Stereographic" (PROJ=stere) despite an attached AUTHORITY["EPSG","28992"]. In contrast, authentic 2021 RWS GeoTIFF and reference Dutch Amersfoort/RD New EPSG28992 use Oblique Stereographic (PROJ=sterea). PROJ documentation explicitly states these methods differ for oblique coordinates. The publisher's 2016 geographic method is therefore NOT equivalent to source-stated EPSG ID; rasterio correctly gives native 2016 CRS.to_epsg() as None. In the SAME fixed Roggenplaat 2019 DTM5 coordinates the 2016 literal WKT vs canonical EPSG source projected point is displaced by median **3.823677 m** (range **3.819518–3.827838 m**). The numeric raster affine origins do differ by integer multiples of 20m (88.99999999999 and -7.9999999997 native-cell widths); this DOES NOT mean the physical source pixel polygons overlap exactly because the 2016 WKT projection operation is not the canonical one.

This source discrepancy is material: among the exact same original 441 fixed 5m Roggenplaat sample-point centers, treating native 2016 WKT literally versus forcibly reinterpreting the 2016 publisher's EPSG authority yields **105/441 locations assigned to a different 2016 native source cell** and **58/441 locations assigned a different original 2016 numeric drying map value**.
