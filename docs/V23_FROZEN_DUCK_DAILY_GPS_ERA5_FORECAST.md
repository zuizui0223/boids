## Fixed geographic and temporal eligibility

- Only the original study named **`Dabbling duck migration Bangladesh 2019-2022`**, using original `study.id × individual.id` as individual key (do not treat all seven species as independent regional experiments). No eBird.
- Parse original UTC `timestamp` strictly `YYYY-MM-DD HH:MM:SS`, WGS84 lat/lon finite in [-90,90]/[-180,180], original `gps.hdop` finite and in [0,15]. **Drop ALL repeated same-ID+UTC timestamps** (not take a convenient first/last duplicate). Use only actual measured GPS points, never interpolate timestamps or infer neighbor contact.
- An original **UTC day** yields a measurable daily target only if ≥6 distinct valid GPS fixes and span **≥8 hours** of that day. Its daily horizontal **radius of gyration** is `R = sqrt(mean(((lat-latmean)*111.2 km)^2 + ((lon-lonmean)*111.2*cos(latmean))^2))` in km, and the scored target is `log(1+R)`. This is *daily spread of original recorded positions*, NOT a habitat-use niche, true home-range area or between-day displacement.
- For target day `t`, the individual must have a complete qualifying measured day **t−1**. Choose nearest of the TWO fixed wetland reference points by great-circle distance from the **last observed GPS position on t−1**. Require distance ≤**120 km**. No current/future day position is used for wetland selection. The original Padma River capture region is excluded unless previous GPS truly lies in a fixed wetland radius; no invented climate grid for all of Padma.
- Predictor weather is strictly **ERA5 day t−1** at the frozen selected wetland grid (not current target-day weather). Fixed climate class is `rain_prev_day = (precipitation_sum > 1 mm)` and `warm_prev_day = (temperature_2m_mean ≥ 25 °C)`, making 4 possible bins. `wind_speed_10m_max` is quality-checked but NOT a selected model predictor in this first test. These thresholds are fixed a priori, not empirical medians. No wildlife outcome values were inspected to define them.
- Require ≥3 prior *eligible* same-wetland duck daily spread observations for that individual (strictly before t), using only the **latest 14 historical eligible days** to estimate private-history mean (cap based only on calendar order, not outcome). Other-bird source summaries may use all earlier eligible days, each external individual **one equal weight**; contemporaneous and future days are excluded.
- Minimum pre-outcome source support: **≥20 independent original individuals**, **≥200 qualifying future bird-day targets**, **≥20% future targets whose weather class has enough prior external matching data**. Otherwise `NOT_ADMITTED` and no model score exported. This does not authorize lowering wetland radius, minimum daily fixes or target count based on observed errors.

## Four fixed predictors, identical future days

For each duck-day `(i,t)`, first compute historical reference from only *other* ducks' daily spread values with date < t and the same fixed wetland region; source history is aggregated to one mean per external bird before averaging:

- **M0**: other-bird prior daily log spread mean, regardless of prior weather bin; require ≥5 external birds and ≥20 historical other-bird days.
- **ME**: other-bird prior daily log spread mean only from prior days with exactly the same frozen day t−1 rain+temperature class. Require **≥5 other birds and ≥20 prior other-bird days** in the matched class, else **fall back to M0** based only on prior source support. Preserve every fallback count, no cherry-picking.
- **MI**: same individual's own last up to **14** historical complete/eligible daily log spreads from same wetland.
- **MEI**: fixed external-reliability shrinkage `(1−w) ME + w MI`, **w=n/(n+2)**, n = number (3–14) of strictly previous individual-day records. `kappa=2` imported from v20/v22 *without tuning on this duck dataset*.
- All M0, ME, MI, MEI score the SAME heldout `log(1+R_{i,t})`; primary **MSE(ME)−MSE(MEI)** (does individual history beyond independently retrieved historical climate help?), registered secondary **MSE(M0)−MSE(ME)** weather bin gain, **MSE(MI)−MSE(MEI)** shrinkage versus raw own history, and **MSE(M0)−MSE(MEI)** total.
- Prequential historical estimation: for all targets on UTC date t, predictions are made BEFORE any source observed t-day values are added to any other-bird history. No current/future observation can affect a historical comparator. No fitted cross-validation ridge hyperparameters; all means and shrinkage are frozen.
- Mean squared log-radius error first within each independent original duck ID, then equal weight across independent IDs. Whole-duck **10,000 cluster bootstrap** with RNG seed `20261029`, plus full signed bird-level counts, site/season/source species support and date coverage counts. No p-value treating individual-day GPS fixes as iid; species, country, years, weather shocks are not independent randomized strata.

## Scientific restrictions and falsification

This is a **true new independent wildlife individual-GPS plus regional reanalysis weather predictive test**, but not a causal climate effect: daily weather estimates are historical ERA5, same nearby grid for multiple ducks, and the weather regime categories are crude. If matching weather class is missing for many targets, the source support gate stops. If primary negative, report negative without trying different wetland radii, weather thresholds, log transformations, training horizon or animal subsets.

No biologically verified private cognitive memory, actual conspecific social partner, resource-use availability, calibrated 3D niche or Reynolds force coefficient is identified by this endpoint. Explicitly preserve all original v13–v22 frozen values, including v22's same-population wild guineafowl shrinkage secondary.
