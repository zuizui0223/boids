# v44 — 同一GPS三点区間で、潮汐は移動速度より移動方向の予測情報として重要か

**2026年11月5日・原本実測結果を凍結。** [解析仕様は今回の出力を見る前に固定](V44_PREOUTCOME_MATCHED_EPISODE_TIDE_SPEED_DIRECTION.md)したが、v32–v43の移動速度・方向の既報結果を見てから設計した探索解析である。**新しい独立集団の確認試験ではない。**

## 研究の問い

同じミヤコドリの **A→B→Cという3点GPS軌跡**で、A→Bの過去速度・過去方向、B地点・潮位・日時を揃えたとき、B地点の上げ潮・下げ潮（潮相）が **B→Cの移動速度** と **B→Cの進行方向** の予測をどの程度改善するか。異なるGPS区間を使って「速度と方向」を比較していた過去の制限を解消する。

元のv41 `original_three_fix_heading_episodes` を一切変更せず、別途**原本GPSを読み直して同じB時刻・個体ID・GPS中間点・次の単位方向が完全一致する場合のみ**B→C速度ターゲットを結合した。**元のv41方向モデルの予測値が数値精度1e−9以内で一致することも確認**した。同時に、未来のC地点や未来の速度・方向を説明変数に入れないテストに合格している。

両標的のM0：絶対潮位と二次項、B地点の緯度・経度、時刻・季節のsin/cos、過去の移動方向（東・北の単位ベクトル）、過去の `log1p(km/h)`。M1：M0＋潮相（上げ/下げ）＋潮相×潮位。学習年のみで標準化した個体均等重み付きridge λ=10を固定。速度は `log1p(B→C km/h)` 二乗誤差、方向は次の単位東・北ベクトルの二乗誤差の半分。それぞれ異なる損失単位なので**絶対MSE同士を直接比較しない**。同一標的内の相対誤差減少率 `R_axis=1−MSE1_axis/MSE0_axis` を定義し、主比較を `R_direction−R_speed` とした。正は「方向軸の**自分自身の基準モデルに対する相対的な予測改善**が大きい」を意味するだけで、潮汐の行動因果効果が大きいことを意味しない。

原本はZenodoの2009–2012ミヤコドリのうち、2010・2011・2012年のSchiermonnikoogとAmeland原本GPS（公開提供者のgzip MD5を再照合、SHA256を記録）、さらに各島のRWS観測点の `WATHTE meting` 10分間隔実測水位（cm NAP、元時刻UTC+01、2010/2011年各52,561件、2012年52,705件）である。原本鳥ID・緯度経度・GPS正確なタイムスタンプや潮位時系列は公開しない。

### 原本GPS時計を一律−15秒補正した感度分析

同じ2島・同じ年・同じ事前固定モデルでも、Schier 2011は速度R+1.433%、方向R+7.931%、相対差+6.498 pp（個体CIはゼロ交差）。Ameland 2011は速度R−1.465%、方向R+14.864%、相対差+16.330 pp（対応する個体CI [+11.135,+22.131] pp）。符号は変わらない。ただし元GPSがUTCかGPS時刻かは独立未検証で、2012年7月にはGPS−UTCが15→16秒となる。−15秒が正解と確定したわけではない。

## 生態学的結論をどう書くか

**堅い観測上の主張：**

> 同じミヤコドリの移動三点区間において、観測点で実測された上げ下げの潮相は、個体自身の過去の移動方向・速度と潮位・位置・時刻を統制した後でも、次の**水平移動方向**を年外予測する追加情報を持つ。2011年のAmelandでは方向軸の相対誤差が大きく改善する一方、全く同じ移動区間の**速度軸の予測は悪化**した。Schiermonnikoogでも方向・速度はともに改善するが、方向の相対改善がより大きいという**個体間差のCIはゼロをまたぐ**。

**原因については仮説にとどめる：** 潮汐によって一部の経路や資源へのアクセスが開閉すると、動きの「向き」は変化し得る一方、平均速度は速くならない場合がある。しかし、元GPSは実際の餌資源、干潟の露出時刻、歩行/飛翔/休息行動、局所海流、潮汐前線や真正社会的整列力を識別しない。線形位置・周期共変量では移動経路の空間構造が取り切れない可能性もある。**相対予測誤差削減率の差は、生物学的な機構効果量や強い因果証拠ではない**。特に2011年の2島は同じ地域・同じ種で独立地域ではない。

元の個体別環境応答、v34の潮位帯による上下潮非対称性、v40で確認したSchier 2012速度予測の正の外部年効果、v41/v43の方向結果は保持したまま、**異なる速度vs方向サンプルを比較していた混同だけを除去した**。既存v47の空間・時刻・潮相一致シャムで局所社会的整列効果が縮小した知見とも矛盾しない。
