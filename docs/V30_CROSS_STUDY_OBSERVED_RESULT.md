# v30 観測結果：4調査群への前日状態モデルの地域間検証

**2026年10月30日 JST — 全4調査群の事前固定条件を満たして完了。** 原資料のハッシュと事前固定した群・対象日・比較方向を保持した。[公開済みプロトコル](V30_CROSS_STUDY_PERSISTENCE_PROTOCOL.md) はGPS位置および4調査群の移動結果を開く前、commit `217f8268505347798cd124d37213c4ca366bc09d` に保存した。v23/v29のバングラデシュ結果はすでに既知だったので、これは**同一原資料内の未解析調査群による探索的な地域間検証**であり、新しい独立アーカイブを用いた完全な再現ではない。

## 1. 判定

オリジナルのGPS資料（Zenodo 16940654；46,324,165 bytes；公表MD5と原SHA256照合済）から、バングラデシュを一切含まない事前指定の4調査群を評価した。元のsource-only ID・日時監査では計123個体だったが、厳密なGPS品質・前日完全観測・履歴・他個体参照条件を通過したのは **112個体・8,369将来個体日**。各調査群の採用要件（8個体・80日以上）、全体要件（60個体・500日以上）を全て満たし、`EXPLORATORY_ALL_FOUR_STUDY_HOLDOUT` が成立した。

**主比較（外部同種履歴 MS 対 前日状態 MP）は4群中3群でMPが優位だったが、全4群に共通の改善は確認されない。** 4群等重みの `MSE(MS)-MSE(MP)=+0.115849`、群bootstrap 95%区間 **[−0.004881,+0.290224]**、4群符号検定 p=**0.3125**。オランダ／リトアニアでは符号が逆であった。

**事前固定した副比較（前日状態 MP 対 50:50の前日＋複数日履歴 MH）は4群すべてでMHが優位だった。** `MSE(MP)-MSE(MH)=+0.048568`、群bootstrap 95%区間 **[+0.031984,+0.065152]**、**4/4群**で正、正確な片側符号検定 **p=0.0625**。全4群等重みのMSEは MP **0.234047**、MH **0.185479**で、相対的に **20.75%低い誤差**。これは探索的な副比較で、多重比較補正を行っておらず、4群のbootstrap区間だけで生物学的な普遍法則を主張できない。

## 2. 実際の独立単位と予測誤差

評価は各個体の将来日誤差を先に平均し、同一調査群内で個体を等重みにし、最後に4調査群を等重みにした。日数やGPS fixesを独立な実験数として扱わない。各モデルは**全て同じ8,369将来日**を評価する。

その他の全体MSEは M0（他個体の過去）= **0.353801**、MI（自個体の直近3–14観測日の平均）= **0.230855**。MSは同じ種の他個体による履歴が不足する時のみ、結果を見る前に固定したM0へfallbackする。全ターゲットの **1,196/8,369** はこのfallbackである。これは種固有の基準が全観測で成立したことを意味しない。

### v29と混同しない

v29バングラデシュの49個体・2,664日では、前日モデルMPが従来の環境付き複数日モデルMEIより数値上よく、MEIの追加優位は支持されなかった。しかし **v29では新しい50:50のMHを事前固定して検証していない**。そのため、v30のMH肯定をv29の「失敗の救済」や同じ手順の独立再現とは呼ばない。v29の結果はそのまま保持し、異なる調査群のモデル比較として並べる。

## 4. 検証の信頼性・限界

- 最初のCI run 41035372891は**GPS位置を開く前の合成テスト**で停止。テストの2つの誤った期待値を修正したが、予測式、対象群、停止条件、比較方向は変えていない。
- 修正後の[元データ初回実行 41035508991](https://github.com/zuizui0223/boids/actions/runs/41035508991)は合成9テスト、原SHA・source-only構造監査、厳密な過去→将来予測、全4調査群の固定比較を完走した。
- [集計だけを追加表示した再実行 41035761824](https://github.com/zuizui0223/boids/actions/runs/41035761824)も成功。ログ出力のみ追加したもので、動物予測コードは変更していない。完全な匿名集計を[機械可読JSON](../validation_v30/results/four_study_holdout_v30.json)として保持。
- 4群はランダム化された独立な生態系ではなく、一つの2025年公開GPSアーカイブの異なる調査群。種構成、追跡努力、季節、地域環境が変わる。4群のbootstrapは小標本で、区間が正でもp=0.0625の符号検定と区別する。
- 本研究が予測したのは**すでに追跡歴のある鳥の翌日の水平GPS空間的広がり**のみ。新規個体の生息地選択・野外3Dニッチ・資源摂取・近隣接触・社会的Boids運動力は測定していない。個体の運動状態と測位過程の持続も交絡し得る。
- 元のGPS位置・個体ID・個別タイムスタンプ・日別の元変換値は再配布しない。v23/v29の結果は凍結したまま。

## 5. 次の独立検証に残る問い

今後本当に必要なのは、**新しいデータ提供元の集団**で、前日状態・個体履歴・実測環境・同時測位した近隣個体情報を**同じ将来予測ターゲット**へ追加し、それぞれの上乗せを比較すること。移動量だけでなく、実使用対可利用資源の情報と高度の測定誤差が揃うまで、種内・種間の3Dニッチ分化やReynolds運動係数の野外同定へ飛躍しない。
