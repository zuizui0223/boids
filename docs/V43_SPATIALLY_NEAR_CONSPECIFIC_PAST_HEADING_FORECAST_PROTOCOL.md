## Exact neighbor eligibility and source-only event descriptors

For each focal valid original 4fix episode from v40:
- Previous same-bird target segment i−2→i−1 and future segment i→i+1 share **no original fix**, original source 5–30min elapsed, 5–360min gap, all four fixes ≤25 km from public gauge.
- At the focal known start t_i, consider **other birds only** whose **latest originally observed valid past movement pair** has two original GPS fixes 5–30min apart, both ≤25km from gauge, latest endpoint at or before t_i, and elapsed GPS age in [0,5]min. This other-bird pair cannot contain an original GPS fix after t_i. Use **latest valid pair per other bird**, no cherry-picking friend.
- Distance of other bird's latest known endpoint to focal bird's current known GPS position is WGS84 haversine horizontal. **NEAR** = ≤200m, the v42 frozen primary radius, and **FAR** = ≥1000m within original 25km area. Middle distance (200m–1km) is not used for near/far direction features. A candidate near other bird's velocity is its original last two GPS fixes' spherical initial bearing E/N unit and scalar log1p speed based on source elapsed interval. Aggregate **equally over distinct other birds**, no flight-state/conspecific ranking or weights chosen by future outcome. If none, use zero vectors with **explicit availability indicators** (not falsely “north” directions). No self-bird other heading.
- Fixed **S0 context controls** on ALL original source candidate episodes, even without near: near availability 0/1, log1p near bird count, minimum near distance/0.2km (0 if missing), minimum near-age/5min (0 if missing), unit bearing from focal current position to nearest other prior endpoint E/N (zero for coincident points), *mean near bird prior scalar log1p speed*, far available 0/1, log1p far count, mean far prior scalar log1p speed. These use only original observations already available by focal time. Geometry and pace controls are necessary to avoid interpreting source-neighbor proximity/speed as social **heading** increment.
- **S1** S0 + 2 numbers: average of NEAR other birds' **past heading unit E/N**. **S2** S0 + 2 numbers: average of FAR other birds' past heading unit E/N, same timing window and a negative-control for global tide/time directional trends. **S3** S0 + both mean heading vectors. All four use identical target rows and the same trained historical original source opportunities.

Focal's actual future fix coordinates/elapsed interval are used **only to create evaluation target and original 5–30min eligibility**, never as known predictor. ## Scientific caution / actual falsification

A robust positive S0−S1 and S2−S3 with far weaker than near would be compatible with local socially relevant motion cues but **not** prove flock alignment, directed response, learned memory or Reynolds-style forces. Shared prey patch, path geometry, same environmental tide/wind, tag duty, and social selection of location/formation remain confounded. A near-heading gain that is as weak as or below far heading gives no spatially specific evidence. A null/negative gain despite adequate support is scientifically useful. If all model effects are near zero, don't rescue by choosing 100m or 1km after observing outcomes.
