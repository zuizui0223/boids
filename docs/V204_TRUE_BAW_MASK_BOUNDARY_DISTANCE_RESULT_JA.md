# v204｜真正BAW地形マスクと年別高潮・低潮線の距離：数値収録範囲の入れ替わりは境界に極めて集中

2026-11-19。v203で初めて確認した数値収録画素の2018→2019入れ替わり（有効2018年247437、2019年219396）の出現位置を、同一BAW製品の4本群の2018/2019高潮・低潮線との距離で診断した。**モデル内部のSOURCE診断であって、干潟面積や鳥の採餌機構の独立した実証ではない**。

## 二つの独立した原SOURCE取得の検証

- [GitHub Actions #44446984047](https://github.com/zuizui0223/boids/actions/runs/44446984047)・[#44447040382](https://github.com/zuizui0223/boids/actions/runs/44447040382) は実元WFS/WCS 6ファイルを再取得し、いずれもテスト＋original source gate成功、**全画素分類・距離帯・四象限の元数値集計が完全一致**。
- 原Source-safe archive ZIP SHA：run44446984047 `0bd67e6398eb90f7107fb402fe7d25afc7d4674076019eddc7473e62f6c89c75`、run44447040382 `218e8d2eb1edf8067c1c092d13589545b098675d68fdc20e92334bccf02c7ae1`（異なるZIP自体には異なるメタデータが含まれる）。両元ZIPを入手してハッシュを計算しGitHub artifact digestに一致したことを確認。
- 元WCS GeoTIFFの2018/19バイトSHAはv203完全一致：2018 `3630b3a732efb79bc5a85a6d1c8bc0c63cff992783ca86142360837cd318ba4f` / 2019 `e666c271b3d3cab98aaa8d0ca7ba3c076b7bd363036f9a15e58593ffa8994e37`。
- 元GeoJSONの**HTTPバイトSHAは毎回違う**ため、これを原地物の同一性と誤解しない。元GeoJSONからトップレベル`timeStamp`のみ除いたcanonicalized semantic JSON SHAは**2回のsource再取得で厳密に一致**（一つのfeatureも除外しない）：
  - 2018 HIGH: `1fb2f96b9c559a49a40a40e345c9a630d2643bfb06ba54902f620fb50fb707f9`
  - 2018 LOW: `e8247c65a22e7decc019a5b706ad3ab666152061eb0db27a73874193b1c139d5`
  - 2019 HIGH: `9ac711f144d29d1aee1d3721b558798a14beec4907f1e384891fee6dd1e38c0d`
  - 2019 LOW: `da2ea308e61ad3a82cab6e0d32654ef45dc8a4cb035247b332d4489ac9e954a1`.
  バイトSHAの相違原因は原source文字列の変動と整合的だが、同一性を保証するのは上記内容ハッシュと元geometryのclip長・件数である。

## 元SOURCEオリジナル数値

面積1e6×(10m×10m)の固定10km²ではなく**10km×10km=100km²**範囲における画素数：
- 2018のみ有効（翌年無効）**31,850**
- 2019のみ有効（前年無効）**3,809**
- 両年有効 **215,587**
- 両年無効 **748,754**。
全クラスの和は1,000,000。原v203と完全一致。

元2018＋2019のHIGH/LOW線合計4カテゴリー（実元WFS117 curves）を同じWCS10m格子へ`all_touched=True`ラスタ化し、距離変換した。線が通るセル29,569。この距離は原線に対する約10mのラスタ近似。

従って「消えた」31,850元画素のうち、**境界100m未満に31,433（98.69%）**、50m未満に28,852（90.59%）。「新たに現れた」3,809元画素のうち100m未満に3,799（99.74%）。距離500m以上の2018年有効27,407セルに対し翌年無効0。**遠方リスクが0なので、100m未満/500m以上のリスク比は定義しない（無限大と誇張しない）**。

近傍100m未満では元2018有効132,159画素中31,433が翌年無効、23.784%の固定SOURCE条件付き頻度。これは年次モデルマスクの処理条件を反映する可能性が高く、生き物の採餌可能率ではない。

四象限（元100km²範囲を機械的に4分割）の2018のみ有効 lost:
- NW 910, NE 3,846, SW 9,448, SE 17,646。東南の源マスク変化が大きいが、現地侵食であることは未検証。

## 科学的な保留条件

**成功と言えること：**同じ公表BAWモデル製品の年別数値マスクの入れ替わりが、その製品の高潮・低潮線に非常に近接するという再現性ある空間パターンを示した。原ローカルSOURCEは2回取得・ハッシュ検証済み。

**成功と言えないこと：**真の干潟が2018→2019に2.80km²減少、年間採餌面積が減った、鳥の行動が変わった、局所浸食が進んだ、等は今回の検定からは言えない。**水位境界線も地形マスクも同一BAW製品由来**なので両者は独立ではない。境界線に集中する結果は製品の潮間帯定義・クリッピング/マスキング規則そのものを診断している可能性がある。

もともとのミヤコドリ2018fit→2019test（v169）実測水位高さによるACC追加予測利得+0.007430798 MSEは別の観測的結果として保持。原GPS実地点での模型h(s,t)、元20m DEM true survey day/vertical datum、餌量・採餌成功、潮汐×太陽/Boidsの真の機構はSOURCE STOP。今後の**年別干潟面積**はこの`topography_inter_supratidal`の有効値マスクを使わず、native high/low boundariesの海陸側トポロジーと正確なモデル基準を独立に校正して定義すべき。
