**Added 2026-10-31 JST after the official source-only WATHTE catalog/1-day astronomy and measured tide checks, but *before* retrieving any full-year tide numeric curves or joining them to v32 animal daily outcomes.** This is a post-v32 exploratory tide comparison.

Seven complete UTC years 2008–2014 are mandatory, with one adjacent-day boundary buffer. Request each year in the fixed Dutch winter UTC+01 offset, parse returned timestamps as offset-aware datetimes and convert to UTC. No ad hoc timezone shifts. Return `SOURCE_NOT_ADMITTED` if any calendar-year 10-minute tide series lacks ≥95% expected observations, wrong site/units, invalid names or whole-year missing data. Exclude RWS missing code 99, non-finite height and absolute height >10 m (implausible/explicit sentinel), no interpolation. Daily UTC tide range `T_d = max(h_t)-min(h_t)` (m) requires ≥116 of 144 original 10-minute slots and at least 18 valid slots per 6-hour UTC quadrant; each original animal forecast event requires T(t), T(t−1), else it is not environmentally matched.
- Main tide feature **fixed before effects:** `z_t=T_t−T_{t−1}` in meters, the day-to-day change of astronomical tidal amplitude. No alternative model chosen after score opening. Baseline `MH=(MP+MI)/2` **from unchanged v32**, extra tidal predictor `MH_T=MH+β_{t−1} z_t`; fixed ridge `β = Σ_{date<t}(z_i(y_i−MH_i))/(20 + Σ_{date<t} z_i²)`. Warmup requires ≥100 earlier original bird-day targets in the tide-complete history; before warmup set β=0 for BOTH models (identical forecast) and retain all eligible targets. **All predictions at the same UTC day t are produced before any day-t outcomes update β.** No fitted intercept or tuning of regularization after outcomes.
- **Primary fixed comparison** `MSE(MH)−MSE(MH_T)`, positive if tide adds day-ahead predictive information to the fixed previous-day+history model. Score only matched common future bird-days; if less than 30 original birds, fewer than 6000 matched forecast days, or fewer than 6/7 complete tide years, STOP with source/eligibility diagnostics and no tide effect. To isolate tide from calendar, **secondary** two normalized ridge models with features (intercept, sin(2π DOY/365.25), cos(2π DOY/365.25)) vs those plus z_t, all trained on only earlier dates with fixed diagonal regularization 20, same warmup; report mean MSE difference seasonal-only vs seasonal+tide. Include the original MH absolute MSE for matched days. No target-day animal-fix count or measured future tide can enter a forecast.
- **Falsification**: fixed "placebo" tidal range change with +7-day offset in the external astronomical tide series (known orbital forecast); report gain vs MH with identical target-days and ridge, no reselected offset. A true tidal mechanism should be interpreted cautiously if arbitrary shifts work similarly. Note this test is not independent environmental replication.
