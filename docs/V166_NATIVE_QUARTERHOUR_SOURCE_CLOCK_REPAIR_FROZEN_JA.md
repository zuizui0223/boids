# v166：ミヤコドリ直前15分SOURCE時刻の定義修正（モデルを変更せず再実証）

2026-11-16。先行v165の真正2018 Vlieland GPS/ACC×実測RWS元SOURCE再取得は成功し、元v130の**193,088個体×15分観測bin、35標識鳥、17 ISO暦週、6–9月、4期間の実潮位と偽潮位の完全同時SOURCE**を再現した。一方v165では「同鳥のイベントUTC時刻が厳密に15分前」の一致検索により**1,904個体×bin（元の0.986%）**だけになり、結果を開く前に固定したSOURCE≥25,000に届かず**新しい潮汐効果はSOURCE STOP**した。元のv165バージョンと停止レシートは保持し、科学的な結果が出なかった事実を削除しない。

## 本当の原因は採餌自己状態ではなく、時間キーの型の取り違え

v129元コードの正規化器で、各私有元ACC×GPSレコードの辞書キーは **(tagged bird, native UTC 15-minute bin start)** だが、v130へ渡された 'source_utc_event' は、そのビン内で**最も早く記録されたACC分類イベントの実時刻**。元コードは各元イベントについて**bin start ≤ earliest event ＜ bin start+900秒**を確認した上で保存した。したがってv165のイベント時刻を正確に900秒ずらすことは、真の連続した15分ビンの確認ではない。**1,904という少数値を「動物の連続観測がほぼ無い」という生態学的事実にしてはいけない。**

今回の修正は SOURCE時間インデックスだけ：
1. 各元イベントが正規化UTCであることを確認し、その時間を**15分幅のUTC境界へ切り下げ**て元native bin startを再構築。
2. 同じ実標識個体×再構築bin startが重複しないことを全193,088元観測で確認。元イベントのビン内位置について、median/p05/p95を匿名SOURCE QCに記録。
3. 同鳥の**一つ前の本物の15分ビンがSOURCEに存在**する場合だけt−15minの行動分類状態を説明変数とする。ビン間は正確に15分だが、各ビンの実元最初のイベント同士の間隔は必ずしも15分ではない、と明示。
4. 前binと現binは同じISO週、GPS/ACCソースが同時に揃っているという元v165のSOURCEゲートを保持。存在しない元ビンは無行動として補完しない。
5. 元v165のSOURCE合格閾値**25,000**、20羽・12週・4月・五分割全週・昼夜15%、元モデル全7種、Ridge λ=20、元実測RWS潮位＋+3/+7/+11日の誤時刻、週×鳥の等重みMSE、10,000週再標本化を一切変更しない。
6. SOURCEゲートを通れば同じBird×15分binの保留週における自己前binの観測分類値を用いた**オンライン条件付き分類nowcast**を初めて比較し、ゲートが通らなければ再びSTOPとして保持する。

## 主検定

- SOLAR に加え **同鳥の直前1ビンで実際に観測した採餌分類事象比**の追加予測。
- 直前1ビンの状態も説明した後に、**正しい港湾実測潮位**が追加する予測情報。
- 同じ観測対象・同じモデル複雑度で、真のRWS潮位 vs **3・7・11日ずらした本物の潮位**のどちらが保留週で優るか。

既にv130では時計+天文昼夜の上に港潮位を加えることで強い予測改善を確認した。ただし同一2018年の同一個体／同一地理を使った事後のSOURCEロジック修正であり、独立の前向き確認試験ではない。どちらの結果でも、干潟の実際の冠水や獲物量・真の摂食行動・同種個体間のBoids凝集／整列／分離力は測定できない。今回のYは**ACC分類イベント割合**に限る。
