## 生態学的問い：環境の「値」が同じでも「これからの変化」は違う

同じ潮位でも上げ潮と下げ潮、同じ天文日長でも伸長期と短縮期がある。局所的に利用できる餌や環境状態を `R(x,t)` とすると、将来の状態は短い時間 `tau` に限り `R(x,t+tau)≈R(x,t)+tau*dR/dt` と表せる。生物の次の移動・時間利用が`R`の現在値に加え`dR/dt`や到達可能な別の`R`に依存する、という**動的機会仮説**を今後の共通の主線とする。**従来の動的step-selection研究に近い考えであり、新規性は数式だけではなく独立した環境周期・分類群への厳密な予測的転移と、その成否を説明する条件に求める。**

`M0 = 自身の移動履歴＋位置・時刻＋環境の現在値`、`M1 = M0＋独立計測の変化率（符号・強さ）`、`M2 = M1＋到達可能な代替生息場所の状態とその変化`。GPSの次方向、活動時刻、利用水深は**異なる応答変数**なので、同じ数値効果として平均しない。独立の原潮汐周期・個体・研究年・地域・種を必ずホールドアウトし、時計だけから推定される位相を入れた見かけの利得と、元の時間自己相関を保った対照位相を区別する。

### 2. 陸上動物の日周・季節：時間利用の構造は広いが、符号は一様でない

RSDSに保存済みのMD5検証済みMovebank元12研究を、**12公表DOI・22原研究×native taxon行・20学名**の既存結果から再監査。夜−昼の観測GPS直線変位速度差`q`は**9/12研究・15/22分類群行**で支持され、元個体bootstrap95%が**正4・負11・未推定7**。原研究DOI均等平均は**+0.010262**だが、非無作為元研究の記述的研究ブロック95%区間は**[−0.049232,+0.076742]**でゼロを含む。これは「全生物が夜または昼のどちらかに一様に移動する」という方向的普遍法則が支持されないことと、同時に選定されたサンプル内の多分類群に時間的移動差があることの両方を示す。GPS変位速度は活動時間割合そのものではない。

### 3. 同じ天文日長・異なる季節側：撮影記録には違いがある

RSDSのセレンゲティ原カメラ監査では、実際の元カメラ**186地点・24,290地点×日付対応**のほぼ同日長の伸長側／短縮側について、合計**38,792記録写真・43元taxonラベル**を整理。15ラベルが固定撮影数の表示基準を満たした。日長が近くても**元の撮影時刻**に種による差があり、例えばハイエナの夜／昼比の短縮期対伸長期Mantel–Haenszel ORは**2.6284**、トムソンガゼルは**0.7917**だった。これは異なる生物学的応答と整合する**観測現象**だが、稼働時間とqの確認がないので、真の動物の日周活動量・個体の記憶・季節の因果効果は同定しない。186地点は**1景観内のサンプル**であって186独立生態系ではない。北アイルランドの別景観も原13地点×年・353イベント選択日ペア/988撮影行で、独立の活動量追試には支持が不足。[RSDS元観測的報告](https://github.com/zuizui0223/RSDS/blob/main/docs/solar_seasonal_real_exploratory_results_20261015.md)。

### 4. 水環境の局所的な保持：動物は必ずしも環境変化を追って大きく移動しない

louisのLake Erieクイナ（King Rail）の独立の元湿地研究では、**10/10羽で時間的な利用水深・状態の保持**が見られ、同じ地元の利用可能水環境と同時刻に取った対照の結合傾き**1.001**に対して実際の利用状態傾き**0.162**、**83.8%小さい**。これは動的な環境への応答が「一方向へ移動すること」だけでなく、到達可能な代替状態を使って**経験する環境を保つ**という形でも現れる可能性を支える別の指標。ただし同じ潮相予測指標・同じ種・独立追試ではなく、元イベント座標結合の未解決のため厳密な地理的原因は未確定。[元louis](https://github.com/zuizui0223/louis)。

## 普遍性の証明まで残る検証

現段階の主張上限は「**複数の実測系で時間・環境状態に関連する利用の非一様性があり、位相の向きと行動応答は条件による**」である。**異なる種・異なる環境周期に同じ動的位相モデルの年外予測利得があるという普遍法則は未実証**。次は元ソースに対応する**同じ観測尺度・適正な時間間隔・独立の位相微分・達成可能な状態の分布**を揃えた別分類群で、既存状態＋時計＋個体運動履歴のM0に`dE/dt`と可到達な代替環境を加えたM1/M2が独立な元潮汐周期・研究年・種・地域で正のproper-score増分を生むか検定する。無観測・HOLD・負の結果も含め、原研究DOIを独立単位とする。

独立GPSホールドアウトのなく、単に過去の肯定的な相関表を「共通係数」としてプールした論文は作らない。社会的Boids力は同時刻・近接個体の位置・速度が原本で観測された時に限って別個に検定する。
