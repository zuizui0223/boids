## General identity: environmental mean and probability of being in mapped habitat

In every genuine original bird (i) × calendar month (m) × actually measured Rijkswaterstaat height band (h) × four true flood/ebb × solar day/night category (c), define:

- (Y_{jc}=1) iff the original true 2010 oystercatcher GPS bird location (j) is within WMR `litoralcode` **3 or4 mid/high** (using its nearest actual NIOZ native grid index ≤300m), (Y=0) otherwise (including low tidalflat class2, whose v1-v2 correction is uncertain).
- (R_{jc}): the **original monthly NIOZ `time_expo` model native cell ordinal midrank relative to ALL original model cells within genuine fixed 1km radius of that same GPS position, minus 0.5**; exactly the original prior v82 response, **unknown physical model units**, not measured hours or prey. **Do NOT use habitat-restricted v85 1km background**, whose full-four-cell source did not admit.
- (p_c=operatorname{mean}(Y_{jc})), (mu_c=operatorname{mean}(R_{jc})); pooled within this four-cell source stratum take (mu_{in}^0=operatorname{mean}(R_j|Y=1)), (mu_{out}^0=operatorname{mean}(R_j|Y=0)) **over all four condition cells pooled**, with **equal original GPS position weighting for these two pooled reference means** (do not first equal-weight four cells for the baseline). If one class never observed across a stratum, define both baseline means to equal pooled grand mean and label as **no two-class support**. No source is dropped for missing one class; source denominators/missing support counts are published as anonymous aggregate only.
- The tide×solar four-cell contrast operator (mathcal D(z)=z_{flood,NIGHT}-z_{flood,DAY}-z_{ebb,NIGHT}+z_{ebb,DAY}).
- Define **mixture/entry descriptive contribution** (D^{comp}_{imh}=(mu_{in}^0-mu_{out}^0),mathcal D(p)).
- Define **conditional covariance/residual contribution** (D^{resid}_{imh}=mathcal D(mu)-D^{comp}_{imh}), which can also be written (mathcal D[p_c(mu_{in,c}-mu_{in}^0)+(1-p_c)(mu_{out,c}-mu_{out}^0)]) wherever individual class conditional means exist. Never mislabel the residual a statistically independent experimental 'within-habitat selection effect'; it includes joint changes in within-class ranks and composition×rank differences. Exact **(mathcal D(mu)=D^{comp}+D^{resid}) to machine precision for EVERY genuine original 4cell group**, even with absent one class, and because the bird/month hierarchy is linear also for bird/site means.
- **No arbitrary ratio `Dcomp/D_rank`** as a primary effect because denominator may be near0, especially Ameland. Original ecotope class Y not an actual GPS-foraging observation; NIOZ model local rank is ordinal and not an independent quantitative resource measurement.
