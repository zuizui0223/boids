Source-only v25-B3 verified **190,289 exact `birdyear × timestamp` pairs**, each with exactly one `case=TRUE` and one `case=FALSE` row (two rows per pair, not 101 alternatives), 493 original birdyear identity tokens (NOT necessarily 493 distinct perennial birds), four taxa (GWFG,LSGO,MALL,NOPI), 3 source seasons and two photoperiod classes. Original case FALSE is an **aggregated source-author alternative habitat profile estimated from simulated moves**, not a true candidate destination; source movement kernel may have been built from all birds including target birds. There are no source original start GPS coordinates in the 13-column CSV. Therefore neither actual conditional choice among 101 destinations nor operational ex-ante next-step movement is identified.

## Fixed unit correction and scientific measures

- **Only difference from original v25-C numerical modeling:** convert **ALL** original `Corn,Field,Other,Protected,Rice,Urban,Wetland` raw integer percentage values from 0–100 to 0–1 by dividing by precisely 100, with no winsorization, per-column scaling, min-max, target-dependent transformation or preference-optimizing selection. This rule was registered before raw source numeric min/max were read, and shown to pass independently.
- Every other v25-C original fixed rule remains: two original rows per birdyear/time, source category equality, true/failure source gates, within-birdyear sorted timestamps, **3 earlier paired observations minimum** to score later pair, exact 5 deterministic **whole-`birdyear` SHA256-mod-5 folds** and no test birdyear in training, heldout calendar-year ecological transfer, seven unchanged habitat-difference predictors `d=TRUE-FALSE`, original source no-intercept L2 mirrored-difference logit C=1, liblinear max_iter400, birdyear-equal source training weights, fixed `n/(n+2)` personal shrink without tuning.
- Four fixed models scoring the SAME eligible `birdyear × timestamp` profile pairs: M0 uniform surrogate `ln 2`, M1 other-birdyear population logit on seven habitat differences, M2 species interactions with same L2, M3 M1 blended with strictly EARLIER individual-birdyear mean profile-difference unit direction and `w=n/(n+2)`. Future paired response habitat data are never added to M3 before scoring that exact time.
- **Primary M1−M3**: does personal prior habitat-profile direction reduce retrospectively defined paired used-vs-aggregate-availability log loss beyond environmental population history? Registered secondaries M0−M1 ecological baseline transfer, M1−M2 species-specific habitat interactions and M0−M3 total.
- **Pseudolikelihood, NOT a real choice probability:** for heldout paired profile difference d, surrogate `log(1+exp(−β·d))`, baseline ln2. Paired-profile "ranking" is 1 if score >0, 0.5 at exactly zero. A single FALSE row is an aggregate of originally simulated destinations, not one independent selected wetland.
- Original **birdyear** is the unit for all per-group equal-weight errors and 10,000 whole-birdyear bootstraps, seed **20261029**; report all ≥100 source birdyears and ≥1000 eligible future profile pairs or STOP. No significance from 380,578 IID point samples. All four species and original calendar years must be reported even if some signs are negative; first three source pairs used only for history. Include all year-holdout M1 scores, without choosing favorable years.
