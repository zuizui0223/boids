# v39 — Conditional past-activity predictive information under the same astronomical tidal state

**Freeze date:** 2026-10-31 JST. This is an **exploratory, after-v33/v34 and after-v37/v38 mechanism construction** analysis of the ORIGINAL previously opened Schiermonnikoog GPS, **not a new independent bird study or preregistration before source observations**. The purpose is a genuinely outcome-falsifiable *time-forward held-out* predictive comparison: does private past movement contain predictive information beyond a relatively flexible instantaneous tide × phase, clock, location, bird identity and GPS observation regime model?

## Sources (unchanged provenance)

- Full original `O_SCHIERMONNIKOOG` Eurasian oystercatcher GPS, Zenodo **10053970** v4, all seven years **2008–2014** and all seven MD5/SHA pins from frozen v32, with v33-D source rules: original visible, manually marked outlier, original UTC, all exact bird×UTC duplicates excluded, valid lat/lon. No extra cohort or response optimization.
- Original Rijkswaterstaat **`schiermonnikoog.waddenzee`** astronomical `WATHTE`, cm relative NAP, all seven UTC years 2008–2014 and original explicit +01:00 conversion. Use **astronomical** water level known in advance, never observed future measured storm level.
- Retrospectively match original GPS only for step pairs with **both endpoints ≤25km** of public Schiermonnikoog gauge, original elapsed time **[5,30] minutes inclusive**, plus a prior source pair formed by fixes `i−2→i−1` (also 5–30min and ≤25km), before current target pair `i→i+1`. The two pairs must **share no GPS fix**; gap `t_i−t_{i−1}` must be **[5,360]min**. If current pair ends after start of the next calendar block, it is scored in the block of **start t_i**; never train on any label whose start is in the 7 days immediately before a test month. No source interpolations, no optimally chosen time gap.
- New target is `y=log1p(haversine(start,end) km / original elapsed hours)`; only the **source-defined next observed GPS step** is scored, not a free-running 10-minute trajectory. The source provides the actual future interval only **to define the evaluation cohort and response**, NOT as an ex ante predictor. Therefore operational use is conditional on the future original GPS schedule matching [5,30]min; do not call it full prospective all-fix prediction. Track exclusion counts and source support. Do not drop high speeds after observing their outcomes; log transform and quality reports handle tails.

## Preventing trivial GPS measurement-error carryover

The behavior-memory predictor is `y_{i−2,i−1}` for this same bird, whereas the future target is `y_{i,i+1}`; **no GPS point in the two segments overlaps**. Both predecessor fixes occur before the forecast start. This prevents one simple shared-position displacement artifact, but same device duty, local patch and correlated GPS errors can remain.

## Fixed baseline and four models on identical future steps

**Fixed predictors for all models E0..E3**, all built at original *target start* time t:
- H(t) in meters, central-difference astronomical `dH/dt=[H(t+30min)−H(t−30min)]/1h`, `H²`, `(dH/dt)²`, `H×dH/dt`, `|dH/dt|`, exposed_fraction **only as analytic v38 toy basis** `clip((1.25−H)/2.4,0,1)`, and v38 explicitly post-field `sign(−dH/dt) tanh((0.5−H)/0.3)`. This last feature ensures a direct memoryless tide×direction model is expressible, but is **not** a measured dry-mudflat fraction.
- UTC hour-of-day sin/cos at 24h and 12h periods, annual day-of-year sin/cos, `year−2011` trend, current WGS84 location scaled relative to public gauge (latitude,longitude and their squared/cross terms); original source bird identity dummy intercept with fixed L2 shrinkage.
- Known prior GPS scheduling controls `previous interval minutes/30`, `gap since previous pair endpoint/360min`, both observed **before t**. Never put actual future target interval, actual next location, or future observational tide into features.
- **E0**, baseline instantaneous tide × phase + clock/season/location + own-bird intercept + past GPS recording schedule, but *no earlier speed or earlier tide values*.
- **E1**, E0 + **last disjoint same-bird recorded step log1p-speed**.
- **E2**, E0 + external **astronomical H and dH/dt from exactly t−3 hours** (pre-known deterministic forcing, no animal-memory predictor).
- **E3**, E0 + both E1 previous private speed and E2 previous tide. E3 vs E2 is secondary private-history increment after environment history; E1 vs E0 the **one registered primary**.

Every model fits ordinary **fixed ridge α=25**, with nonpenalized intercept only and fixed physical feature scales (no normalization on test). All models use identical eligible target episode rows. The original direct v38 handcoded coefficients are **NOT** reused or optimized; this is an observational predictive ridge, not a causal parameter estimate of the toy speed law.

## Strict held-out chronological scoring

- Source GPS rows may be parsed once, but **training outcomes in month M must have target start time < first calendar day of M minus 7 days**. Test in chronological **original UTC calendar months from 2010-01 through 2014-12**. Precompute sufficient training statistics only from rows before the cutoff. Never use any outcome from the current month, future months or preceding 7-day embargo. All end-of-step outcomes required for training must also end before the cutoff. The test predictor's disjoint earlier pair can be from the same month but its **end** is strictly before current target start (like actual real-time device history), and was not used to fit model coefficients.
- A month may be scored only after ≥**5,000** prior eligible scored-like episodes from ≥**10** different original birds. Months without sufficient training **STOP that month**, report counts, never change burn-in. All four models trained on the same available historical rows and scored on the same target episode population.
- Primary common support for an aggregate score: ≥**20** original test bird IDs with ≥**30** held-out step episodes each, ≥**10,000** scored original future step pairs, spanning ≥**3** different calendar years, ≥**12** scored UTC months. Report all other low-support birds (source-safe aggregate count) but do not weight them as equal birds in the primary effect. If the support is insufficient, emit `NOT_ADMITTED` with source/target counts and **no model MSE**. No lowering thresholds after inspecting the source.
- Compute error by *original bird* across all its held-out episodes, then equal bird weight. Primary signed gain `MSE(E0)−MSE(E1)` (positive if earlier disjoint private movement adds future-prediction information). Preset secondary `MSE(E0)−MSE(E2)`, `MSE(E2)−MSE(E3)`, `MSE(E1)−MSE(E3)`. Report **all** absolute errors, all signed contrasts including failures, counts of birds with positive effect, 10,000 paired whole-bird bootstrap with RNG seed **20261031**, exact one-sided bird sign p. Descriptive **all calendar years**, and *equal-calendar-month/annual block uncertainty* to diagnose shared tidal/weather conditions; this is one original coastal source, not independent 20+ habitats.
- A substantial positive primary identifies **conditional private past-speed predictive information within the fitted model family**, not cognitive memory or a causal state transition; a flexible environmental/spatial model, unmeasured weather, feeding patch, GPS tagging duty and animal health may explain the same signal. Null does not prove a memoryless cause.
