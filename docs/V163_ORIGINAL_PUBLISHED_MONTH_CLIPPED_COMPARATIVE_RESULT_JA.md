## 4. 研究上の解釈と優先順位

**支持**：複数のクリック陽性SOURCE SITEで、直前1hのbuzz状態が、元の暦・時刻とクリック検出量に加えて、**他SOURCE SITEへ移す**際の予測情報を持つ。これはICEの13地点、SWEの掲載月のみ5地点、RWBの2地点などに残る。

**反証／上限**：同じSITEの別暦年へ移すと（特にSWE）、効果はほぼ消える。この対照で残らない以上、v160の地理的なパターンを「全球に共通する持続性の生物学的法則」と言うことはできない。SOURCEコホートが限られ、個体別ではなく音響機器のdetectabilityと地域・採餌行動の環境が混じる可能性を残す。

**メタデータ未解決**：論文のHONOは2022-10〜2023-09だが元CSVには2015〜2018年のSOURCE記録も存在。後者の誤り・別のデプロイ・旧ラベルかは公開元だけでは断定できない。現段階は、v162の保守的SOURCE全除外とv163の掲載月内保持の**両方のSOURCEルール**を固定して併記する。論文Table A1の公開年月を越える原C-POD取得歴の台帳と個体／センサIDによる追加照合を将来の真の解決条件とする。

**潮汐×太陽との関係**：本v163は潮位・潮流の実測を全43地点へ対応していない。元論文ですでに日周・季節・日長・海況の関連が調べられており、ここから新しい潮汐×太陽の全球効果量を作成しない。魚の音響とネズミイルカのC-PODクリック陽性条件付き採餌buzzを同じ生物学的なMeta効果としてプールしない。Boids社会的な整列/分離/凝集にも未接続。
