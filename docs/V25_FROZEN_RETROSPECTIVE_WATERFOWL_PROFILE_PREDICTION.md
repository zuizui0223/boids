## Input domain, exactly registered before numeric source opening

- For **each** of the seven exact environment fields `Corn,Field,Other,Protected,Rice,Urban,Wetland`, require finite numeric values between **0 and 1 inclusive**, and **zero source missing values**, both in used TRUE and matched FALSE profiles. If any value violates these published habitat-composition expectations, STOP without fitting, rather than adapting scaling after positive/negative results.
- All `birdyear × timestamp` pairs must be exactly complete TRUE/FALSE as registered. Both halves must have identical species, source season, photoperiod and timestamp. `birdyear` is a **bird-year token**, not externally certified stable permanent animal ID across different years. Treat equal-weight **birdyear** as statistical unit and never call 493 tokens 493 independent animals or field ecosystems.
- Habitat pair feature `d = x_TRUE − x_FALSE` in original 7 unit-scale source fields. These two vectors are known only as retrospective source used-vs-generated-availability summaries, not as before-transition alternatives. No GPS coordinate, wetland ID, step-start or detected food intake.
- Eligible test stratum: after at least **three** earlier dated original matched pairs *within the heldout birdyear*, to support personal history from strictly past original `d` values. All four models score exactly same source stratum; original first three pairs are history only, never preferentially added if model scores improve.
- Source pre-outcome hard gate: ≥100 distinct original `birdyear` tokens each with ≥4 source pairs, and ≥1,000 eligible later source pairs. Date ties must not be used to update history before scoring each same-time step (source has exact one pair per time).

## Four fixed models and heldout units

Five deterministic **whole-birdyear** holdout folds by `SHA256(UTF8(birdyear)) mod 5`, fixed before any habitat numeric scores. Other birdyears' full original source are training data and may include later calendar dates than heldout test birdyear; this is therefore **cross-birdyear retrospective transfer** rather than strict across-study-calendar future prediction.

- **M0 uniform:** source TRUE-vs-FALSE paired-profile surrogate log loss `log(2)`, tie ranking score 0.5. A retrospective source classification null, not biological 50% choice probability.
- **M1 environment common:** L2 logistic no-intercept on signed original habitat differences; for each training pair create `+d` label 1 and `−d` label 0. Fit original seven profile attributes with scikit-learn `LogisticRegression(C=1.0,fit_intercept=False,solver=liblinear,max_iter=400,random_state=20261029)`. Per original training birdyear, total weight exactly 1; within each paired record total balanced positive/negative half to avoid steps dominating.
- **M2 environment + species conditioning:** identical M1 seven differences plus 4 one-hot `species × d` interaction vectors, same solver/regularization/training-only species encoding. Species identity alone is constant across paired original TRUE/FALSE and is NOT a legitimate direct discriminator.
- **M3 private history + environment:** for a heldout birdyear with n≥3 prior recorded pairs, history direction `m_{i,t}=mean(d_{i,s}:s<t)`, and source beta from M1 on OTHER birdyears. Fixed personal coefficient `beta_private = ||beta_M1|| * m/(||m||+1e-12)`, zero if history norm=0. Fixed historical weighting `w=n/(n+2)` from v20/v22/v23, with `beta_M3=(1−w)beta_M1+w beta_private`. No posthoc fitting of w or personal scale on original test responses. **Only earlier same-birdyear used/aggregated-available profiles contribute to m.** M3 tests predictive repeatability of habitat-profile differences, not cognitive individual memory.
- M3 does not get a preview of any current source TRUE/FALSE or later `d` value while building history. All model scores require current target two habitat profiles to evaluate their retrospective ranking; these current source covariates are **not available before a real step**.
- Absolutely no use of source `birdyear` or timestamp as a model direct habitat covariate. No original habitat values or precise source timestamps/animal ID tokens redistributed.

## Fixed scores and source-group-level uncertainty

For eligible paired source stratum with `d`, all models' signed score `s=βᵀd`; paired surrogate log loss `logaddexp(0,−s)`, score of M0 `log(2)`, pair-ranking accuracy 1(s>0)+0.5(s=0). Average across all eligible source pairs per **original heldout birdyear**, then equal-birdyear means. Primary `G_private = loss(M1) − loss(M3)`: positive means fixed personal history improves over common environmental profile. Registered secondaries `loss(M0)−loss(M1)` (common environment transfer), `loss(M1)−loss(M2)` (species-specific interactions) and `loss(M0)−loss(M3)`. Present **all** signs and negative outcomes.

Whole-birdyear bootstrap 10,000 resamples, random seed 20261029, show 95% percentile interval and positive count, full original four species/three seasons/day-night support. A simple sign binomial is descriptive only because original birdyears can repeat biological individuals and share annual environment. Source timing evaluation includes original year counts and fixed leave-one-calendar-year-out *M1 only* environment model, for all original years with >0 eligible test birdyear targets and other-years sufficient training. Source year and birdyear are not independent country/region replicates.

A paired-profile loss is **not** genuine choice among 2 real wetlands; the FALSE profile is already an aggregated counterfactual availability estimate, and original selection options are from full-data simulated movement. Therefore even a strongly positive result is evidence ONLY of out-of-birdyear predictive structure in original paper's generated habitat-use comparison, NOT direct natural resource memory, private Boids force, niche partition, actual future GPS position or environmental causal risk.
