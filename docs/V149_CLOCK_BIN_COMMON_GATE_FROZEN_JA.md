# v149：同一日内の時計時間帯を細分化した魚類コーラス共起の原本検証（事前契約）

日付2026-11-15。**v145–v148の組別結果を見た後の探索的診断**であり、独立の確認実験ではない。

## 問い

v148の「同日×太陽昼夜」ではBocaccio×UF440の録音共起超過が6/6サイトで残ったが、同日の夜間でも「19–21時の集中か、深夜か」の細かな時間選好を維持していなかった。ここで同一日内の時計時刻を**6時間、4時間、2時間**の非重複幅で固定した、二音型の時間内陽性頻度から得る独立期待値を比較する。

全て同じ**元録音60ファイル・9地点・2018–2023年・136,032時間**。v145と完全に同じ元の連続7日+で完全24時間がある日のみに固定する。

- 窓24時間：v148の同日帰無期待値を再現する。
- 窓6/4/2時間：同日×現地時計時刻ブロック別A/B陽性時間を保持し、E = Σ(nA·nB / n録音時間)を計算する。
- 窓1時間：Eは観測Oに**数学的に一致する（飽和モデル）**。これは必須のコード整合性チェックであって、「全て時刻で説明された」という生態学的結論には使用しない。
- 全90サイト×音型組と320地点×年×音型組の元Oは完全一致を要求。v148の同日期待値も再現。年別の全Eを合計するとサイト全期間値に一致。
- 全90組を確認して、元v145で適格だったBocaccio×UF440とWhite Seabassとの2組を**説明用（結果既知・事後選択）**に提示。新規検定やp値を生成しない。

## 解釈の上限

- 6→4→2時間への細分化で残差の符号・強度が変わるなら、日内の時間的集中が見かけの共起を作る可能性と両立する。
- 2h帯でもO/E>1でも、長時間の発声持続や音型別の正確な時刻選好、潮位、底層水温、波・船舶騒音と録音可聴性は未調整。条件付き独立帰無はコーラスの連続性を保存していない。
- 窓幅でモデルの期待値は単調に増減するとは限らない。Eが変わる量を環境・社会的因果寄与率へ変換できない。
- 音響ラベルUF440は魚種同定済みではなく、魚個体の相互作用やReynolds型Boids係数を推定できない。

## 検証方式

- 原60XLS(X)個別SHAをv142と照合。v145時間・v148のOと同日Eを固定検証。
- \`python -m unittest discover -s validation_v149 -p 'test_*.py' -v\`
- 初回 \`python validation_v149/v149_clockbin.py --emit\` で元データから全90+320集計と、小さい**source-safe receipt**を生成。全件のJSONはGitHub Actions artifactへ。CIログのreceiptと照合後、小さいJSONだけGitHubにコミットし、\`--check\`で再現テストを強制する。大きい集計をコネクタ経由で転送すると文字列破損のリスクがあるため、それを避ける。
- independent_coast_effects=0、global_tide×solar_effect=NOT_ESTIMATEDを維持。既存v145–v148は不変。
