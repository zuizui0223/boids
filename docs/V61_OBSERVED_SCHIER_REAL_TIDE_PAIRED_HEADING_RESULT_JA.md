- Schiermonnikoogの原本ミヤコドリGPS：2010年**7,911区間・21羽**で、同じ個体重み付きridge λ10 2D進路モデルを学習。2011年**4,948移動区間・13羽**を一切再学習せず評価。旧v43年外全体モデルを元のまま再現。学習年・評価年の個体識別子の完全分離は未要求。
- 出版者MD5と固定SHA256を検証。RWS公式 `schiermonnikoog.waddenzee` 実測潮位2009–2011年、各52,561件NAP時系列を検証。
- v59凍結の次進路を見ない対応：実際の満ち潮と引き潮を同じ鳥・1km格子・潮位差15cm以内・別日・季節・時刻・直前運動で対照した**211重複のない実測ペア**。全7段階の候補件数(1784 → 1294 → 1276 → 969 → 572 → 277 → 248)を再現。元の13羽のうち**10羽に対応ペアがあり、うち7羽は10ペア以上**。45週、12か月。対応ペアを持つ10羽すべてを等しい重みとした。1羽あたりペア数は1〜48、中央値17で、少数ペアの鳥も存在する（重要な感度分析課題）。
- 実測対応状態の平均差：水位 0.07376m、季節 12.85日、暫定UTC時計 1.25h、直前進路 15.09°。条件内でも完全な物理的同一環境の実験ではない。

## 原本の観測方向を使った結果

Ameland v60と**全く同じ主指標**：実際に観測された別々の上げ・下げ潮の次進路を `y+`/`y-`、前年2010固定モデルの各実測B状態における潮相切替予測単位ベクトル差の平均を `g` として `T = dot(y+ - y-,g)/4`。Tが正なら、実測した進路差が潮相別予測の方向と一致する。これは潮汐因果効果や旋回角そのものを示さない。

**正方向の事前主基準を2島目でも達成。** 観測された二つの潮相の対応進路差は、2010年にだけ学習した潮相別モデルの方向差と整合した。直交方向のCIはゼロをまたぎ、絶対方向差は潮汐以外の行動変動も含む。実際の相対進路スコアと「真の潮相−反転」cosine利得は数学的に関連するため、**独立した2本の証拠として数えない**。
