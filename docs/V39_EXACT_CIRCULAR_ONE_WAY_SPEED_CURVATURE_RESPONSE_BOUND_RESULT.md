## 研究問い：速度と曲がる頻度の必然的な共変動

この実験は半径Rを一定にして速度vを変えるので、同時に**角速度 ω=v/R も増加**する。「高速の相手を追いかける」操作には社会的な運動適応だけでなく、より速く曲がる相手を追うという物理的要求が混ざる。

[事前凍結v39数理仕様](V39_CIRCULAR_ONE_WAY_BOIDS_SPEED_TURNING_COMPENSATION_FREEZE.md)では、仮想魚が一方的に円を泳ぎ実魚が角度位置だけを追う最小モデルに限定した。

```text
phi_V(t) = omega*t; omega=v/R
d phi_R/dt = kappa*(phi_V-phi_R)
delta=phi_V-phi_R
d delta/dt = omega - kappa*delta
```

`kappa>0` は**実際の魚から推定した値ではない**角度追従の制御利得（毎秒）。`delta` は近距離での円の角度ずれ、0≤delta*<πに限定。安定固有値は−kappa、平衡角度ずれ`delta*=v/(R*kappa)`。円に沿う2尾の接線方向はともに正、実魚の平衡速度は仮想魚と一致して`v_R*=v_V`となる。それでも**方向のずれ**と**距離**は残り、`A*=cos(delta*)`、`d*=2R sin(delta*/2)`となる。

## 数理的な必要利得の下限

方向一致度をc以上、2尾の距離をdmax以下に維持するという制御仕様を決めた場合、**近距離円弧枝**での正確な利得下限は

```text
kappa_align_min = v/[R*acos(c)]
kappa_dist_min  = v/[2R*asin(dmax/(2R))]
kappa_min       = max(kappa_align_min,kappa_dist_min).
```

説明用の恣意的な閾値`c=0.8,dmax=5cm`、`R=15cm`なら距離制約が厳しい。このモデルでは5cm/sの仮想魚に必要な`kappa≥0.99533/s`、15cm/sでは`kappa≥2.98600/s`。**相手速度3倍のまま同じ方向一致・距離を保ちたければ、追従応答利得の最低下限も3倍**。この定量的な幾何制約が本研究の数理的な結果。実際の魚の`kappa`推定や3D力学のベータ値には対応づけられない。

## 新しい検証可能な実験（提案、未実施）

**速度と曲率を分離する2×2実験**が重要。半径だけでなく仮想魚の速度も独立に制御すると、「速さそのものが社会反応を変える」と「曲がるための速度追従負荷が変わる」を区別できる。

例えば以下はいずれも元実験とは**別の将来の操作条件案**：
- **同じ角速度 ω=0.5/s、異なる速度**：R=10cm, v=5cm/s と R=15cm, v=7.5cm/s。ここでモデルの方向一致度は同一。絶対距離は半径によって異なるため、正規化距離 d/R も比較する。
- **同じ仮想魚速度 v=10cm/s、異なる角速度**：R=10cm（ω=1/s）と R=15cm（ω=.667/s）。固定kappaなら前者の方向一致度が必ず低くなる。
- 2×2をランダム・同じ実魚のクロスオーバーとし、個体/セッション単位の群分割、物理時計/速度前処理を固定。固定の水槽壁近傍距離と描画視角は半径でも変わるので、独立統制やモデル調整は必要。
