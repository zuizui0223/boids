# v138：潮汐×太陽周期の位相ずれを活用するための観測設計シミュレーション

2026-11-15。v133–137にある実データの制約（動物観測努力の欠落、複雑モデルのホールドアウト劣化、朝しか観測していない研究など）を踏まえ、**同じ努力量で潮汐2区分×昼夜2区分を計測できるか**を事前の観測設計問題として数学的に検証する。**ここに動物行動の新しい実測効果やメタ解析はない。**

## 1. 物理周期と厳密な区別

NOAAの調和分潮解説では主半日周の月由来M₂≈12.4206012h、太陽由来S₂=12h。潮汐には日周のK₁≈23.93447213hもある。
- 公式資料：https://tidesandcurrents.noaa.gov/about_harmonic_constituents
- NOAA tide tables：https://tidesandcurrents.noaa.gov/publications/Understanding_Tides_by_Steacy_finalFINAL11_30.pdf
- 調和分潮の比較数値：https://coastal.ceg.tudelft.nl/book/2d_tidal_constituents.html

M₂とS₂の**相対位相が2π一巡**するのは

\[
T_\mathrm{beat}=\frac{1}{|1/12.4206012-1/12|}/24
=14.765295\ \mathrm{days}.
\]

これは天文学の位相差であり、「観測期間が14.77日未満なら交互作用が統計学的に識別不能」という硬い閾値ではない。1日の連続観測でも4セルが存在すれば形式上は対比できる一方、経時相関や単一日の偏った条件に弱く、月半ばを跨ぐと太陽時刻とM₂位相の広い組み合わせをカバーできる。

## 2. 定義・計算

**完全に仮想的な平均0の水位**：

\[
h(t)=A_M\cos(2πt/12.4206012+\phi_M)
+A_S\cos(2πt/12+\phi_S)
+A_K\cos(2πt/23.93447213+\phi_K).
\]

3条件 A=(1,0,0)、(1,0.5,0)、(1,0.5,0.5)。振幅の1:0.5:0.5は**地域観測に基づく推定値ではなく、感度実験の設定値**。潮位はh(t)≥0とh(t)<0に二値化。実地の冠水・非冠水判定、上げ/下げ潮の向きではない。昼を06:00–18:00と固定し、10分刻みで同じ位相格子24M×4S×4K=384組（使っていない分潮の位相は重複）を各シナリオに適用。0や1の事象は一切生成しない。1、3、7、15、30日を比較。

観測方法：
- 昼だけ8時間：08:00–16:00。
- 8時間を昼夜に2分割：昼08:00–12:00、夜20:00–24:00。
- 8時間を4ブロックに分割：夜02:00–04:00、昼08:00–10:00／14:00–16:00、夜20:00–22:00。
- 24時間連続：より高努力量の参照（8時間条件との絶対精度比較不可）。

各シナリオで昼夜×潮位正負の4セルに割り当てた観測10分枠をn₁…n₄、総Nとすると、**設計バランス**を

\[
B=\begin{cases}
16/(N\sum_{j=1}^4 1/n_j),& n_j>0\ \forall j\\
0,&\mathrm{otherwise}
\end{cases}
\]

と定義。1が4セル均等、0はセル欠損。これは仮に各セルで同じ独立Poisson強度のイベント率であればlog率の差の差の分散の努力量部分に相当する**設計基準**である。実際の有効サンプルサイズ、相関を考慮した検出力、統計的有意差、各生物の活動率、潮位×昼夜の係数や因果効果ではない。

## 3. 事前指定した比較と基準

主要比較は同じ8h/dayの3プラン：
(1) 昼間8h、(2) 昼夜各4h、(3) 昼夜×2回の2hブロック。数日間同じ時計時間を繰り返すものとし、シフトする潮位と固定時計時間の関係を検証。
最小値、格子平均、4セル揃う位相格子割合で比較し、**平均の向上だけではなく全位相で交互作用を対比できるか**を評価。4ブロック計画は半日周だけの場合に優れるはずだが、混合潮汐では失敗する初期位相があることも結果に残す。

各窓の実装は \`validation_v138/phase_design.py\`、合成数学テスト \`test_phase_design.py\`、最終結果 \`results/sampling_design_phase_grid.json\`。ソース原本と一切混ぜず、3モデルの違いと原データ不足はそのまま保持。

## 4. 生態学的予測と限界

**研究仮説**：潮汐は時間そのものではなく、地形と水位が許すアクセス可能な生息地や資源の組合せを変える。その際、昼夜に同じ潮汐相を踏めていない研究では、水位への応答と夜間特異的な活動（または検出率）の効果が交絡することがある。

自然界の月潮や日潮は潮汐型・岸形・閾値・季節・観測装置によって異なる。高緯度の白夜・極夜や季節ごとの日の出入りを固定06–18の設定は表さず、日の出後しか撮らないデザインでは期間を伸ばしても「夜」を復元できない。局所水位実測・観測機会・生物独立単位・検出過程・移動遷移を取得するまで、Boidsの分離／整列／結合を機構的に同定したとは言えない。

今後の系統的マクロ解析では、「潮汐効果あり」を集約する前に、\`effective_coverage\`, \`actual_exposure_time\`, \`solar_window\`, \`physical_tidal_regime\`, \`site_id\`, \`individual_id\` をデータ規格とする。適格な個別沿岸だけに潮位×昼夜の一次モデルを当て、独立した海岸を単位とする階層/メタ解析へ進める。
