## Genuinely different response and independent environmental source
The new outcome measures **where native 2020 gull GPS fixes are observed** relative to independent actual **2017–2019 GIC tidal-wetland random-forest agreement**. The original publisher bytes from public GCS layer \`gic-2019-v1-0/v1-0-1/murray-gic-v1.0.1-twprobabilityEnd-...tif\` are source-verified per object MD5 and affine, using the already independently authenticated 65536² EPSG:4326 native 30-m pixel grid (v105–v108). GIC's RF score 0–100 is **not a calibrated probability of animal habitat, not 2019 actual tidal-flat area, not local instantaneous inundation, and includes mapped tidal flat, tidal marsh and mangrove**. Wadden v91 wild oystercatcher uses different geography, habitat definition and response.
