# v154：魚類コーラスにおける潮汐代理の追加予測情報と他音型の同時共起

2026-11-15、原本結果の新しい予測スコアを**開く前に比較対象・ゲート・モデルと対照を固定**。v145–v153の既存音型/年別共起結果とNOAAの完全時刻突合結果は見た後の**同一研究内探索的解析**。

## 問い

同じカリフォルニア9録音地点・2018–2023年136,032原本時間において、過去年で学習したBocaccioの音響記録陽性を次の完全な現地暦年で予測するとき、M0現地日周・季節・天文太陽高度より**独立したNOAA検証済み沿岸水位代理**が予測を改善するか。さらに「他音型Bが同じ時間に検出された」という情報が追加改善を示すか。

## 固定5モデルと基準

音型A＝Bocaccio（前回まで陽性の数が十分）。同時音型Bは **UF440（種未同定）とWhite Seabassの2組を事前に全表示**。Bの選択はv145–v152結果を見た後なので、今回の数値は確認的な新規外部追試ではない。

| 比較対象 | 学習時に使う元録音時間の情報 | 数値予測の意味 |
|---|---|---|
| CONST | 学習元のBocaccio陽性率だけ | 定数の基準 |
| M0 Solar/clock | 現地時計時刻の調和項3次数、年間季節2次数、録音地点の天文太陽高度・暗いかどうか | 日周＋季節の基準 |
| M1 Real NOAA | M0＋最寄りNOAA水位計の実測毎時高さ・前後1時間の変化・絶対変化・夜間との交互作用 | 海岸水位の**代理予測**、沖合の実際の潮汐場ではない |
| MGHOST +3d/+11d | M1と同じ変数を、*別の3/11日後*のNOAA実測で置換 | 同じ予測標本を保持した不適切潮汐位相の診断対照 |
| M2 Real NOAA＋partner | M1＋**同じ録音時間の**別音型B陽性 | 同時録音に基づく条件付き連関（魚個体の社会行動、先行予測ではない） |

**モデル複雑度を調整しない**：全て\`LogisticRegression(solver=lbfgs,C=0.25,max_iter=400)\`、学習年のみの平均/標準偏差でスケーリング、nats/元録音時間の二値対数損失を主スコア、Brierを副次。同じ元Yと同じ時間を全モデルへ使用。勝ちモデルや有利な地点を後から選択しない。

## 年別保留・ソース入場条件

- 各録音地点で過去の**すべてのローカル暦年**を学習に使い、次の年は**丸ごと保留**。前年以外を後から混ぜたり、現在年のYを説明変数へ混ぜない。
- 先行する学習年は最低1500録音時間、保留年は最低720。Bocaccio陽性は学習80・保留20、音型B陽性は学習30・保留10、両者の陰性時間は学習/保留それぞれ最低20。足りない地点×年は**SOURCE_RESPONSE_STOP**として保存。
- v153のNOAA真正14観測所×年・SHA256台帳に一致し、0/+72/+264時間のすべてのNOAA水位と両側1時間値が同じ元録音時間で取得できること。位相誤り対照の欠測だけが起きる時間は**全モデルから同じように除く**。同一サイトの元録音時間の95%以上残らなければ、対象サイトは全モデル停止。
- 地理感度：NOAA最寄り水位計まで**80 km以下**の録音地点だけを別表にし、全9地点での平均とは区別。90 km先の港湾水位を実際の深い魚の水位と同じにしない。

## 判定

- M1がM0とCONSTの両方を上回り、さらに**正しいNOAA時刻**が誤った+3/+11日を上回るなら、その地区では実測沿岸水位代理が日周/季節以外の時間的な予測情報を持つ可能性。別の年・別海域でも確かめる必要がある。
- M1が良くても**間違った潮位の方が同等かより良い**なら、「潮汐位相固有の反応」とは解釈しない。
- M2がM1より良くても、**同時録音の共通音源・検出状態、水温や湧昇流の未測定日単位変動**が理由かもしれない。M2はBと同時刻の情報を与えるので**未来に利用可能な予測値ではない**。
- 1年ごとのnats/時スコアは自相関を含むので、それ自体を独立個体数やp値にしない。サイト×年の平均と正負数だけを出し、**統計学的有意性・global meta係数は出さない**。複数地点は同じ地理・同じ著者原本に依存。

**問題点として必ず残す**：録音の非記録＝確実な魚不在ではなく、明示Off/Noise除外後も元の可聴性や一時的な船舶騒音は不完全。NOAAの沿岸水位計と海中音響地点は最大90.625km離れている。潮流・海水温・湧昇流は現状のモデルで直接制御していない。
