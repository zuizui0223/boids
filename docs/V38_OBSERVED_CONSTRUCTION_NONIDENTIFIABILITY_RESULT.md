# v38：潮汐×方向の記憶なしモデルでも、野外で見えた3符号は生成できる

**2026年10月31日 JST。合成シミュレーションと数理的反例の結果。** 本解析はv33/v34の野外GPS観察符号を事前に知ってから設計したもので、**独立な鳥の観察でもモデルの野外検証でもない**。前のv37（状態遷移＋有限移動）と正面から比較し、同じ3つの符号だけで「潜在状態記憶と移動過程が不可欠」と論理的に言えるのか調べた。

## 1. 結論：3符号だけでは野外の潜在状態遷移を一意に同定できない

元のv37は、潮汐が活動状態を切り替え、採餌とねぐらの間の有限な移動状態がある**合成モデルA4**で24/24種子、そこに3D社会的操舵を加えた**A5**でも24/24種子で、既知の野外GPSの定性的3符号を再現した。しかし、v37の限定された「記憶ありで通勤なし」モデルA3が不支持だったからといって、**記憶のない別クラスの運動法則が不可能**とはいえなかった。

v38では、鳥のROOST/FORAGE/OUTBOUND/INBOUNDを一切与えない**記憶なしの連続的なスカラー運動速度法則**をつくり、3Dの位置／進行方向を積分した。潮汐高さHとその変化速度dH/dtの**交互作用**を直接速度へ与える。

```
v(t) = 0.30 + 0.48 A(H)
       + 0.12 sign(-dH/dt) tanh((0.50-H)/0.30)
A(H) = clip((1.25-H)/2.40, 0, 1)
```

Hは源データのRWS天文潮ではなく、v37の**ソースフリー合成潮汐**、座標は任意3Dトーラス内の人工30エージェント。速度はkm/h、観測変数は水平ステップ速度のlog1p。**係数と0.5m反転位置は元の野外結果を見てから人工的に設定**したもので、フィールド推定量でも普遍の物理閾値でもない。

## 2. 24種子×4固定モデルの全対照

各モデルはv37の元コードをGit blob SHA `b4920aa6014306b7e776393db6ee7f469a892f8f`で検証し、同じ周期12.4206h、24合成日、48h burn-in、30人工個体、24 RNG種子を使用。動物の実測値はゼロ。

3符号とは、H高−H低の速度差が負、低水位でebb−flood正、高水位でebb−flood負をいう。各潮位帯0.5mの高さ制御はv37と同じ。

| 合成モデル | 同時に3符号に合致した種子 | 高−低水位 | 低水位ebb−flood | 高水位ebb−flood | 平均合成近傍数 |
|---|---:|---:|---:|---:|---:|
| C0_ADDITIVE_H_PLUS_PHASE | 0/24 | -0.2718 | 0.1466 | 0.1770 | 0.00 |
| C1_SMOOTH_INTERACTION_NO_SOCIAL | 24/24 | -0.2718 | 0.1295 | -0.1443 | 0.00 |
| C2_SMOOTH_INTERACTION_WITH_3D_BOIDS | 24/24 | -0.2718 | 0.1295 | -0.1443 | 24.43 |
| C3_WRONG_CLOCK_HALF_TIDE_SHIFT | 0/24 | 0.2697 | 0.0161 | -0.1379 | 0.00 |

- **C0** 高さとebb/floodの**加算のみ**では低・高水位の向きが両方正なので、**0/24**。低水位でebb優位、高水位でflood優位という符号反転に**水位×方向の交互作用が必要**（あくまでこの指定された加算系モデル族の中で）。
- **C1** 同一時刻のHとdH/dtだけに反応する**滑らかな記憶なしモデル**が**24/24**。ROOST/FORAGE状態、過去の採餌経験、通勤タイマー、個体別の学習規則は一切使っていない。
- **C2** C1と全く同じ運動速度法則にv37の3D分離・整列・凝集の操舵を与えても**24/24**。平均合成近傍数は24.43なので操舵は実際に計算されている。ただし3符号は**水平速度だけ**なので、空間の場所や方向・集団形状はまだ評価していない。社会的Boids力が野外に存在しないという意味ではない。
- **C3** 潮汐の速さを生む時間軸を約半周期（+6.2103h）ずらして、元の水位／潮向きで評価すると**0/24**。人工的な潮汐同期モデルには時計位相の情報が重要なことを示す物理対照で、野外の因果検証ではない。

## 3. 18条件×24種子を固定した感度解析

追加の解析は実測で最適化するのではなく、あらかじめ[プロトコル](V38_MEMORYLESS_TIDAL_INTERACTION_IDENTIFIABILITY_PROTOCOL.md)に固定したα={0.20,0.48,0.80}、β={0.06,0.12,0.20}、幅w={0.15,0.30}mの**18係数組合せすべて**で同じ符号を解析。計算量を抑えるためこの感度解析は3Dの方向を積分せず、合成スカラー速度に同じ対数正規ノイズを与えた。

**18/18条件 × 24/24乱数種子 = 432/432計算で3符号成立**。これは元の係数1組だけでしか動かない例ではない。ただし、パラメータ範囲は最初から元の観察パターンを生成しやすい交互作用の符号・形状を仮定した狭いもの。432例を**実証的再現432回**と扱わない。将来の気候・干潟の標高・種間／個体間ニッチへ一般化する証拠ではない。

## 4. 機構を識別するための決定的な予測

合成モデル内で**まったく同じ現在の水位H=0m、dH/dt=0m/h**を与えると：

- **v38記憶なし法則**は過去にどこにいた個体にも **0.55 km/h** の同じ決定論的速度（3D headingとノイズの前）。
- **v37活動状態遷移モデル**では、同じ環境でも履歴状態ROOSTとFORAGEを意図的に保持した個体が **0.09対1.1 km/h** と異なる。これは過去の状態を保持する潜在メカニズムによる。

したがって野外で真に区別するなら、現在のHと水位の傾き・観測時刻・季節・GPS時間間隔・個体・位置／生息地を揃えた上で、**以前にどの活動場所・水位・状態にいたかという情報が、次の移動速度・移動方向・休息時間・採餌地点を追加的に予測するか**を調べる必要がある。

現在の野外GPSには採餌／休息の真ラベルがなく、同じH,Hdotに異なる状態が現れる理由にも場所や天候などの交絡がある。そのためこの実験は**野外の記憶機構を支持／反証していない**。

## 5. 修正された統合理論と投稿上の意味

同じ潮汐環境への移動応答を説明しうる最小記述として、
- *instantaneous forcing*: 現在のH×dH/dtがただちに速度規則を変える。
- *state hysteresis*: 現在のH,dH/dtが同じでも、過去に採餌／移動／休息のどの状態にいたかが次の運動を変える。
- *social heading*: 以上のいずれにも、独立のBoids整列・凝集・分離による運動方向・集団構造が加わり得る。

この区分を設けないと、潮汐と水平速度の３符号から「通勤・記憶・社会力が必要」と過剰同定しやすい。現在の実測は潮位と上げ下げ潮の条件付き**速度差**であり、野外の集団の3D高度・方向や真の資源ニッチの直接検証ではない。

この意味で**v37とv38は、異なる十分機構を見つけた数学的な非同定性の結果**として統合すべきである。v37は撤回する必要がなく、ただし「他のあらゆる機構を除外した」とは書けない。
