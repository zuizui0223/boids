# Boids：これまでの肯定結果と、次の予測モデルに残す要素

2026年10月30日。既存結果の基準は main `47cf12b51553c865027961ae5c162f1b479f5c8c`（v28）。各版の数値 JSON、比較対象、コードの評価単位を照合した。

## 現在の中心的な結論

**動物の移動・空間利用には、周囲の現在状態、自個体・自群れの過去、環境条件がそれぞれ予測情報を持つ例がある。合成モデルでは、私的学習と社会的な選択模倣の組合せによって、その情報が個体単位にも集団単位にも現れる。**

この研究の成果は、「どの情報を使うと、何を、どの時間尺度で予測できるか」を数値で比較できるところまで進んだことにある。秒単位の旋回、日単位の移動の広がり、季節単位の群れの空間利用、生息地内の使用地点の識別は別の対象であり、一つの効果量へ合算しない。

以下の実測比較は探索的研究プログラム内の結果である。個々の比較が結果を見る前に固定されていても、全データ源を通じた一つの確認的メタ解析ではない。95%区間は記載した独立単位を再標本化した bootstrap 区間である。

## 3. 合成モデルで示せた数理・機構的な肯定

### 3.1 同じ初期状態から個体・集団の利用差が生じる（v12）

初期の資源選好を同じにしても、私的な報酬強化だけで、保留した後半日の同ギルド平均モデルに対する個体別patch予測に **+0.428 nats/choice**、個体別高さprofileに **+0.242 nats/fix**の利得が生じた。30個の独立seed世界で検証した。

同じ人工ギルド内の選択模倣を加えると、母集団平均モデルに対するギルドのpatch予測に **+0.592 nats/choice**、高さprofileに **+0.183 nats/fix**が現れ、個体単位の追加利得は弱まる。これは「情報が個体ごとに残る条件」と「集団に共有される条件」を同じモデルで比較できる成果である。人工ギルドは生物学的な種ではない。

原記録：[direct scores](../validation_v12/results/endogenous_policy_v12.json)、[介入差と不確実性](../validation_v12/results/driver_audit_v12.json)。direct scoreに介入差のCIを付けない。

### 3.2 社会関係が変わると予測すべき集団区分も変わる（v13）

5日目に人工ギルドの半数を入れ替え、5–6日目で学習して7–8日目を予測すると、現行ネットワーク区分は直交する反実仮想区分より **+0.193495 nats/choice**良かった。30seed bootstrap 95% **[+0.102003,+0.286962]**。学習あり−なしの差は **+0.238773**、95% **[+0.146533,+0.333563]**。条件付き高さも **+0.121808 nats/fix**改善した。

今回、固定ソース・30seedから完全JSONを再生成し、主要報告値が表示精度内で再現することを確認した。原テスト14件も成功。再生成JSONのSHA256は `c7e34840d91306045cbad7f0bf350cc68067a564b95135f0f28010b84f3e8e85`。これは計算の再現であり、新しい生物学的実験ではない。

原報告：[v13 result](NETWORK_REWIRING_RESULT_V13.md)。再生成原記録：[v13 replay](../validation_v29/results/v13_replay_2026-10-30.json)。文書の副比較CI上限2箇所に約1×10^-6以下の丸め表示差があるが、支持判定は変わらない。元Actions artifactとのバイト一致を検証したものではない。

### 3.3 Boidsの運動力が担う部分を切り分けた（v11–v13）

環境の選好差を与えた合成世界では、社会力を加えると水平分化が **−0.105472 nats**、水平位置を条件付けた高さ分化が **+0.074272 nats**変化した（12対応seed、両区間は0をまたがない）。つまり、既存の差が表れる空間軸を社会力が変え得る。[v11原記録](../validation_v11/results/environment_ablation.json)。

一方、v12–v13の学習・ギルド化に対する通常のBoids motor forceの追加はほぼ0だった。v13では **−0.000223**、95% **[−0.003193,+0.002111]**。このモデルの個体・集団差を主に作っているのは、報酬学習と行先選択の共有である。

さらに、異なる分離・凝集係数が同じ観測条件で同じ瞬間運動を作り、別条件では将来の空間利用が変わる合成反例を示した。したがって、短期移動への当てはまりから長期ニッチを一意に推定できるとは限らない。[v9数学的監査](MOVEMENT_TO_NICHE_IDENTIFIABILITY_V9.md)、[v10空間利用予測](NICHE_IDENTIFIED_SET_V10.md)。

## 4. 今の論文で主張できること

中心を一文にすると、**「動物の空間利用を予測する情報は、現在の近隣状態、個体・群れの履歴、環境に分布しており、その有用性を予測対象ごとに切り分けられる」**となる。

実測部分では、同じ個体・群れの過去と現在の周辺情報を持たせたときに、どの予測が改善するかを示す。合成部分では、学習と社会的選択の共有がそのような情報構造を作る十分条件を示す。共通の生物機構を実証したとの結論はまだ置かない。

Boidsの分離・整列・凝集だけによる野外の種内・種間ニッチ分化、3D資源利用、認知記憶、競争の因果効果は未実証である。独立な別資料v6・v8・v15では近隣情報の主比較が支持されていないことも、その適用範囲を判断する根拠として残す。

`batter`、`odsp`、`mina`、`louis`は独立した研究として位置付け、その結果をBoids自身の実証件数に加算しない。今回はこれらのリポジトリを変更していない。

## 5. 今回進めた検証

v23の最も直接的な未解決点は、複数日の履歴が、単純に「昨日と同じ」と予測する基準に勝るかである。新しい比較を開く前に、[v29プロトコル](V29_HISTORY_VERSUS_PERSISTENCE_PROTOCOL.md)を記録した。元の49個体・2,664日、原データのハッシュ、品質基準、4モデルを維持し、正確な前暦日の値だけを使う比較を追加する。

**追加比較を実行し、元の4モデルの全個体別誤差が許容誤差1e-12で再現することを確認した。** この比較は同一資料の探索的な拡張であり、過去結果を知らない独立検証とは呼ばない。

| 同じ49個体・2,664日を予測する情報 | 個体等重みMSE |
|---|---:|
| 他個体の履歴 | 0.518971 |
| 気象区分で対応させた他個体の履歴 | 0.520229 |
| 自個体の複数日の履歴 | 0.348176 |
| 自個体履歴＋気象区分付き他個体履歴 | 0.347095 |
| **自個体の正確な前日の値だけ** | **0.320076** |

「昨日と同じ」と予測するだけで、気象区分付き他個体履歴より誤差が **38.47%減少**し、**41/49個体**で改善した（既定の記述的比較）。一方、複数日履歴の組合せが前日予測を上回る主比較は **−0.027019**、95% **[−0.078755,+0.021354]**、18/49個体だけが複数日履歴有利であり、支持されなかった。前日予測が数値上は最良だが、複数日履歴に対する統計的優越や同等性まで示したものではない。

この結果を踏まえ、カモでの中心的な肯定は **「同じ個体の直前の状態が翌日の予測に有用」**とする。長期的記憶や持続的個体差を追加で立証したとはしない。今後のモデルは、この前日基準を明示してから、長い履歴・環境・近隣情報の上乗せを問う。

履歴の時間幅も確認した。2,645/2,664標的では前日が履歴に含まれた。履歴は通常14観測日だが、欠測や再来訪により最古の観測が274日前の場合もあった。「直近14観測日」と「直近14連続暦日」を区別し、今回結果を見てから履歴幅を変更することはしなかった。
