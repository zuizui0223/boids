# v159 — 北東大西洋C-POD元CSVの43地点×6地域・クリック陽性時間を原本監査

研究資料：[Stavenow Jerremalm et al. 2025](https://doi.org/10.1002/ece3.72566)。欧州PMC公式ZIPから本当のData S2メンバー `ECE3-15-e72566-s002.csv` を再取得して、v158でSHA256固定された**126,231行×32列・26,454,371バイト**と厳密照合する。ロジスティックモデルや生態学的な新しい係数を作る前の**ソース／観測分母監査**。

## 新しい固定チェック

1. 公表された**43 C-POD地点、6地域、2009–2023年**が、元CSVの `SITE`, `GROUP`, `COUNTRY`, `year` で本当に確認できるか、全レコードをグループ別、地点別、年別に合計して照合。
2. `year`＋`YDAY`＋`hr`を実際の閏年カレンダーで復元（ただし現地タイムゾーンは資料だけでは未確定）。同一SITE×時刻の重複、`hr_day_year_SITE`の原ソース合成ID重複、不正時刻を数え、すべての元行がユニークな1時間に対応するか検証。
3. `clicks`, `buzz`, `regular`, `buzprop`, `foraging_click`, `DPM`, `DDDN`の**原定義候補**について数値・0・分子分母の整合性チェック。buzzがclicksより多いなどの異常を自動検出。対照として元CLICK陽性の時間で`buzz=0`を明示。ただしこれをネズミイルカ不在と呼ばない。
4. 各SITE内で前後に**連続してクリック陽性が観測された元時刻**を数え、前1時間がsource-positiveである診断が可能か評価。ただし間のCSV欠損時間を`clicks=0`に補完せず、**録音努力を保証する自己遷移率とは扱わない**。
5. REGION×SITE×YEARの数値を**source-safe要約のみ**GitHubに保存。元の個体別・クリック時刻別行、機器配置の詳細な真の時刻列や26MB CSVは転載しない。

## 原論文の先行内容との差分

元研究はすでに6地域の採餌時刻と季節・日周・日長・水温などの関係を検証している。今回はこれらを新発見とは呼ばない。source-only結果が成立した後、クリック陽性の時間内に採餌buzzがあるか、**同じ年・siteを保持したregion-holdout**で分析可能かを別の段階で検証する。C-POD停止／未検出時間を含まない場合、一般的な生物の出現率、24h稼働努力に対する採餌率、潮汐×日長の地域因果係数は推定不可。
