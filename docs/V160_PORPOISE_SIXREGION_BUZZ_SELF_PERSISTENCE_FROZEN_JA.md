# v160：ネズミイルカ6地域の採餌buzz状態の自己持続は、他の地点へ転移可能か

2026-11-16。Stavenow Jerremalm et al. 2025（DOI 10.1002/ece3.72566）の元真正CSVから、v159で **43地点・6地域・126,231クリック陽性時間、実時刻重複0、連続したクリック陽性時間ペア78,030**をソース確認した後に、今回の固定モデルを凍結。地域×地点のbuzz陽性率は既知のため、**探索的解析**として扱い、独立した事前登録の生態学実験とは言わない。

## 観測単位と評価目的を限定

\`Y_t=1\` は、元Data S2に **クリック陽性（clicks＞0）として記載された**SITE×hourで、\`buzz>0\` が検出されたこと。ネズミイルカがいる／いない、C-PODが稼働している／停止している、真の採餌成功や捕食個体数を表さない。Y=0は**クリックがある元記録内でbuzz=0**であり、元CSVが欠けている時間をゼロで埋めない。

\`Y_{t-1}\` とその前のクリック数は、**同じSITEの1時間前の実際のクリック陽性行が存在する場合だけ**使う。元v159では78,030の連続元行ペアがあった。追加の同時刻・前日 \`Y_{t-24}\` は**元CSVにclick＞0の時間が実際に存在する場合にのみ**計算する。今回のモデルは\`clicks_t\`という**現在の観測情報**を使用するので、年外の将来行動予測ではなく、観測時点での採餌buzz検出を後から分類する条件付き予測である。

## 固定したSITE全保留の設計

6つの原著GROUPを完全に維持する。各GROUPごとに**1つのSITEの全期間をまるごと保留**し、同じGROUP内の**その他のSITEだけ**で固定モデルを学習。別GROUPの学習やテストを勝ちモデルに応じて移し替えない。複数SITEを独立の生物種や独立の海岸研究として数えない。

| モデル | 条件付ける内容 |
|---|---|
| C0 | 学習地点全体のbuzz陽性率 |
| C1 | 現地CSVのhour調和1/2次、通日（YDAY）調和1/2次、year線形項、**現在の検出クリック数 log1p** |
| C2 | C1＋1時間前の実際のクリック数 log1p |
| C3 | C2＋**1時間前の実際の採餌buzz陽性** |
| 別サブセットG24 | C2と同じ元観測値・同じSOURCEサンプルで、1時間前のbuzz陽性 vs **24時間前の別日同時刻buzz陽性**を比較。過去24時間も実際のclick陽性行が必要 |

固定ロジスティック回帰 \`C=0.25, lbfgs, max_iter=350\`。スケーリングは他SITEの学習元時間のみで実行。主スコアは保留SITEの**クリック陽性時間あたり二値logloss（nats/元観測時間）**、副次Brier。改善量は\`loss(C2)−loss(C3)\`（予測損失を下げれば正）と、共通負対照サンプルで\`loss(G24)−loss(C3)\`（真の1時間前が前日同時刻より良ければ正）。

## 固定した入場・STOP

主要モデルでは、保留SITEに**実測連続ペア250時間以上**、学習（同地域の他SITE）1,000時間以上。学習buzz陽性≥100・陰性≥100、保留陽性≥40・陰性≥30。前日24h負対照は別元サンプルを要するため、保留≥150、学習≥700、保留陽性≥25・陰性≥20、学習陽性・陰性とも≥100。原本SOURCEデータの機会数が不足したSITEは**STOP**して全43地点と全6地域の不適格例も公表。すべてのGROUPに有利な予測値が出ることを想定しない。

## 解釈

- SITE保留でもC3がC2を改善するGROUPが多ければ、**クリック陽性に条件づけた採餌音響状態の1時間自己相関が、単純な暦・時計・現在と前のクリック検出数の後でも転移可能**という観測的支持になる。
- C3がG24に優れば、**同日・直近の採餌状態が前日同時刻のbuzz状態より情報を持つ**といえる。ただし同じSITE内の海況、昼夜・曜日・C-POD音響検出の継続、動物の滞在などによる共通変動を除去したわけではない。
- 原研究はすでにネズミイルカの採餌割合と日周・季節・地域差を解析しているため、これらを今回の初発見と呼ばない。
- このSOURCEには別魚種の同時行動や全C-POD稼働時の無検出時間がない。**個体の記憶、社会的Boids整列/分離/凝集、潮汐×太陽の生物学的因果係数・全球統合効果は推定しない。**

## 実行

\`python -m unittest discover -s validation_v160 -p 'test_*.py' -v\`：ソース無関係の数理／SOURCE STOPテスト。
\`python validation_v160/porpoise_site_holdout.py --emit\`：v158元CSVを実際に再取得しメンバーSHAとv159真正43SITE・78,030ペアの元分母を照合、全GROUP×SITEのモデル／STOPを出力。レシートはsource-safeのSITE単位のみ。以後\`--check\`で厳格な再計算を導入する。
