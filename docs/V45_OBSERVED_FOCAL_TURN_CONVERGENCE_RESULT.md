# v45：同じ焦点鳥が近隣方向へ曲がったか？ 観測結果と識別限界

**2026-10-31 JST。先行v43/v44の野外結果を見た後の同一GPS資料の探索的検証。** [元の結果前に新指標・最低支持・時間シャッフル対照を固定](V45_ORIGINAL_TURN_TOWARD_NEIGHBOR_PROTOCOL.md)したが、GPS個体群自体は未開封ではない。本研究の観察は**局所的な方向一致への収束が負**であり、「近くの鳥の方へ追従・同調している」との素朴な仮説を直接支持しない。**ただし、負の収束は直ちに忌避／社会的反発を意味しない。**

## 1. 元のソースと過去の効果を完全照合

Zenodo 10053970 v4のミヤコドリ2008–2014年全7原GPS gzip（公開元MD5／元SHA256）、RWSの`schiermonnikoog.waddenzee` 2008–2014 10分刻み天文潮WATHTE NAP cmを元の時計変換で再取得。元v41 ID/UTC、v42実際の200m共時近接、v33-D実潮汐×移動速度、v39個体直前速度、v40自身の直前方向、v43他鳥方向、v44双方同時情報、**全モデル・個体別匿名結果・年/月別評価**を絶対誤差1e−12以内で完全に再計算し、既存の結果を変えないことを確認した。

元v44の**18個体・68,232**「近鳥200m内と遠鳥1km以上の双方で前観測方向がある」未来GPS区間をそのまま出発母集団とし、前の**焦点鳥自身の別GPS2fix対の移動量≥50m**、次の元GPS対の移動量≥50m、近鳥・遠鳥各平均過去方向ベクトルの合成強度≥0.25を固定要求。全閾値を満たした原GPS区間は**4,667件**。各元鳥10区間の最低支持後、**17個体・4,660区間、11UTC月、2010・2011年**が評価対象となった。18鳥というv44母集団と17鳥という今回の方向定義可能な分析対象は異なる。同じ個体の前後GPS区間は**同一測位点を共有しない**。近鳥・遠鳥の方向は焦点鳥の未来予測開始より過去5分以内に観測終了した元の別鳥2fix対のみ。

## 2. 今回の固定観測指標は、予測MSEではなく「方向の収束」

前に進んだ焦点鳥の単位方向 `u_before` と、その後の元GPS対の単位方向 `u_after` の差をとり、**予測開始より前**の近鳥単位方向 `n`・遠鳥単位方向 `f` にそれぞれ内積する：

```
C_near = (u_after - u_before) · n
C_far  = (u_after - u_before) · f
C_NF   = C_near - C_far
```

C_NF正なら、**焦点鳥は同じ未来区間に対して近鳥の過去方向へ遠鳥より強く近づく**。主比較と符号を結果前に固定。各元鳥内で全適格なGPS区間を平均し、最後に各元鳥を等重みで平均。GPS観測区間4,660を独立の環境反復として個体bootstrapを過小評価しない。10,000回全鳥対応bootstrap RNG 20261031、exact one-sided正方向鳥符号も算出。

| 固定比較 | 等鳥平均の方向収束変化 | 全鳥bootstrap95% | 正／負の鳥 |
|---|---:|---|---:|
| **主 C_near−C_far** | **-0.097949** | [-0.135902, -0.057040] | 2／15 |
| 副 C_near | -0.102040 | [-0.130932, -0.071621] | 1／16 |
| 副 C_far | -0.004091 | [-0.029513, 0.017443] | 10／7 |

**主の負方向は17鳥中15鳥で観測され、95%区間もゼロをまたがない**。ただしこれは「鳥は近隣を避ける」との**因果的結論ではない**。本データでは近い他鳥と同じ方向をもともと向いている鳥がランダムな旋回で一致度を落とすような、**初期一致度による幾何学的な平均回帰**もあり得る。

## 3. 時間シャッフルの粗い対照

同じ焦点鳥・元暦年月・UTC6時間枠・天文潮の上昇/下降符号の中で、**近鳥＋遠鳥の元方向ベクトルの組を崩さずペアとして**100回シャッフル。これにより時計と潮汐方向の粗い共通変化を保持しながら、個別の焦点鳥と他鳥過去向きの正確な時刻対応を外した。**17鳥・4,552適格区間**が別ゲートを通過。

- 元の正確な時刻対応のC_NF：**-0.098952**
- シャッフル後100反復のC_NF平均：**-0.032547**
- 5–95%のシャッフル分布：[-0.063882, -0.004304]
- 元実測−シャッフル平均：**-0.066405**。

観測されたC_NFはシャッフル平均よりもさらに負。**現実に観測された近隣の時間整合性と方向変化との対応がある可能性**を示すが、shuffleは正確な位置、風、食物分布、潮流やGPS観測間隔を保存せず、100回を独立した鳥の実験として扱わない。

## 4. 野外年・暦月を変えても同じなのか

- 2010年：元17個体・4,081未来方向区間、C_NF=-0.090361。
- 2011年：元7個体・579未来方向区間、C_NF=-0.119912。

両年の平均方向は負だが、2011年は7鳥で少数。11か月を等重みで平均した別推定量はC_NF=-0.183865、単純月bootstrap区間[-0.387904, -0.044358]で負だが、これも月を独立な研究地に変えることはできない。

## 5. 最重要の次の反証：幾何学的な「初期一致度」による平均回帰

*負のC_NFが社会的な反発でなくても発生することは、数式上で明白である。* 例えば、鳥自身の元の向き `u_before` が近鳥 `n` に遠鳥 `f` より大きく一致している場合、完全に社会情報を使わずランダムに少しだけ曲がっても `C_near−C_far` は負に偏りやすい。

次の**事後診断としてあらかじめ方法と比較方向を別途固定**し、`u_before`に対する実際の旋回角の大きさを保持した「時計回り・反時計回り対称の慣性帰無」を導入するのが科学的に必須：

```
B = u_before · (n - f)
c = u_after · u_before = cos(turn_angle)
C_expected_under_symmetric_turn = (c - 1) * B
C_excess = C_observed - C_expected_under_symmetric_turn
```

C_excess が0付近に収束するなら、観察された負のCは**初期方向一致の幾何学と単なる旋回の慣性**で説明でき、社会的忌避という解釈は不要。負のまま残る場合も、共有された移動経路や風・潮汐による向きの制約が残るため因果的な社会的反発とは断定できない。**この補正検証はv45本体では未実施であり、v45の負の効果をそのまま社会的相互作用へ読み替えてはならない。**
