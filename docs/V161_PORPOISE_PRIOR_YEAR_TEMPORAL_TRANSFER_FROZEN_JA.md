# v161：ネズミイルカ採餌buzz自己持続は同じSITEの「翌年」にも転移するか

2026-11-16。v160における**別SITEの完全保留**で自己状態追加予測が全21適格SITE中20で正方向だったが、これは特定SITEの恒常的なbuzz陽性率（音響検出状態、マイク/環境、動物の出現頻度）を1時間前のbuzzが代理している可能性がある。そのため、今度は**同じSITE内の過去年のみ学習**し、後の年の全元クリック陽性時間を保留するという別の転移方向を追加する。

## 固定仕様（v161の新しい予測結果を開く前に保存）

- 元C-POD Data S2 CSVをEurope PMC公式で再取得し、v158/159の抽出CSV **SHA256 \`972b43b0313cb29aa485733b2892fba1f42aea5543da08ab87f8389bb3b7addf\`** と43SITE×6GROUP・126,231元click陽性時間・78,030元の連続1時間ペアのSOURCEゲートを完全に再現。
- 各行の年はv160で元年から凍結した\`(year−2016)/5\`を**整数年へ逆変換**して、2009–2023年範囲と誤差が完全一致するかを機械検証。元の\`year\`データを予測ラベルから作らない。
- **各SITEにつき学習は必ずその年より古い年だけ**。テストはそのSITEの後の1暦年の元で実際に記録されたクリック陽性時間全体を保留。各SITEの全年を使ってモデルを調整しない。
- \`C0\`定数、\`C1\`時計2調和・通日2調和・元年トレンド・その時刻のclicks、\`C2\`その前1hのclicks、\`C3\`その前1hのbuzz陽性を比較する。さらに元録音が存在するt−24のbuzzとt−1を**同一Y・同一時刻で**別対照比較。
- **v160で固定したsource gate閾値やモデル係数を一切変更しない**：主検定はtrain≥1000、test≥250、train buzz陽性/陰性≥100/100、test陽性/陰性≥40/30。t−24対照はtrain≥700、test≥150、train陽性/陰性≥100/100、test陽性/陰性≥25/20。L2 logistic C=.25、train-only標準化、正のproper二値logloss減少（nats/元click陽性時間）とBrier。
- 全SOURCE SITE×暦年を結果に載せる。学習元年数・元時間・元正負が不十分ならそのSITE×yearを**STOP**して、勝ち年の後選択や過学習を行わない。
- 地域・SITEそれぞれの平均は**一つの元研究内の依存した録音系列**であり、site-yearの個数を独立した世界研究数として扱わない。GROUP間の効果を一つの全球生物学的メタ係数へプールしない。

## 反証可能な分岐

- 別SITEだけでなく同SITEの後の年でもC3がC2よりよければ、**クリックが検出されたという条件のもとで、自己音響採餌状態の直前1時間に予測情報がある**という結果の時空間的な頑健性が高まる。
- 翌年ではC3改善が消える／負なら、v160の結果はSITE陽性率・検出環境の代理かもしれず、汎用の「記憶」や時間ニッチ持続性の主張を弱める。
- t−1とt−24の両方を計算できたSOURCEサブサンプルで、t−1に固有の改善が減る場合は、日周周期や源の観測条件が大きな原因として残る。

**観測限界**：同じ動物個体を識別していない。clickがなかった時間、録音器が止まった時間、個体の実採餌成功、局所潮位・潮流を計測していない。現時刻のclicksを使用するため後ろ向きの条件付き分類で、実際の未来のネズミイルカ行動予測ではない。系統的Boids力・全球潮汐×太陽の生物学的因果効果は未推定。

## 実行方法

\`python -m unittest discover -s validation_v161 -p 'test_*.py' -v\` で源に依存しない正しい年の逆変換・ホールドアウト分割をテスト。

\`python validation_v161/porpoise_temporal_holdout.py --emit\` は真正原本とv160 SOURCE QCを再取得して全43SITE×元SOURCE年のモデル・STOPを出す。データ本体は音響原本のSHAだけ、SITE×GROUP×年の集計はGitHub Actions artifactに保持。小型source-safe receiptを固定後\`--check\`で結果カテゴリ完全一致・数値は異CPUの固定1e−7許容差で照合する。
