# v42 — 野外の原GPSで200m以内の別鳥が過去5分以内に測位された機会数

**2026年10月31日 JST。結果：SOURCE_SPATIALLY_COTIMED_NEIGHBORS_AVAILABLE_BEHAVIOR_NOT_TESTED。** 今回は実際のGPS座標を使って他鳥の存在と近接を確認したが、社会的な方向予測、Boids操舵係数、因果的な個体間相互作用の効果を計算したわけではない。

## 前段の元sourceのみの再現

Zenodo 10053970 v4の原2008～2014年7gzipを公開元MD5/SHA256で再照合。元の個体ID、UTC、visible/outlierだけを読んで**v41の39鳥、602,380元のID時刻、2010～2012年276,946の時間だけの候補と年別カウントすべて**を完全再現してから、元GPS緯度経度を開いた。元個体IDや個別GPS時刻を保存・公開していない。

## 源の近接条件

v39/v40と同じ四つの元GPS時刻の条件（5～30分の過去ペア、5～360分の空白、5～30分の将来観測ペア）に加え、**全4点が公式Schiermonnikoog潮位点から25km以内**を要求。その結果、同一元sourceの**328,323候補**を得た。

他の個体の最も最近の元GPSが、焦点個体の予測開始より**前、最大5分**にあり、他鳥自身に**その前の5～30分の移動ペア**が存在する場合だけ近接を判定。他鳥の未来のGPS測位は使わず、他鳥の直前の位置と焦点鳥の現在位置の水平大円距離を評価した。距離しきい値は結果を見る前に固定し、100mと1kmは源のサポート感度、**200mが主条件**。

## 次の直接的予測比較

元v40のV1（潮汐Hと上げ下げ潮、時間・場所・個体、過去速度＋過去の自己方向）を全モデル共通の対象にそろえた上で、**200m以内にいた他鳥が予測開始までに記録した過去の進行方向**を追加する。元の他鳥の距離、既知測位遅れ、既知の過去速度、同時刻の遠い鳥の平均方向などを対照として含め、将来月の学習・検証で予測増分を比較する。

仮に近い別個体の方向が役立っても、同じ風・潮汐・餌場・渡り経路、観測過程により方向が似る可能性があるため、**Reynolds整列／凝集／分離の因果係数を同定したとは言えない**。次の主効果は新規の独立先行固定で、今回の近接機会数そのものを効果と混同しない。
