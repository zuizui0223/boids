2018年と2019年の別年で、同一条件付き予測構造の**3コントラスト全てが正方向に再現**した。これはこの研究内では現在最も有力な正の結果。ただし2019年の真潮位の誤位相優位は2018年より小さく、2019年も週17回を独立研究数としない。

## 3. 何が解明されたか、何がまだ解明されないか

**支持できる**：同じ沿岸の別暦年で、タグ付けされたミヤコドリのACC行動分類が、自己の直前のSOURCE行動状態から予測可能であり、これに加えて正しい時間対応の実測港湾潮位が、時計・天文昼夜・個体固定差・元月の後でも元SOURCE週へ追加予測情報を持つ。3/7/11日違う港実測潮位より正しい潮位が一貫してよい傾向。**自己状態と外部周期の相互に代替できない予測情報の存在**という構造の再現。

**ただし因果的には未証明**：
- 2018と2019は同じ島・同じ種・同じRWSゲージで、元GPS標識個体は42羽で重複があり得る。2019年自体も先行v127で結果をすでに確認済み。2018年から2019年へ係数を固定した真の「年外予測」は実施しておらず、**各年内で学習し、各年の別週へ検証する歴史的同一年内の再解析**である。
- **保留週内の実測した前15分のYを予測に使っている**のでオンラインの条件付きnowcast、週開始前の予測ではない。
- GPS位置の実際の干潟露出・水深・餌密度、鳥が見ている局所潮流をモデルへ入れていない。港の潮位はGPS位置から最大25km離れた代理。
- 真潮位の5追加項（水位＋上昇下降＋水位×phase＋夜×水位／phase）の総合情報であり、**潮汐×太陽交互作用だけの係数が同定できたわけではない**。
- タグ行動は元分類アルゴリズムの\`forage\`/ \`inactive\`事象割合で、実際の摂食や獲物量ではない。
- 群れの個体間距離、近接個体の方向、凝集の再現性を直接測定しておらず、**Boidsの分離・整列・凝集の実動物社会力を同定したわけではない**。

## 4. より普遍的な生態学的予測への含意

時間ニッチの組織化は、①地域に共通した環境周期（太陽・潮汐など）、②個体自身の行動状態が直近から持続すること、③個体間の相互作用、の**別々の層**に分けられる。今回の同じタグ鳥のSOURCE結果は、特に①潮汐位相の情報と②行動分類状態の持続が**2018と2019で同時に予測的に寄与**し得ることを支持する。

ただし現在の3つの海洋音響データ系は音型ラベル・センサーデータの意味とsourceの無記録時間が違うので、この2つのミヤコドリ年のMSE減少をCalifornia/Roscoff/ネズミイルカのlogloss減少と全球単一係数としてプールしない。全球の潮汐×太陽の直接生物学的機構は依然未同定。

**次の決定的な独立テスト**：1) 2018のみで学習したモデルを2019の鳥へ投影する真の年外予測（動物IDの重複と未知IDの処理を結果前に固定）、2) 実GPS地点の地形DEM・局所の実潮位をsource校正して潮位→干潟アクセス可能面積へ接続、3) 別海岸の複数個体データへ再現、を分けて計画する。SOURCEが無ければ生態因果は主張しない。
