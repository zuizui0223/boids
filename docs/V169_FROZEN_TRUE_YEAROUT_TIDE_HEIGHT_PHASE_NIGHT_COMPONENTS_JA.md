# v169｜2018年のみに学習したミヤコドリモデルで、2019年の潮位「高さ・上げ下げ・夜間依存」を実測原本から分解する（結果前仕様）

2026年11月17日。v168では、同じVlieland *Haematopus ostralegus* 標識個体の2018年GPS/ACC元分類とRWS港湾実測水位でRidgeを**2018年だけ学習**し、2019年の真正な125,241個体×15分観測ビンを全年保留して比較した。直前15分の自己行動分類を追加するとMSE +0.080300の改善、実測潮位5項を追加すると+0.007557の改善だった。しかし、真の潮位位相と3/7/11日ずれた元実測水位の最良対照の差は**+0.001509**、同じ統計量の週単位記述的95%区間 **[−0.000323, +0.003282]**。ゆえに「どんな潮位条件が予測情報を持つか」を次の関心として、新しいv169効果を開く**前**に以下を固定する。

## 対象SOURCEと物理観測の契約

- 元の[Zenodo O_VLIELAND corrected 10053988](https://zenodo.org/records/10053988)の2018・2019年GPS＋加速度計分類元データ、Rijkswaterstaat *Vlieland Haven* の実測2018/2019年6–9月の港湾水位を元のプロバイダから再取得し、元v128/v129/v126/v127の本物元MD5＋RWS月別レスポンスSHAを原本と一致確認する。
- 元v168の凍結したSOURCE分母 **2018年157,863個体×15分実測連続bin**を学習に使用し、**2019年125,241個体×15分実測連続bin、27標識鳥、17暦週、昼81,408/夜43,833**を完全保留する。SOURCE binは元ACC earliest eventをUTC15分境界へ切下げて再構成し、同じ個体の前binが本当に記録されている場合だけ使用する。元GPS/ACC欠測を行動割合0として埋めない。
- 2019年のSOURCE Yはどのモデルの係数、正則化、補助パネルやSOURCE絞り込みにも使用しない。**ただし予測時点に実観測された2019年の同個体前15分Yは説明変数に入力する**。これはオンライン条件付き分類（nowcast）であり、2018年末から2019年全行動を予報したものではない。
- **2019年新鳥がいても転移可能な主パネル**のみを扱い、元v168と同じく鳥ID固定効果は学習2018・試験2019の両方から取り除く。元v168の既知鳥パネルは共通17羽が先に固定した必要20羽を満たさずSOURCE_STOP済み。このv169で再入場させない。

## 6つの元RWS物理項パネル（結果を見る前に固定）

時計・月・GPS位置の天文昼夜＋同じ鳥の直前15分ACC事象分類割合を**全モデル共通のHISTORY**とする。

元RWSの5項のSOURCE列順は \`[height, phase, height*phase, night*phase, night*height]\`。ここで**height**は実測の港湾基準の水位、**phase**は上げ潮/下げ潮の方向符号（±1）、**night**は元GPS地点の天文学的昼夜ダミー。これらを以下の6パネルに分解する。

| パネル | HISTORYの後に追加する物理項 | 何を診断するか |
|---|---|---|
| HEIGHT | height | 水位だけ |
| PHASE | phase | 上げ下げだけ |
| HEIGHT_PHASE | height, phase | 2軸の加算 |
| HEIGHT_PHASE_CROSS | height, phase, height×phase | 水位と上げ下げの結合 |
| HEIGHT_PHASE_NIGHT | height, phase, night×phase, night×height | 昼夜によって水位・潮位方向への応答が変わるか |
| FULL | **height, phase, height×phase, night×phase, night×height** | 元v168の5項すべて。元v168の2019年全体MSEと**完全一致させる** |

**各パネルで真の2019年RWS時刻0日と、3/7/11日ずれた同じRWS元実測**を4つ用意する。高さ・上げ下げだけのパネルにも同じ数の誤位相対照を用意し、共通のSOURCE Yと元2019年15分観測ビン上にスコアリングする。各パネル内で真の水位と誤位相は**完全に同じ説明変数数**、パネル間では変数数が異なるので後者を「独立の因果効果量」と呼ばない。

モデルはv168と同じRidge λ=20（インターセプト無罰則、元尺度、出力0–1クリップ）。**2018年のSOURCEだけで各モデルを一度学習し、2019年のSOURCEに再学習せず適用する**。新しい手法の後選択・チューニングなし。比較するMSEは元2019年の各週で各鳥の平均を取り、鳥等重み→週等重みするv168の評価関数と同一。

## 元2019年保留の固定した効果量と負対照

1. **HISTORY→各物理パネル**：\`MSE(HISTORY)−MSE(HISTORY+panel at true t)\`（正＝元2019年の予測改善）。
2. **同一パネルで真のRWS時刻と誤時刻の比較**：\`min_{3,7,11} mean_week MSE(panel with shifted RWS)−mean_week MSE(panel with correct RWS)\`。正なら「正しい元RWS時刻のSOURCEの予測MSEが、そのパネルの3つの間違った時刻の最良より低い」。
3. 元SOURCEのネストした診断：HEIGHT→HEIGHT_PHASE（phaseを加える）、PHASE→HEIGHT_PHASE（heightを加える）、HEIGHT_PHASE→HEIGHT_PHASE_CROSS（height×phase）、HEIGHT_PHASE→HEIGHT_PHASE_NIGHT（夜間の2交互作用）、HEIGHT_PHASE_NIGHT→FULL（高さ×phase）。**これらの正負がそのまま独立要因の因果的寄与率を意味するわけではない**。
4. 本物のSOURCEの週ベクトルを固定10,000回再抽出し、元の真・誤位相点推定と**同じ統計量**になるよう、各再標本化で全週の各モデルMSE平均を出してから最良の誤位相を選ぶ。これは**同一海域2019年の記述的区間**であって、新しい独立集団や因果推定の95%CI／多重p値ではない。17週の正方向数もすべて記録する。

## 日夜・個体・季節でのSOURCE感度（結果を見ずに固定）

同じ**2018年のみで学習した係数**を一切変更せず、2019年の実SOURCE観測を次の8パネルへ分解してスコアリング：DAY、NIGHT、2018年にもタグがいた既知鳥、2019年だけの新鳥、MONTH_6・7・8・9。全モデルの元Yと元2019年時刻は各パネルで共通。閾値は各SOURCE部分群≥1,500件、異なる元2019年週≥2（SOURCEのみの条件）。全パネルの正負とSTOPを公表し、有利な月だけを主結果へ格上げしない。

この**月別パネルの区間は異なる同じSITE×週の部分SOURCEなので元年間区間とは別**。複数月の効果量の平均を新しい独立4研究として扱わない。また夜間の記録と干潟水深・餌の活動は直接同じ変数ではない。

## 判定できること／できないこと

- **予測として言える**：2018年でのみ学習した係数を2019年へ運んでも、元の実測港湾潮位の高さや上げ下げ、または夜間との交互作用のどのブロックが、同個体の実際の直前行動分類を説明した後にSOURCE保留MSEを減らすか。
- **まだ言えない**：「高潮位によって餌が取れなくなった」「干潟干出面積の縮小が原因」「動物が内因性の潮汐時計を持つ」「夜×潮位が直接選択圧を生んだ」。観測点は港湾実測ゲージで、動物GPS地点（最大25km）での実水深・地形DEM・干出面積・餌密度を測っていない。
- **負対照の限界**：誤潮位シフト3/7/11日は、天文潮汐の周期性・季節性を残す。これは交換可能な完全ランダム化帰無ではなく、位相固有性を試す頑健性診断。
- **個体間Boidsの分離/整列/凝集**：このモデルは元タグ鳥の自身のACC履歴のみを使い、他鳥の位置・方向を説明変数にしないため、まだ同定できない。
