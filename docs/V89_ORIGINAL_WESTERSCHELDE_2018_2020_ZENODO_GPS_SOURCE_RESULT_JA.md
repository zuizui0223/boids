## 3. 別地域での物理データの候補と、今回の解析の科学的な上限

独立した**潮汐環境の候補**は、オランダRijkswaterstaat公式の**Vlissingen湾口観測所`vlissingen`**（RWS `OW/WATHTE/meting` 10分 cm NAP）である。また**2018年の西スヘルデ河口の塩性エコトープ地図**がRWSの公開地図として登録され、以前のWadden海の2008〜12年WMRカテゴリ地図を代用せず地域独自の面積・干出分類を構築する可能性がある。しかし**今回v89では観測所2018/19年の元実測潮位時系列も、地図ポリゴンの元分類も未取得・未検定**であり、絶対標高や実際の干出／採餌、潮汐位相の予測に使ったという説明はしていない。

元の固定仕様は2018／2019年それぞれ**本物の8羽以上、3か月以上5羽が共存するGPSソース月、2,000GPS時間位置以上**を要求し、**2018年の6羽／2か月、2019年の2羽／0か月**で不成立。だから**当該外部河口について2018〜20年の潮汐×日照の4条件Dや、個体クラスタの95%区間は未推定**であり、鳥が無反応なことを意味しない。

## 4. 普遍性の研究に向けた判断

今までの元ワッデン海2島GPSの2010年：
- **潮汐×太陽の実測物理的時間機会**は真のRWS二測点で検証され、日長だけでは説明しきれない。
- Schierでは**WMR地図の中位・高位潮間帯にGPSが記録される割合**の上げ下げ×昼夜D **−5.62パーセンテージポイント**（実際18羽鳥bootstrap95[−7.70,−3.58]）が探索的に支持された。
- 同じSchierで**月別NIOZ曝露モデル位置の順位Dは正**。異なる応答指標なので直接の矛盾ではない。
- Amelandでは同種のGPS干潟内割合D−2.04ポイントは区間がゼロを跨ぐ。両島のD差も区間ゼロ跨ぎ。
- 2011年に同じWadden海サイトの新しい未観測の鳥はどちらも0羽だった（元v87）。
- 別海岸・別4種の中国Leizhou元2019–21 GPS／生息地地図は元2026 Dryadメタデータまで取得できたが、実データが公開APIで**HTTP401**（元v88）。今回の西スヘルデは別河口の**生GPSは真正に取得**できたものの、個体×同じ月の源データを4条件で比較するための個体数が不足した。

**したがって現在の結論は「潮汐×明暗の特定の生態反応が複数海岸・複数種に普遍である」と言える段階ではない**。むしろ「独立の元野外GPSの取得可能性と、独立鳥数・現地の真の実測潮位・同年地形の3条件をすべて満たす研究地点を事前に選ぶ」という、検証可能な生態学的普遍性プロトコルが必要だと確認できた。
