# v41 — 元GPSで、別個体の直前の移動方向を利用可能な「時刻」は十分ある

**2026-10-31 JST。公式元GPS ID/UTCだけのオリジナル-source適格性結果。** これまでの潮汐・速度・方向結果（v33–v40）は既に既知であり、これは**新しい社会的Boids効果でも、鳥同士の接近を観測した結果でもない**。元資料の動物の位置・速度・進行方向・生の潮位値は本検査で一切読んでいない。

## 対象元資料と条件

元Zenodo 10053970 v4、`O_SCHIERMONNIKOOG` GPSの2008–2014全7原gzip、既報の公開元MD5と当初source-only SHA256一致。**602,396原CSV行、39源個体ID、visible/manual outlier QC除外16行、重複ID×UTC 0、602,380元個体時刻行**をチェック。元測位の個体ID・UTC時刻・visible・outlier以外のCSV数値を読み取らず、元個体ID・実際の動物時刻の配列を出力しない。

前のv39/v40と時間だけを一致させた、同じ鳥の4つの別の元GPS時刻`i−2,i−1,i,i+1`（過去区間5～30分、予測開始までのgap5～360分、未来実観測区間5～30分）に限定。これらの元GPS候補の開始時刻`t_i`で、**別鳥**がその時刻までに観測を終了した5～30分の**過去の2GPS点**を持ち、最新の観測時刻が`[t_i−5分,t_i]`にあるものを数えた。これにより未来の他鳥GPSは使わない。

ただし今回は**個体の実位置を一切開いていない**。同じ時間に違う場所にいた鳥、数km離れた鳥、集団外の鳥も候補に入る。この値は、将来の「同時空間的な隣人情報」解析へ進める可能性の**明白な上限**であって、実際のsocial nearest neighborにはならない。

## 今後の強い必要条件

次の新しいプロトコルでは、同じ時刻に**位置が1km以内**だったなどの事前固定ジオメトリ制約と、元v40の同一鳥の潮汐・速度・方向を使った**V1基準**の上で、他鳥の過去方向を加える将来月予測を比較する。空間的な元source支持が少なければスコアを出さずにSTOP。GPS同期の偏りや共通潮汐が他鳥の方向を揃える可能性を評価する対照も別途固定しなければならない。

**このv41の肯定結果は、Boidsの社会的力の証拠ではなく、データ適格性の肯定結果である。**
