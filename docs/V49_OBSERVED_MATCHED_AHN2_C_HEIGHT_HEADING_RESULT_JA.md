# v49 野外原本結果：AHN2標高が取得できる同一GPS区間では潮相の方向予測増分も頑健ではない

**2026-11-05 JST。生態学的な正負双方の結果を固定。** [v49事前仕様](V49_FROZEN_MATCHED_AHN2_DIRECTION_ELEVATION.md) はこの新しい照合結果を開く前に固定。ただしv43/v44の全移動区間方向予測の肯定結果とv48のC標高予測の弱い/否定結果は既知だったので、厳密には**結果を受けた探索的な条件別再解析**である。

## 原本観測と同一分母

2010年元GPS（O_SCHIERMONNIKOOG / O_AMELAND、Zip提供者MD5+独立SHA）だけから選んだ固定K=8の2km AHN2 WCS地形タイル、EPSG:28992横軸/提供元NAP高度候補。2011年の元GPS三点A→B→C（両間隔30–120分・各区間0.4〜120 km/h）におけるAHN2有効な到着点Cの静的標高 `z(C)` と、**同じ源Cを行先とする元の次進行方向（東・北の単位ベクトル）**を厳密に対応付けた。原本個体・B時刻・B位置・過去方向/速度が完全一致しない記録はSOURCE_STOP。元v41次方向予測とv48到着標高予測を**絶対差1e−9以内**で再現するゲートに成功。GPS原本や鳥ID、原本地点は公開していない。

RWS観測点は島ごとに固定した `schiermonnikoog.waddenzee`・`ameland.nes` で、2009/2010/2011各年52,561件の実測10分 `WATHTE meting` NAP cm → m。M0はB位置・日時・潮位とその二次項・過去方向/速度、Mrealは潮相・潮相×潮位を追加、Mghostは同一観測点の前年潮相（現在水位h(B)はそのまま）。2010学習、2011完全未使用年のテスト、両標的とも**同じ訓練GPS・同じテストGPS区間・同じ説明変数・同じ個体均等重みridge λ10**。潮相を説明変数に使っても目標値 `z(C)` は独立に得られたAHN2標高であり、潮位から計算した「乾湿」ラベルを使っていない。

## 科学的含意の整理

**以前の肯定結果を維持する。** v43/v44の2011元GPS全移動三点区間ではSchier 4,948例で潮相を入れると方向予測誤差−7.89%、Ameland 4,678例で−14.91%（減少）を確認している。しかし、その同じ鳥のAHN2有効なC標高が得られる**一部の経路**（Schier 1,009例、Ameland 1,238例）だけに限定して**再学習・再評価すると**、潮相の次方向追加予測値はともに頑健ではない。

これは「方向は地形高度と無関係」と確認したわけではない。主な可能性：(i) AHN2に標高がある場所は地上/海岸近くの一部に偏り、干潟や水面側は大量の欠測、(ii) 限定によって鳥・週・移動方向の組成が変わる、(iii) 全GPSで学習した係数と選択subsetで学習した係数が変わる、(iv) 真の局所潮汐前線は地形高度だけでなく流路・浅瀬の流体・資源供給で決まる。**この段階でどれが原因かは判定できない**。

**次の決定的な追加監査**：2010年の**全移動GPS**でM0/M1方向モデルを一度だけ訓練して固定し、2011年同一テスト原本をAHN2のC標高「有効」「2010固定区画内だが欠測」「2010区画外」に分け、同じ固定モデルの予測改善がどの観測範囲で大きいか確認。これなら元のv43モデルと完全な数値再現ゲートがあり、再学習の影響とテスト対象制限の違いを切り分けられる。ただし欠測マスクは生息環境の種類を直接表さず、同じ鳥同士の条件付き比較・季節/空間一致偽対照が必要である。

**原因の未実証**：実際に露出した干潟、可用餌、局所潮位の遅れ、GPS時刻標準、AHN2測量年/水面欠測、社交的Boids steeringと種間ニッチを同定していない。どの肯定結果も独立した別種/別地域の反復ではない。
