# v132 global tide×solar evidence search — period-stratified source-screen contract

Frozen 2026-11-14 JST **after the 2018 Vlieland v130 outcome and v131 study discovery** but **before any v132 stratified retrieval/screen counts**. This is a prospective *search-method/quality* contract, NOT a preregistered ecological effect hypothesis. V131 first wave: seven queries capped at 35 each produced 197 DOI/title-unique metadata entries, **121 (61.4%) are publication year 2026**, a strong publication-time search bias. It is scientifically invalid to generalize that initial bounded list worldwide or claim 197 independent biological results.

### Planned improvements
- Run genuine original Europe PMC REST `search?format=json&resultType=core` searches within **six independent eras** 1970–1999, 2000–2009, 2010–2014, 2015–2019, 2020–2024, and 2025–2026.
- Within each era run **six predeclared functional group text queries** (shorebirds/spoonbills, seabirds/gulls, fish, coastal crustaceans/horseshoe crabs, molluscs/barnacles/other benthic invertebrates, insects/mammals/other coastal vertebrates). The tide and sun/circadian/diel terms are required in search terms; search is broader than an already-tide-specific positive list.
- Maximum 40 original metadata records per group/era query with original DOI/PMID/title/abstract; 36 source query outcomes plus source errors retained, never silently replace an empty search group. Merge with v131 original 197 candidates; DOI preferred, normalized-title fallback, track original query groups and original publication year. Nontrivial preprint–final-DOI aliases may remain; require future manual de-duplication and data-identity audit.
- **Automated abstract triage is NOT full-text eligibility**: coarse classes `possible_field_tide_solar`, `possible_field_tide_only`, `possible_clock_lab`, `possible_review_theory`, `uncertain_relevance`, and `unrelated`. Each result carries rules/reasons and source query only; never an effect/SE. Do not silently exclude negative studies. Prefer a **high-sensitivity** screen whose uncertain category is reviewed.
- Preserve title/source URL/DOI/year/journal and a *short leading abstract snippet* for permitted later manual screening; do not export entire copyrighted abstracts. Source file records citations and metadata, not raw measurements. Never assume animal/taxon identity from a lone keyword or infer sample size from paper count. Previous v131 targeted 10 papers are separate curator seed candidates; they do not add independent field effects automatically.
- Stop when publisher source data inaccessible; preserve partial query-level coverage and **label incomplete**. Do not claim PRISMA-complete systematic review without at least two manual title/abstract and full-text screeners, reference chaining, preprint collision reconciliation and effect source extraction.
- **No pooling until comparable endpoint×metric verified original effect and SE, independent study clusters and method coverage**. This contract includes both H1-positive and H1-negative cases.
- Track categorical reason why some papers are not quantitative: day-only; tide-only; tidal clock lab-only; tide proxy too distant; species/season or tags shared; incompatible endpoint; insufficient per-study variance; private data; tide+sun collinear; tide sampling phase unobserved.

### Five preidentified high-value primary-source comparisons
(1) 2025 Tagus vs Ria Formosa Portuguese juvenile spoonbill (two wetland clusters, **one study**, same species, source tag duty-cycle differs), [DOI 10.1007/s12237-025-01598-x](https://doi.org/10.1007/s12237-025-01598-x): feeding in intertidal flats mean 47.16%/62.09% of behavior **within habitat**—not fractions of all feeding time; rice-field feeding activity 52.27% similarly within-habitat. Model-selection interpretation should use original GLMM and no invented standard errors.
(2) Florida Indian River Lagoon 2024 microtidal horseshoe crab spawning abundance [DOI 10.1371/journal.pone.0302433](https://doi.org/10.1371/journal.pone.0302433): global negative binomial tide coefficient **+1.978, SE 1.776** with 95% CI [−1.503,5.459], tide not strong; wind direction is important. One same lagoon/two survey sites, day-night variation not fully evaluated; tide physical effect does not necessarily dominate microtidal wind-driven surges.
(3) 2017 Dutch red knot 42 individual telemetry [PMC5647280](https://pmc.ncbi.nlm.nih.gov/articles/PMC5647280): 88% tidal distance-to-roost periodicity, 57% daily, 52% both, after >50 h GPS; percentages are not standardized tide magnitudes or external independent species effects.
(4) 2026 red knot high-throughput ATLAS Dutch Wadden low-tide day vs night [DOI 10.1111/ibi.70126](https://doi.org/10.1111/ibi.70126): 2018–2022 bird-years samples 36,23,7,24,18 (possible repeated birds), *only low tide* compare spatial niche area and residency; data on request, tracking code Zenodo. NOT evidence for adding tidal predictor vs no-tide baseline, and not independent of any related Wadden tracking dataset without study/network audit.
(5) Prior v130 genuine O_VLIELAND 2018 temporal CV 35 tagged birds, 193088 bins, true stage beats +3/+7/+11 ghost in one site, but constructed after seeing v129 source effects; field single-coast pilot not cross-taxon meta.

### Target conclusion
**Which environmental *opportunity channels* make true tidal information independently predictive, and when does this translate to ecological time×space partition?** Predeclare habitats accessible across tide, wind surge in microtidal systems, current vector, nocturnal prey and predation, and detection bias as competing moderators. Do not flatten multiple mechanisms into "positive vs negative tide effect" without endpoint and unit comparability. No promised positive global estimate.
