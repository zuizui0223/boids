# v158：6大地域・43観測点のネズミイルカ音響データを全球時間ニッチ解析へ入場させられるか

2026-11-15。先行のCalifornia（9録音地点）とRoscoff（1録音地点）では音響タイプの追加予測情報を検証したが、これを全球の一般化へつなぐためには、**別の動物群で、実際の録音機器稼働機会と非検出が確認できる公開データ**が必要。

候補：[Stavenow Jerremalm et al. 2025, Ecology and Evolution DOI 10.1002/ece3.72566](https://doi.org/10.1002/ece3.72566)。NE Atlanticのネズミイルカ（*Phocoena phocoena*）C-PODクリック記録を**43原観測点・6研究地域・2009–2023年**にわたって解析。公表のData S2 CSVは約25.2 MB。元論文では日周・日長・SST・塩分・生産力との関連を検証済みなので、これらを新規発見とは呼ばない。

## なぜ即座に全球メタ解析しないか

元の「クリックを検出した時間」だけがCSVにあっても、「C-PODが稼働していたがクリックを検出しなかった時間」が全て載っているとは限らない。**欠損行＝行動不在という誤りはRoscoffの59時間の潮流雑音マスクでも問題だった。**

したがって、v158は音型や音響予測の効果をまだ計算せず、まず**元のData S2を正式Europe PMC supplementaryFilesで取得できるか**、CSVの元SHA256・行数・列名・欠測率・値が数値かどうかを取得する。新たな生物学的p値・傾向は算出しない。元25.2MB CSVは再配布せず、source-safeなスキーマとカウントだけを保存。

## 予め必要な入場ゲート

1. 原本CSVの正式サプリメントを検証し、source content SHA256と生の列名を保持。文献にある43観測点・6地域が実際に列で識別可能かを確認する（列名の文字列だけで証明済みとしない）。
2. 本当に時間印・年・月・観測器site/deployment IDが存在するかを監査。**時刻の一意性/タイムゾーン・連続性・観測努力の明示的記録は次の段階で原行値に基づき検証**する。
3. 捕食buzz、一般echolocation、無音、C-POD OFFなどが明確な観測意味を持つか、検出済み行だけか、全年の連続空時間があるかを検証。「buzzが0」は未捕食行動とは限らず、clickがないのか機器が止まっていたのかの区別が必要。
4. 閾値の異なる地域/機器と本当の生物個体の違いに注意。43地点は43の独立した生物種ではなく、元論文は1種の6地域。別魚類の音響タイプPS/LPS/Bocaccioと生物学的な測度は同じではない。
5. 物理潮汐や月光を後で取り込む前に、各地点へ本当に水位や潮流の時間帯を割り当てられるか確認する。天文の時計、音響状態の持続と別音響イベントの3層を、無理に統合する前に素材の可否を判断する。
