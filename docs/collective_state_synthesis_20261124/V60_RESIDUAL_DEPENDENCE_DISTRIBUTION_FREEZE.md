## Four stochastic residual regimes (8 replicates each)
1. pooled_iid: exact v59 M0 pooled training residual bank, same seed, same per-fish/time independent draws.
2. light_iid_centered: M0 training residuals from only the test illumination; subtract their pooled 2D vector mean across fish and times. Independently sample residual vectors per fish/time.
3. light_group_centered: same centered residuals, sample simultaneous three-fish vectors at an original group time, permute fish labels jointly with a uniform random permutation per simulated time. This retains simultaneous group structure but not temporal dependence.
4. light_block_centered: same centered residuals, draw length-five consecutive group-time blocks (1s) from same-illumination training recordings, only native 6-frame-contiguous times, never crossing recording or gap. Apply a uniform fish permutation fixed throughout each sampled block. Block starts uniformly sampled from all eligible original starts. Preserves within-block temporal and group dependence; breaks longer-range dependence and identity links across blocks.

All residual banks use the fully shared M0 fitted on the identical train set, common across candidate masks, not each model's own residuals. Subtract mean only for new same-light regimes so their mean is not intentionally a separate treatment-specific drift. Finite draw means/variance can differ; block sampling marginal weights not exactly identical to individual-time sampling. Fixed seed derived from SHA256 of regime, heldout ID, training IDs; same innovations across masks. Exact v59 seed for pooled_iid. No outcome-dependent fitting of noise or covariance. Only train residual counts and aggregate noise diagnostics exported. No raw positions, fitted coefficients, or residual vectors exported.
