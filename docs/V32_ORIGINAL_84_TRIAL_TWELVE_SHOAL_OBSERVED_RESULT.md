- 元84 TXT全件のEIDC index公表サイズと取得した原バイト数を照合し、元ファイルSHA256を各々計算。前回から元SHAを独立固定した01/02/105の3件も完全一致。81件について**EIDCが配布元MD5を公開したとは主張しない**。元コードは個体位置や正解の時系列をGitHubへ複製せず、各録画から回帰の十分統計量へ変換した。
- 学習・標準化の十分統計量方式は独立の**8件の人工既知正解テスト**でsklearn実装と検証。**以前の3原録画に対してv30の6モデル×2未来窓MSEが元数値から最大0.01の範囲で完全再現**できた場合のみ84録画モデルに進む。[v32数値バックエンド凍結仕様](V32_MOMENT_BACKEND_KNOWN_TRUTH_AND_V30_REPLAY_GATE.md)。

## 12実験群の元魚実測結果

以下のI(ell)は、Gのみの誤差MSE_G、現在群れ速度を加えたMSE_0、ell秒前の群れ速度を加えたMSE_ellより、`I(ell)=(MSE_G−MSE_ell)/(MSE_G−MSE_0)`と算出した**モデル特異的な追加的予測改善の保持率**。相互情報量・実際の魚の情報共有率ではない。

| 本物の元12群で検証 | 0〜0.2秒後の予測 | 0.6〜0.8秒後の予測 |
| --- | ---: | ---: |
| GのみMSE（元pixel²/s²） | 3407.0695 | 8925.0302 |
| 現在群れ速度を追加したMSE | 3344.9188 | 8479.9969 |
| 現在の群れ速度の追加でMSEが減少 | **1.824%** | **4.986%** |
| 古さ0.2秒の群れ速度による保持率 I(0.2) | **0.8502** | **0.8198** |
| 古さ0.4秒 I(0.4) | 0.6973 | 0.6694 |
| 古さ1.0秒 I(1) | 0.3634 | 0.3984 |
| 古さ2.0秒 I(2) | 0.1537 | 0.1881 |
| 最初の測定点 I≤0.5 | **1.0秒** | **1.0秒** |
| MSE(0.2秒前) > MSE(現在)の元Group数 | **12/12** | **12/12** |

すべての**12個の独立な原実験群**について、同じGと将来の正解を使ったとき、現在の他個体速度は0.2秒前・0.4秒前・1秒前・2秒前のいずれよりも予測誤差が小さかった（両未来窓、各比較12/12）。未来短期の「0.2秒前−現在」MSE差の群等重み平均は**+9.31195 pixel²/s²**（事前規定の5,000回・12群単位の記述的bootstrap 95%区間 **[7.3073,11.5806]**）。遅延は**+80.18209**（**[70.2964,90.8842]**）。これらは学習foldが重なり合う交差検証であり、独立母集団の名目的な信頼区間として解釈しない。

旧v30探索的な3録画での保持率I(0.2)=0.7829/0.7771に対し、群の完全除外・元84ファイル・12群平均では0.8502/0.8198となった。結果の方向と比較的遅い減衰は再現したが、値の差は**学習データ量、群等重み化、source cohort**が変わったものでもある。種間の有意差と解釈しない。

## 事前仮説への**反証的結果**：情報強度と情報持続性は普遍的なトレードオフではない

研究間ではテトラ・アユ・トゲウオで追加的予測改善の**強さ**と古さに対する**保持率**の大小が一致しなかった。この二指標を、トゲウオの同じ12実験群内でも比較した。元Groupごとに
- 強さ S_g = (MSE_G,g−MSE_現在,g)/MSE_G,g
- 0.2秒古い群れ情報の保持率 I_g(0.2) = (MSE_G,g−MSE_0.2,g)/(MSE_G,g−MSE_現在,g)
を固定し、元Group12個でSpearman順位相関を計算。全12群で分母は正であり、事後的な削除・再符号化なし。

| 事前予測「強さと保持率の順位相関は負」 | 実測Spearman ρ | 結論 |
| --- | ---: | --- |
| 短期未来 | **−0.1748** | ごく弱い負の順位相関、記述的のみ |
| 遅延未来 | **＋0.1608** | **予測方向に反する**ごく弱い正の順位相関 |

**両未来窓で一貫する負のトレードオフは支持されなかった。** 本研究で今後論じられるのは「情報の強さと時間持続性は**区別すべき二軸**」ということであり、「一方が強い集団では必ずもう一方が弱い」という機構の成立ではない。n=12の各原実験群に対してここで人口一般の有意性を主張しない。

## 解釈の上限と将来の生態学的検証

**明確な肯定結果**：元トゲウオ研究の**12本当に異なる実験群**へ外挿しても、群れの現在速度の追加的予測力が古い速度より高く、0.2秒前でもその追加的改善の82〜85%が残るという、source-conditionalな**比較的長い時間的持続性**が確認された。

**言えないこと**：その持続時間が魚の感覚・記憶の半減期、個体間の因果的追従、社会的相互作用による伝播、進化的種差だとは同定できない。タンク共通の水流・餌刺激・追跡平滑化など**社会相互作用ゼロでも古さ依存の予測差が生じる**。またPuyとNiizatoの源泉研究とは環境・追跡過程が異なり、正式な3種メタ解析や各種の独立野外個体群一般化はできない。音響行動データがないため、魚類コーラスの個体発声とBoids運動の因果的な連結は未検定。

**次の実証の鍵**：実環境の共通水流・餌投入時刻・群れの向きなどを同一群で独立に観測／操作し、自然群・実験群ごとの学習外ホールドアウトを維持して残差的な隣魚影響が再現されるか検定。潮汐・日照・発声と接続するには、群運動と音源を**同じ時間軸・発信個体レベル**で記録する必要がある。
