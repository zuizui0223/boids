# v92 | 潮汐×太陽による時間ニッチ組織化：二つの時計、利用可能性、行動の条件付き統合理論

作成：2026-11-09 JST。既存の原本結果を**再計算なしで監査し、2026-11-09時点の独立文献を照合した機構的統合**。新規のUHSLC 2019原毎時水位×太陽高度解析は別の \`validation_v92/\` で走査する。そこで生じる **SOURCE_UNAVAILABLE を「生物学的な零効果」と書かない**。見えていない結果をここへ補わない。

## 中心課題
> いつ、どの沿岸・どの分類群で、潮汐と太陽という別の周期が生物の活動・利用空間・種間の時間ニッチを組織化するのか。その強さが、潮汐型・地形・採餌様式・季節・代替資源・社会性によってどう変わるのか。

### 概念上の新規性を置く位置
「生物が潮汐にも太陽にも応答する」は既知。「同じ潮位・同じ日長でも時間的位相が違えば異なる機会が生じる」も物理的に当然。**検証すべき新規性**は、異なる地域・種にまたがって、(1) 実測の利用可能性の切替がどれだけ強いか、(2) 利用可能性と活動/利用地点の連鎖のどこが種特異的か、(3) 外部独立種・海域の結果を説明・予測できる条件を予め定義して成功/失敗を説明すること。

## 機構の3層・時計の複数階層

**L1 / 外部物理周期**：太陽高度・日長・日の出入り・季節、月-太陽起源の潮汐各分潮 M2 約12.4206h、S2 12h、K1 約23.934h、O1 約25.819h。M2とS2の位相差が約14.77dの大潮小潮包絡と関連する。太陽は *光の生理・温度* と *潮汐形成への重力寄与(S2)* の二つの独立した意味を持つ。**日長は潮汐を単独で駆動しない**。局所水位には気圧/風/波/河川/海岸地形が加わる。

**L2 / 実際の生態的機会**：沿岸セル x の地盤標高 z(x) と局所水位 h(x,t)、食物/リスク、昼夜の実照度を別ソースで観測する。干出干潟を使う種では \`A_i(x,t)=1[z(x)>h(x,t)]\` を基本にするが、水深の浅い水面を使う種では \`A_i=1[0<h-z<d_{i,max}]\` とし、他の種では潮流・塩分・溶存酸素などを利用。観測所の水位Q25は **地盤zそのものでも干出面積でもない**。補助機会 \`U_i(x,t)=A_i(x,t) × f_i(餌,太陽/光,捕食リスク,潮流)\` を作る。GPSの点をこのUの推定と混同しない。

**L3 / 生物の実現時間ニッチ**：\`P(H_i(t)=1 | U_i(t),状態_i,気候,検出過程)\` ＝潮間帯への入域/活動段階、\`P(x_i(t)|H=1, U_i,移動履歴,競争/捕食)\`＝入域後の行動/空間選択段階。観測は \`P(detected | real activity, sampling schedule, tag failure, night)\` を通る。同じ実測潮汐と明暗でも別の応答が正/負になりうる。いずれの段階も「実際に餌を食べた」ことを必ずしも示さない。

**L4 / 内因性時間追跡**：概日約24h と概潮汐約12.4h の時計が同じ個体内で独立に存在または相互作用する可能性。GPS時刻との相関だけでは体内時計を同定できない。一定環境での持続/周期刺激実験が必要。

## 主張を機械的に分離する指標

- **P1 外的ゲート**：独立した元潮位 \`h_s(t)\` に対し \`Q_{s,y,0.25}\` 以下を「低水位相対状態」と固定し、天文太陽高度 \`α>3°\` を昼・\`α<-3°\` を夜とする。\`O_{s,d}=時間(低水位∩昼)/時間(低水位)\`, \`A_{s,d}=時間(昼)/時間(有効測定)\`, \`M=O-A\`。\`M\` の**年平均符号だけ**を主張しない。独立する二周期の相対位相がゆっくり変わるため、時間平均が0でも \`E(|M|)\`, \`Var(M)\`, 成立機会の日別範囲は非ゼロになりえる。完全な太陽周期/潮汐周期を保った位相ずらしnullと比較して、単なる周期幾何学に過剰な「シグナル」を与えない。
- **P2 潮汐型**：4分潮振幅比 \`F=(K1+O1)/(M2+S2)\` で半日周(<0.25)、混合半日周(0.25–1.5)、混合一日周(1.5–3)、一日周(>=3)に分類。**Fは潮差の大きさではない**。潮差、干出地形傾斜、最大連続利用窓、低水位×昼重複を別指標にする。
- **P3 二段階生物反応**：潮汐×昼夜4セルで、\`D_Y=(Y_{flood,night}-Y_{flood,day})-(Y_{ebb,night}-Y_{ebb,day})\` を個体×月×実測水位帯で計算。Yが「GPS干潟内/外」か「選択位置の曝露モデル順位」かで別の科学的量。前者と後者の符号は一致不要。動物の実測活動・食物摂取・生存はまた別のY。
- **P4 反事実の活動時計**：\`M0=潮位/潮相 + 太陽高度/日長 + 位置 + 季節 + 個体移動履歴\`。 \`M1=M0+固定した潮汐×太陽交互作用/外部資源窓\`。\`Mghost\`は誤った時差で位相を置換。固定された別年、未学習個体、未観測種、別海盆への予測利得を同じ観測Y・適切なproper scoreで評価。**1地域・同種からの意味のある科学的交互作用が、未観測種の予測に必ず改善を与えるわけではない**。
- **P5 種間時間ニッチ分割**：種iの環境状態条件付き利用密度 \`p_i(phase_tide,phase_sun | effort,site,season,available habitat)\` を推定。種間の距離（例えばJensen-ShannonまたはSchoener D）を計算し、単純な全時間の出現数差/検出機会差と比較。潮汐日が太陽時刻に対して動くため、**日内24hヒストグラムだけでは潮汐位相の分割を見逃す**。種間競争の因果を主張するには餌場共有・相互作用の直接観測が必要。

## 最重要の、反証可能な条件付き仮説

| id | 条件 | 予測される時間ニッチ | 反証・境界 |
|---|---|---|---|
| H1 物理ゲート | 日潮差と潮間帯の地形傾斜で干出/水深窓が十分変わる | 高い日別/季節別アクセス窓の変動 | 潮差大でも浅場面積が変化しない場合は弱い |
| H2 二つの時計 | 低水位と日照が非同期 + 種が明るさに依存 | 日長を揃えても活動窓が変動 | 触覚採餌や極昼では昼夜交互作用が弱まる可能性 |
| H3 位相の向き | 同じ水位でも dh/dt の符号が異なり行動遅延 \`τ>0\` | 運動方向/生息地遷移に位相依存 | τ=0、候補全地点の傾向同一、移動先なしで追加情報ゼロ |
| H4 地域潮汐型 | F と大潮小潮/一日一回潮の違い | 周期位相の占有/活動パターンの形が変化 | 半日周の正符号が全球で一定とは予測しない |
| H5 可達代替空間 | 到達できる餌場・休息地の質/数と個体の行動能力 | 多候補なら状態維持、少ないなら活動窓収縮・集中/転換 | 個体が訪花/採餌を観測していなければ採食の因果は不可 |
| H6 種間感覚差 | 光・水深・資源に対する種ごとの応答関数が異なる | 同じ2D周期上で種間分割が生じうる | 観測努力/タグバイアスが説明する場合は否定 |
| H7 季節・高緯度 | 日長が0〜24hに近づく、極地では昼夜の4セル欠損 | 非単調：中間日長で昼夜比較強く、極昼/極夜は推定不能 | 日長単独の回帰係数から誤って「交互作用なし」としない |
| H8 捕食・競争・社会 | 同じ餌場機会でも夜間危険/集団凝集/競争が違う | 捕食回避/空間遷移として時間分割 | 同時刻近隣個体がなければBoids社会力を推定しない |

## 研究デザイン：一つのマクロ生態学へ

**全球環境層**は UHSLC本物の毎時潮位×天文太陽位置を使用し、source QC・datum内Q25・本物の測定日/季節・分類した4分潮・潮差・地域別水位変動から時間ゲートを推定する。最初の2019原データパイロットは緯度15°ごとにsourceだけで1観測所、選定ルールに結果の閲覧を使わない。適格site×year×monthから全適格2000–2024へ展開したら沿岸独立クラスターをブートストラップする。\(O-A\) の正負の平均と絶対変動は別アウトカム。**潮位Q25は干出地図ではない**。

**全球干潟環境層**は Global Intertidal Change 30mの実際の分布（1999–2019）を独立レイヤーとして扱い、地理的に潮間帯が存在することと、毎時干出を混同しない。真の干出指標には現地の鉛直datum整合地形・近傍水位伝播モデル・観測年を要求し、揃う地域を「機構の認定subset」とする。

**生物多分類群層**は 1海域1種のWaddenを学習例、タグと昼夜×潮相のsupportが十分ある別海域・別種のGPS/行動記録を独立外部検証に用いる。中国南岸4種Dryad元ZIPは 2026-11-09時点 boids v88 で公開API HTTP401 のため**未取得**；2018年WATLAS v90は source gate不足。他種への再現済みと書けない。地理的・分類学的に独立のサンプルが今後揃うまで、物理全球結果と生物1種結果を同じ肯定係数に合算しない。

**最重要の生態学的予測**：潮汐×太陽が「時間ニッチ分割」を生むのは、二時計の非同調そのものではなく、**(i)周期が実際に可利用生息場所を変化させ、(ii)その各状態の便益・リスクの順位が種間/個体間で異なり、(iii)生物が時間/場所を変えられ、(iv)その差が独立の観測過程で検出されるとき**。四つのいずれかが欠ければ明確な生態学的分割がない/観測できない可能性がある。これは現在**反証待ちの条件付き一般化仮説**であって実証法則ではない。

## Honest conclusion
2026-11-09 時点、**潮汐×日照の物理ゲートはWadden 2地点・2年で確認、実測GPSと潮汐×明暗の異なる関連は1種2島で探索的に認められるが、真の全球生物学的時間ニッチ分割条件はまだ未実証**。生物学的符号を全地球へ外挿するのではなく、実測物理・地形・種ごとに異なる応答・外部反復の3段階を連鎖させて検証する。
