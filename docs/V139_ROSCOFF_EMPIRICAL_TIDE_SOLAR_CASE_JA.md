# v139：潮汐と昼夜の交互作用を真正公開音響データで再解析（Roscoff）

2026-11-15。元論文：[Diel and tidal rhythms drive fish acoustic communities in a European kelp forest](https://doi.org/10.1186/s12862-026-02521-z)、2026、Roscoff沿岸フランス。原著の**統計解析用Supplementary Table S1/S2のXLSXを真正取得**し、SHA-256と元セル数の全数照合を行った。論文が公開した音型別カウント・環境時系列を時間で結合し、記録のある時間だけを対象として新しい区間ホールドアウト予測を実施した。

## 原本・観測構造の独立照合

- 元XLSX：Europe PMC supplementaryFiles 内 `12862_2026_2521_MOESM2_ESM.xlsx`、**299,726 bytes**、SHA-256 `2df8fac5749d804b8d16d98db065ba19dc3796a4a01ce1cfa87c56f5d622d0d0`。本リポには元XLSX本体を再配布せず、原本SHAと再計算可能コード、集約数値のみ記録。
- Excel Table S1の**421行（元の26音型ごとの相対的記録数）**を検算：**6,172アノテーション**（原著と一致）、音型26種。音型richnessもsourceのAP/AQ列と一致。
- `S24_num`で定義される**20個の12:00–翌11:00の24時間区間**。単なるカレンダー日で区切ると36日相当になり、実際には同じ観測区間を誤認する。20×24=**480時間**をS1+S2から復元、**421時間採用・59時間除外**を厳密再構成。
- Table S2の環境時系列に480時間分が存在し、採用された421時間の水位はS1の列と**全て同値**。原著の水位は現場水深ではなく**SHOM Roscoff水位局由来の、海図基準面に対する値**である。光は現場HOBOロガーで記録された変数。
- この6,172件は**音の注釈数**であり、6,172個体でも独立した6,172回の訪問でもない。単一録音地点、20の意図的に選択された期間である。

## 真正音響記録の新しい予測比較（5分割、区間ホールドアウト）

目的変数：**採用された1時間の音響アノテーション件数**。Poisson回帰（物理水位mは5m中心化、固定ridge=0.5）、20個の24時間区間を単位に、元論文のLow/Medium/High/VeryHighから各1期間を1foldに割り当て、5foldの外部区間予測を結合した。ソースの421時間はPoisson型の均等観測イベントとして扱うが、真の魚の個体数ではなく、過分散と連続時間相関・選択バイアスは残る。原著の全共変量を含むNB混合モデルの再現ではなく、**比較可能性を意識した独立の簡易予測モデル**である。

| 候補 | 421hのホールドアウトPoisson対数スコア（高いほど良） |
|---|---:|
| 一定発声率のみ | -3.8135 |
| 昼夜のみ | -3.6538 |
| 昼夜＋連続水位 | -3.6320 |
| 昼夜＋連続水位×昼夜 | -3.6444 |
| 昼夜＋連続水位＋大潮小潮係数区分 | -3.5711 |
| **上記＋大潮小潮係数区分×昼夜** | **-3.5394** |

- 連続水位×昼夜の追加：**-0.0124 nats/retained-hour**。5fold中改善したもの**0/5**（すべて非改善）。水位の時計シフト±3, ±6, ±9, ±12hを加えた9条件では、正しい時刻対応は**5/9位**。これは位相の仮比較であり正式な潮汐特異性の統計検定ではない。
- 一方、潮汐係数区分×昼夜の追加：**+0.0317 nats/retained-hour**。fold単位は改善**4/5**、選定24h区間単位では**11/20**。ひとつの24h区間の予測値を除いて平均すると、改善は**+0.0177〜+0.0447**。後者は**モデルを再学習するLOOではなく、予測スコアの1期間除外**。
- 59時間の欠測を含むHigh/VeryHighでは係数区分交互作用の改善は平均 **+0.0043**。欠測のないLow/Mediumでは、全モデルからのホールドアウト予測値で **+0.0524**。

### 除外時間ゼロの10期間だけでモデルを一から再学習

元のLow/Mediumの**240時間・10期間**のみの完全な観測時系列を使い、2モデルを別に区間ホールドアウト。

- 昼夜＋水位＋潮汐係数：**-3.4963**。
- さらに潮汐係数×昼夜：**-3.4438**。
- 差：**+0.0525 nats/retained-hour**。大潮・小潮係数×夜の予測改善が**高潮差日の音響マスキングだけによって生じたものではない**可能性を支持する。ただし、元の期間選択、季節、観測所1地点、測定環境や音の検出率について無作為化・補正した実験ではない。

## 生態学的推論の正当な境界

支持されるのは、**Roscoffの条件付き音響記録において、24時間内の水位の昼夜依存を足すより、14日程度の潮差状態（大潮小潮）に依存した夜間変化を足す方が、5fold区間予測で有用だった**という限定的な実データ所見。元論文でのGLMMのp値と、このPoisson予測性能は異なる問いを答える。

支持されないのは、魚個体の社会行動の潮汐因果効果・潮流速度への応答・実際の個体移動・群れのBoids係数・全球のマクロ系統効果である。選択された20期間の連続性、59除外時間、魚以外の音型・検出確率の影響が残る。20期間は20独立沿岸ではないため**全球メタ解析効果はNOT_ESTIMATED**。

原著の他の独立沿岸データを取得するまでは、この結果を**メタ解析で統合する1つの沿岸候補と、検出欠測に関する方法論的事例**として扱う。
