# v155：自己発声持続を除いた後に、別音型の同時検出は独自情報を持つか

2026-11-15。v145〜v154のカリフォルニア原本・魚類コーラス関連、特にUF440とBocaccioの同時録音による見かけの予測改善を**既に見た後**に固定した追加検証。結果依存で音型・モデル・正負対照を選び直さない。これは同一研究内の*探索的条件付き情報検証*であり、独立の実証や魚個体の社会力同定ではない。

## 動機

v154の「Bocaccioをその年の季節・時計・太陽・NOAA潮位で予測し、**同じ録音時間の**別音型Bを加える」と、UF440の保留年で平均+0.00714 nats/hの追加利得が見えた。しかし、Bocaccioが長時間鳴き続け、その活性状態が自己持続することをモデルに入れていなかった。両音型が同じ環境で長時間続けて鳴けば、直接の魚同士の反応がなくてもBの検出が「Aが今鳴いている」ことを補足的に予測する。

新しい対比は、**自己の直前1時間の実際の録音陽性**を先に加え、追加で他音型が役立つか。それが**別の日に録音された同じ音型**を加えても同程度に見えるかを比較する。

## 元ソース完全維持、1時間自己履歴に必要な限定のみ追加

- 原本Kim et al. 2025 Dryad 60 XLS/XLSXをv142の個別SHA256と全数照合。全9地点・32地点×暦年・**136,032時間**の連続7日以上完全24時間の機会母集団（v145）を使う。
- 確かに1時間前の録音がある場合にだけY(t−1)を測定し、**各元の連続7+日区間の最初の1時間275個のみ落とす**。共通モデルサンプルは135,757時間と事前固定。Off/Noise/欠測をA=0と誤ラベルしない。
- 元のNOAA14観測所×年プロバイダ全ボディSHA256と音響60ファイル個別SHAをv154ツールで照合し、各元時間の実測沿岸水位値・±1時間勾配を使う。
- B=UF440（魚種名不明）とWhite Seabassの**二つとも**、原本の同じ録音時間のB(t)、元の同じsite×月×連続7+日区間で**Bの丸一日24hプロファイルを+3日または+5日だけ循環移動した**B_ghost(t)を作る。現地の時計時刻・元のコーラス継続時間は各Bゴースト内でそのまま保持し、元の日付の共通環境や真のA/B同時記録だけを崩す（循環の境界は例外）。
- 完全な元録音時間とYはすべての候補モデルで共通。最初に音響とNOAAの取得/原SHA照合を終えてから、モデルの新しい成績を開く。
- v154の元の21適格な地点×年×音型組だけを評価可能候補として引き継ぎ、残り43のsource support STOPを**そのまま残す**。1h元履歴除外後に元支持条件を下回る場合は別STOPで記録。勝つ年度やモデルを結果依存で追加しない。

## 固定モデル

すべてv154と同じ固定ロジスティック回帰 \`C=0.25, lbfgs, max_iter=400\`、学習期間だけで標準化。各録音地点の**過去暦年の全部**で学習し、後の年全体を保留してlog-loss（nats/録音時間、低い方が良い）とBrierを全モデルの同一時間で採点。

| 対比 | 説明変数 |
|---|---|
| 定数 | 学習年のBocaccio陽性率のみ |
| Solar | 時計3次調和、季節2次調和、太陽高度/暗夜 |
| Tide | Solar＋NOAA海岸実測の高さ・変化・夜間との交互作用 |
| Self | Tide＋**実際に観測されたBocaccio 1h前の陽性** |
| B_real | Self＋**現在の同じ録音時間のUF440またはWhite Seabass** |
| B_ghost3 / B_ghost5 | Self＋同じ月・同じ現地時計時刻だが元とは違う日+3/+5日のB音型 |

特に固定する2つの関心量：

- **自己持続の追加**：\`loss(Tide)−loss(Self)\`。
- **同時Bの固有の追加**：\`loss(Self)−loss(B_real)\`。さらに**\`min(loss(B_ghost3),loss(B_ghost5))−loss(B_real)\`** を誤日対照との比較として全件保存。

どちらも正なら予測改善。**p値や独立海岸のCIは出さない**。二つのゴーストのうち保留スコアで最良を使う比較は、保守的な診断であって、厳密なrandomization null検定ではない。

## 明示する限界

- 録音データは「手動アノテーションの1時間枠で、陽性音型が存在した」という情報であり、個体・真の発声開始・繁殖成功・採餌・個体数ではない。
- Y(t−1)はテスト年に観測済みの前時刻データなので、自己持続モデルは1時間前の観測を利用できる状況に限る。B(t)は**現在同時観測**なので事前に未来を予測する材料ではない。B_ghostはテスト年の**別日の事後観測**なので現実の予測器ではない。
- 直接の魚間相互作用が一切なくても、検出器の可聴性/船舶騒音、共有水温・湧昇流、共通生活史と音響認識誤差によって条件付き情報が残りうる。
- 音型Bの丸一日シフトで年月と時計時刻を保存しても、日ごとの海況・録音雑音を固定したわけではない。
- 9地点は同じカリフォルニアの1公表研究、コーラス年ごとに独立した研究は増えていない。世界全体の潮汐×太陽効果やBoids社会力を推定しない。
