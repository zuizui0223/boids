# v166 補注：真の潮汐位相と誤位相のスコアの「最良」の定義

2026-11-16。真正2018年の元SOURCE・155,000件超の観測・5fold・MSEの主結果に変更なし。比較統計量の解釈のみ厳密化。

- **+0.004461034 MSE改善**：元17 ISO週で各モデルのMSEを**先に等重み平均した後**、+3日/+7日/+11日のうちMSEが最小の誤位相モデル（+7日）と真の0日を比較する値。
- **10,000週再標本化の[+0.002365,+0.005461]**：元v165 `score_models` 内で各週**それぞれの最良の誤位相**をまず選択し、真の潮位との元週別MSE差を再標本化した別の、保守的な統計量。これは先の+0.004461034「全週平均した後の最良位相」と**完全には同じ推定対象ではなく、その形式的95%信頼区間とは呼ばない**。
- 元17週中15週で真の潮位が3つの誤位相に勝ったというSOURCE観測結果はそのまま。標識鳥間で共有する同じ海況・同じ年の自己相関も解消していないため、両比較から位相の因果性のp値は作らない。

2019年のv167も点推定+0.002771784と週ごと最良ゴーストの記述的区間[+0.000361,+0.003487]の定義が異なる。再標本化で主点推定と同じ統計量を推定するには、**再標本化した各集合でモデル別の週平均を求め、その後に最良の誤位相モデルを選択する**必要がある。この修正統計の正式な不確実性は元週スコア全体の新たな原本再計算まで未推定とする。

潮汐の予測情報の符号は2018・2019のSOURCE観測に支持されるが、強い因果的統計有意性や全世界への外挿は未主張。
