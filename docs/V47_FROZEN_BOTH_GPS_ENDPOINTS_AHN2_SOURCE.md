# v47 FREEZE — Original AHN2 height at BOTH start B and destination C of GPS movement: source-only

**2026-11-05 JST, before any v47 observed B+C source counts.** The v46 C-only counts are known (Schier 2011 1018, Ameland 2011 1243; both 2012 insufficient). This new predeclared gate **does not inspect tide phase or biology**. Keep the 2010-training-only selected 2km K=8 AHN2 WCS cells unchanged; do NOT choose additional areas after seeing v47 counts.

## Purpose
Determine whether actual wild Eurasian oystercatcher B→C movement pairs have **two valid georeferenced AHN2 source-height values** from the predeclared 2010 source-hotspot tiles. Both are essential before testing if birds move into a genuinely newly exposed historical tidal-height band (hypothesis, not yet measured).

## Original data and frozen matching
- Two original Zenodo GPS studies O_SCHIERMONNIKOOG and O_AMELAND, years 2010/2011/2012, published original gzip MD5+SHA checks exactly as v46, source `visible` flags, WGS84 site bounds and native naive original timestamps. DO NOT download RWS tides here or estimate any ebb/flood effects.
- Reuse v46 functions `source_hourly`, `freeze_training_cells`, `original_ahn2_layer`, `source_tile`, `rd_tile_at`, K=8, 2km source tile grid and 256×256 AHN2 WCS output cells (7.8125m derived sample interval). No original raw GPS coordinates/animal IDs/timestamps committed.
- For each test-year original GPS track, use genuine consecutive original A→B→C fixes, each interval 30–120 min, horizontal ground displacement 0.4–120 km/h, as v46. Count all source three-fix destination candidates first; **B and C both** must fall within 2010-selected cells, sample an original source-valid georeferenced AHN2 pixel with physically plausible first-band −20..+50m candidate and float auxiliary 0–1 coverage ≥0.999 (semantics remain unverified). No missingness interpolation, no new source cell selection, no false DTM=sea floor claim.
- Keep observations even if B and C lie in different selected cells. Report total triples, C-only valid sample count (must exactly replay v46 original source receipt), B-only count, B+C valid count, distinct contributing birds, ISO weeks, calendar days, distinct selected source tiles, number of test pairs both in broad −3..+3m NAP band, and z_C−z_B **source geometry availability only** (no numeric endpoint elevation distribution, no outcome report).
- Source feasibility threshold for later field hydrostatic-front analysis: ≥500 B+C pairs in same test year and site, ≥3 original birds, ≥4 ISO weeks, ≥2 selected DTM source cells contributing. Also report more conservative B+C both in −3..+3m NAP threshold ≥300 pairs, ≥3 birds, ≥4 weeks, ≥2 cells. The first is geometry source admission, the second asks whether physical tide-adjacent ranges have independent source support. If either fails, later front analysis NOT_ADMITTED for that site/year; source unavailability is **not an ecological null**.

## Interpretation and uncertainty
First-band raster height is a historical AHN2 2007–2012 DTM candidate, NOT necessarily intertidal seabed; exact survey years, original band2 mask definition, local wet/dry status and drift are unresolved. No RWS water gauge, physical `z−η`, prey availability, tide-front distance, animal behavioural state or social Boids force can be inferred from source eligibility alone.

If any 2011 site passes, the NEXT separately frozen biological question should predict **actual next destination elevation relative to its initial B elevation** (an outcome independent of gauge water levels), with speed/direction/area/clock control and original contemporaneous gauge tide phase added. A response defined as `z_C>η(t)` is algebraically contaminated by including `η(t)` in the response, and must NOT be used as primary phase-prediction target. A physically motivated crossing indicator (newly exposed tidal interval) can be descriptive/secondary, clearly labeled a gauge-relative proxy, not verified real prey access.
