# v60 実際の上げ潮・下げ潮で観測された次の進路の対応比較

**2026-11-07 JST：原本再実行と数値監査を完了。** [原本 GitHub Actions #42326562970](https://github.com/zuizui0223/boids/actions/runs/42326562970) 成功、対象 **50件のテストが成功**。[v60固定仕様](V60_FROZEN_ACTUAL_OPPOSITE_TIDE_PAIRED_HEADING.md) は2011年の新しい対応進路結果を一切確認する前にコミットされた。ただしv43–v58では同じ歴史的ミヤコドリ母集団の**他の標的・全GPS予測結果を既に見ている**ため、これは**事後探索的な観測解析**である。

## 原本・分母・時点を統一

Ameland（オランダ・Wadden海）ミヤコドリの原本GPSを出版者MD5と固定SHA256で再検証。独立のRWS観測所 `ameland.nes` の実測潮位 WATHTE（NAP、10分間隔）は2009–2011年、各年52,561点を検証した。前年2010年の3点GPS移動**3,753区間**で個体重み付きridge λ=10を学習し、2011年の元の**4,678区間・5羽**を年外評価する。評価年の次方向や対応ペアの観測方向でモデルを再学習・調整しない。2010年と2011年で同じ個体IDを含む場合があるので、**個体完全分離の検証ではない**。

v59の源データのみの固定対応（同一鳥・同一1km B位置格子・実際の上げ下げ・潮位差15cm以内・別日・季節30日以内・時刻3時間以内・直前移動方向45°以内・直前速度ログ差0.40以内）を、次方向を見ずに再構成した。以前のv59の全7段階件数（1,991 → 1,319 → 1,303 → 942 → 550 → 240 → 182）および**168重複なしペア、5羽、46週、11か月**を完全再現した。選別後にはじめて、それぞれの本当に観測された次方向ベクトルを開く。

対応状態の差の記述平均は、実測潮位差 **0.07425 m**、季節差 **11.96日**、時刻差 **1.156時間**、直前移動方位差 **12.02°**。許容条件内でも完全に同一の環境状態ではなく、他の環境・活動状態の交絡は残る。

## 新しい実測主要結果

同じ鳥・同じ格子の**別々の日時**に記録された上げ潮の次方向ベクトルを `y+`、下げ潮を `y-` とする。2010年の固定モデルで、各実測B状態に上げ潮・下げ潮を入力したときの**予測単位ベクトル差**を計算し、両B状態の平均差を `g` とする。

**主推定量** `T = dot(y+ − y−, g)/4` は[-1,+1]に収まり、正なら**実際の進路差の向きがモデルの潮相別予測差と整合する**。決して潮汐を操作したときの生物学的旋回角、操舵力または標準化された効果量ではない。

| v60元GPSの固定指標 | 結果 |
|---|---:|
| 実際に成立した重複なし上げ/下げペア | **168** |
| 個体均等主スコア `T` | **+0.1676872981** |
| 対応whole-bird 10,000回bootstrap 95%区間 | **[+0.0861812723,+0.2491933238]** |
| 正の個体数 | **5/5羽** |
| 全32符号の鳥単位片側sign-flip感度 | **0.03125** |
| 別推定対象の等週→等鳥スコア | **+0.2074431056** |
| 別推定対象のwhole-week 4,000回bootstrap 95%区間 | **[+0.1392973529,+0.2794708820]** |
| 実際のペアの次方向の絶対角度差 | **79.54095°** （鳥CI [63.0320°,94.1143°]） |
| ペア上の真の潮相 vs 人工反転cosine loss利得 | **+0.3355379613** （鳥CI [+0.1661885000,+0.5048874227]） |
| 90°直交方向への投影 | **+0.0210481477** （鳥CI [−0.0472467454,+0.0858571496]） |

**事前に定めた主な正方向の基準は達成した**。168を独立個体と見なさず個体単位で推定しても、元の対応進路差は**2010年の固定モデルが指定した潮相別の方角**に整合した。見かけの共通時計回り／反時計回りは主張していない。直交方向の鳥区間はゼロをまたぐ。進路間の絶対角度差79.54°は、鳥の通常の行動変動にもより生じ得るため、それ自体は潮汐の効果ではない。ペア上の真の潮相対人工反転のcosine利得はTと数学的に関連するため、**独立した二つ目の証拠として数えない**。

## 一般生態学・Boidsへの接続と限界

現在の野外データが支持する主張は「**満ち引きという周期的環境の向きが、現在の水位や直前の運動を考慮しても、野外鳥類の実際の進路を条件づける予測情報を持つ**」という**観測的な関連**である。v57ではモデルの情報が近隣別島にも一方向で転移した。v58は人工的な符号反転によるモデル感度、今回v60は同一個体の本当に異なる二時点を対応させた観測方向差であり、各結果の推定対象を混同しない。

ただし、(1) 元GPSのUTC/GPS時刻定義、(2) 局所潮流と水位の空間遅延、(3) 餌の露出前線、(4) 観測されない採餌・休息・場所利用、(5) 2010モデル学習係数の不確実性（鳥ブートストラップに未伝播）、(6) 同じ種・同じWadden海・同じ過去個体に対する多数回の探索解析、という制限がある。上げ潮と下げ潮を**実験的に割り当てたわけではない**。複数個体の瞬間的な位置関係や反発・整列を測っておらず、Reynolds/Boidsの社会的力を推定・証明していない。海洋前線の追跡や種内／種間ニッチ分化の原因も未同定。
