# v22 preregistration — contemporaneous collective velocity versus two-second-old other-fish velocities

**Frozen before v22 scores are computed, 2026-11-24 JST.** Original Puy tetra v5–v8 and Niizato ayu v9c results were already inspected; **this is a post-prior-results diagnostic** on the same source populations, not an independent discovery or fish sound experiment. All existing numerical endpoints remain immutable.

## Rationale and identifiable target

Two species show that the currently recorded **other-fish mean movement** adds heldout-recording predictive information to a focal fish's own recent movement and spatial geometry. But current neighbor velocity could proxy group persistence or shared cues rather than active neighbor-following. Replace only the other-fish velocity feature with its measurement from **2.00 seconds before prediction**, while preserving current focal self movement, present spatial geometry, response rows, training folds, algorithm and target.

**The primary contrast is contemporaneous minus stale predictive accuracy**, not an experimental causal effect:
`D_{s,h} = equal-recording-mean[MSE(geometry + 2.0s-old OTHER-fish mean − current focal velocity) − MSE(geometry + current OTHER-fish mean − current focal velocity)]`.
Positive D means the present other-fish state carries more temporally specific information than two-second-old other-fish state under these retrospective fitted regressions. It does not isolate social communication or biological acoustic behavior. Report separate source and horizon results; no pooling of dimensional MSE.

## Negative checks and source/admission gates

- Synthetic fixtures where all other-fish velocities are constant must yield equal present/old feature values exactly; independent moving neighbors must yield distinguishable features while own state and geometry remain unchanged; any indexing into future timestamps when constructing predictors is a STOP.
- Verify every source's original SHA/MD5, original filename, sample-index/elapsed-time mapping and row counts; verify current base/global columns exactly replay old authors' feature construction.
- Source download, unexpected bytes, original score replay mismatch, source temporal gap, numeric NaN, unequal model target support, or insufficient data => scientific `SOURCE_OR_REPLAY_STOP`, **no fabricated ecological score**.
- Publish compact aggregate JSON and source digests, never original fish coordinates or personally identifying tracking data.

## Claim boundary and stop rule

Even if positive in both species and both horizons, `D>0` supports **relative temporal specificity of collective velocity predictive information**, not fish hearing, onset of chorus, neighbor causality, 3D habitats, or a universal force. If not positive, retain the null/adverse signs and downgrade the global-state interpretation accordingly. No observational response here includes fish calls.
