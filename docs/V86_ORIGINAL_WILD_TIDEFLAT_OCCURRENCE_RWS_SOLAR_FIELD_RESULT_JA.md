# v86 原本結果：真の野生ミヤコドリGPSで「中位・高位潮間帯内に記録された割合」と潮汐×昼夜の関連を検証

**2026-11-09 JST。原本データによる[GitHub Actions #42573488013](https://github.com/zuizui0223/boids/actions/runs/42573488013) SUCCESS、v86 6件＋v85 9件＋v82 7件＋v77 6件の合計28件ソース・known-truth検証PASS。** SchiermonnikoogとAmelandの異なる原Zenodo2010年ミヤコドリGPS集団、2010年公式Rijkswaterstaat潮位2測点の各52,561件10分測定、2008〜12年を代表するWageningen Marine Research（WMR）元エコトープ地図全ポリゴン、月別NIOZ元数値モデル格子を認証した。**先に同じ個体×月×実測潮位×潮汐上げ下げ×天文昼夜の4条件が元v82と完全に一致することを確認してから、GPSの潮間帯内外という新しい応答Yを初めて採点した。**

新しい解析はv85の「干潟にいたGPSだけを使った元NIOZ数値順位の4条件比較」がソース未達だったことを受けて固定した**新しい後付けの探索的アウトカム**である。v85で成立していない効果を遡及的に計算したわけではなく、以前のv82「モデル指数の周囲1km内順位」とも異なる現実の**観測GPS位置のカテゴリ分類**を応答としている。

## 1. 新しく定義した、生物に近い実測位置利用の応答変数

元GPS位置Bから300m以内の最寄りの **あらゆる** 元NIOZ静的格子を同じ固定手続きで取得し、その格子が本物のWMR2008–12年エコトープ地図の`litoralcode=3`（中位潮間帯）か`=4`（高位潮間帯）なら`Y(B)=1`、それ以外の潮間帯下部（分類2）、深い水域・陸地・塩性湿地等は`Y(B)=0`とする。元のGPS地点を近くの干潟セルに移したものではない。月別NIOZの`time_expo`数値を直接生物の応答には使わない。

**重要な出典限界**：WMRのGeoServerは正真正銘の公開元地図だが、2019年第1版と2021年第2版で低位干潟（分類2）の判定境界に修正があったため、現在のWFSデータが訂正済み2021第2版と完全同一か未認証。問題の分類2は`Y=0`に含まれ、現地で実際には採餌できる低位干潟を「対象の中位・高位以外」としている可能性がある。したがって**全干潟の利用率でも、餌場選好でも、観測した採餌時間でもない**。またエコトープ地図は2008〜2012年の複合データであり、GPS観測年2010のその瞬間に干出していた水面・餌資源を直接観測した地図ではない。

## 3. 固定した生態学的推定量と原本の本命結果

[
D_{imh}^{\mathrm{flat}}=
  (p_{\mathrm{flood,night}}-p_{\mathrm{flood,day}})
 -(p_{\mathrm{ebb,night}}-p_{\mathrm{ebb,day}}).
]

## 4. 元データ内の補助検証：中位と高位に分けても

旧の低位干潟`code2`を入れず、同一元4条件・同一元鳥で、Yを`code3`だけ、`code4`だけへ変更する**事前固定二次感度**を全件確認した。code4の元GPS採録数は双方で100件以上あったため、あらかじめ定めたソース数基準を通った。ただし高位干潟セルはSchier316、Ameland70と狭く、境界位置の分類に敏感であり、二次解析は主張の独立再現ではない。

|---|---|---|

## 5. 研究全体で何が新しく、どこまで言えるのか

**今回の強い正味の進展**は「潮汐曝露数値の高い場所を使う」という旧NIOZモデル内の空間順位と、**「実GPSが地図上の中位・高位潮間帯にいる割合」**という生物記録の頻度を**真に違う生態学的な2軸として定義した**こと。Schierでは旧v82全GPSの数値曝露順位D **+0.0499791（+5.00順位ポイント）**だったのに対し、新v86の中位・高位GPS利用割合のDは**−0.0561557（−5.62位置割合ポイント）**。それぞれ別の応答なので同じモデルの符号反転による「相互矛盾」「多重の独立発見」と読むべきではなく、**空間内でどこにいたかと、そもそも中位・高位干潟へ入ったかが異なる振る舞いを持ちうる**という新しい条件付きメカニズム仮説を与える。

**未測定：** 実際に鳥が採餌した瞬間、餌・底生生物や中位/高位干潟の局所地盤標高・実測流況、上げ潮と下げ潮で実際に干出していた場所、Roostingや集団移動、夜間のGPS記録機会・機器時計の厳密校正。WMR2008–12年モデル混合地図の2021訂正版同一性未認証、低位干潟`code2`は本当の採餌利用地でもY=0とされている。中位・高位だけに限定した`Y=1`は、**「干潟全体にいた確率」や実際の採餌行動の直接計測ではない**。また元の2010年2島・1種同じワッデン海の繰り返し探索結果は、別の海盆・別種に一般化できない。

**新しい次の固定可能な課題**：潮汐によって利用可能な生息地へ「入る・出る」段階と、入った後に「どの曝露環境セルを選ぶ」段階を分けた階層的2状態モデル（入退域と条件付き移動）を定義し、同時刻のGPS観測間隔・餌場/休息状態・局所実測潮位の地理的伝播・個体ごとの元機会数を調整する。v85はstrict-in-habitatの完全4条件が足りなかったので、その内部段階に独立野鳥反復があると断言せず、まず元sourceな観測機会の実測とサンプル数を評価する。国際的な普遍性を試すには、真に独立した別海岸/別種・別GPS個体を固定仕様で予測する必要がある。

以前のv63**潮汐方向と次のGPS進路の実測正**、v70の**二観測所の潮汐×太陽の実測物理機会**、v69/v70の**太陽条件追加による独立の次GPS方向予測の改善なし**、v75–v82の元モデル指数の正/未確立/島間差未確立、v85のstrict-in-habitatモデル指数生物D**未計算**はすべて元の定義のまま保持している。
