# Acoustic Boids v14：刺激後の状態維持と到達時刻を分ける

作成日：2026-11-22。**以下は人工モデルの計算結果であり、魚の実測結果ではない。**

## 結論

v13と同じ24シードを4000から16000ステップまで追跡すると、相互作用を保った条件では、刺激あり・なしの発声個体率は終盤にほぼ同じ高い値になった。主要評価窓 `[12000,16000)` の刺激差は **−0.000005534**、シード対を再標本化した95%区間は **[−0.000021159, +0.000008464]** だった。

v13の `[3000,4000)` で平均差を大きくしていたシード1010・1014も、無刺激側が後から高発声に到達した。この観察は、この既定条件での刺激効果を「高発声への到達を早めること」として解釈する根拠になる。一方、移動する確率系の定常分布が一意であること、あらゆるパラメータで履歴効果が消えること、魚で同じ仕組みが働くことは示していない。有限期間の平均値の近さは、同等性検定や漸近収束の証明でもない。

数値の一次出力は `validation_fish_boids_v14/results/summary.json`、配布ZIP内の `results/audit_result.json`・全軌跡・CSVである。実装と再現手順は [v14 README](../validation_fish_boids_v14/README.md)、固定した設計は [プロトコル](V14_ACOUSTIC_MAINTENANCE_PROTOCOL.md)、数学的な範囲は [導出補足](V14_GEOMETRY_DERIVATION.md) に示す。

## 1. 何を追加したか

v13では、一部のシードで刺激終了後も発声差が4000ステップまで残った。v14では、同じ軌跡を長く観察し、さらに刺激終了時に相互作用の一部を切ることで、有限期間の遅れと刺激差の維持を区別した。新しいパラメータ探索や、効果が出たシードだけの選択は行っていない。

| 項目 | 固定した設定 |
|---|---|
| 個体数・シード | 32個体、1000–1023の24シード。v13と同じシードの追跡 |
| 計算期間 | 16000ステップ、`dt=0.06`。960モデル時間単位であり、魚の960秒ではない |
| 外部刺激 | 強さ0.8、`[1000,1040)` の40ステップ |
| 切断時点 | 1040。刺激終了後の更新から変更 |
| 比較 | 4機構 × 刺激あり・なし × 24シード = 192軌跡 |
| 主要評価窓 | `[12000,16000)` |
| 補助窓 | `[1040,1240)`、`[3000,4000)`、`[7000,8000)` |
| 保存状態 | 1000、1040、4000、16000回の更新が完了した位置・速度・二値発声 |
| 区間推定 | 対応するシードを単位に10000回の百分位ブートストラップ。乱数種20261122 |

プロトコルは、新しい計算結果を見る前にコミット [`d56e0de`](https://github.com/zuizui0223/boids/commit/d56e0de00d2a1bc11da434aedda00251049f0418) で固定した。v13の結果を受けた探索的追跡であり、独立した再現実験ではない。区間は未調整の記述的区間で、魚個体や魚群の母集団についての信頼区間ではない。

切断前の重みは全条件で `(音に向かう運動, 受音による発声促進)=(5,3)`。切断後は次の通り。

| 名称 | 切断後の重み | 介入の意味 |
|---|---|---|
| intact | (5,3) | 両方を維持 |
| motor_cut | (0,3) | 音に向かう運動だけを除去 |
| hearing_cut | (5,0) | 受音による発声促進だけを除去 |
| both_cut | (0,0) | 両方を除去 |

motor_cutでも通常のBoidsの運動項は残る。位置を固定する介入ではない。また、切断は刺激あり・なしの双方に同じ時刻で施す。異なる無刺激条件を対照に使う混同を避けるため、まず各機構内で刺激差を計算し、その差同士を比較した。

## 2. 相互作用を維持したまま長く観察すると

発声個体率は各ステップで発声している個体の割合である。以下は24シードを等しく重み付けした窓平均。差はすべて「刺激あり − 刺激なし」。

| 観察窓 | 刺激なし | 刺激あり | 平均差 | 95%区間 |
|---|---:|---:|---:|---:|
| 直後 `[1040,1240)` | 0.884603 | 0.914193 | +0.02958984 | [+0.00000651, +0.08727865] |
| v13終盤 `[3000,4000)` | 0.939652 | 0.998297 | +0.05864453 | [−0.00000911, +0.15089590] |
| 中盤 `[7000,8000)` | 0.998310 | 0.998328 | +0.00001823 | [−0.00000651, +0.00004557] |
| v14終盤 `[12000,16000)` | 0.998276 | 0.998271 | −0.00000553 | [−0.00002116, +0.00000846] |

終盤の刺激差は百分率に換算すると約 **−0.000553パーセントポイント**。正のシード7、負のシード8、差が厳密に0のシード9で、中央値は0だった。無刺激側も約99.83%が発声する高い活動状態になっている。

v13窓の生データは保存済みv13と厳密に一致する。区間は今回の固定ブートストラップ乱数種で再計算しており、前報の乱数種20261121による端点と完全一致するという意味ではない。

群れの凸包面積についても、v13窓の平均刺激差 −3.27410 から、v14終盤では −0.00619、95%区間 [−0.02564,+0.00970] になった。終盤の平均面積は無刺激3.99072、刺激あり3.98453である。面積は任意単位で、魚群の実面積に換算していない。

全24シードの図は `figures/all_seed_continuations.png`、機構比較の図は `figures/maintenance_audit.png` として配布する。図の100ステップ表示平均と、推定に使う固定窓平均を区別している。

### 効果の集中

v13窓で正の刺激差を合計した量の **99.9800%** はシード1010・1014の2本に由来した。分母は正の差だけの和 `sum(max(delta_i,0))` であり、正負が相殺する純差ではない。全軌跡を示す理由は、この集中を平均曲線で隠さないためである。

終盤には大きな差が残らず、正の差の総和自体が0.000203125まで小さい。終盤の正の寄与の上位シードを新たな生物学的類型として解釈しない。

## 3. 変化したのは到達時刻か

到達を「刺激終了後に始まる連続200ステップの発声個体率の平均が閾値以上になる最初の窓」と定義し、その窓の完了時点を記録した。これは定常状態に入る時刻を推定する指標ではない。検索開始は1040、最も早い確認時点は1240。到達しなければ16000で右打ち切りとするが、今回は全24シードの両条件で、閾値0.80・0.90・0.95のすべてに到達した。

閾値0.90で、刺激前の200ステップ平均が閾値未満だった3シードは次の通り。

| シード | 無刺激の確認時点 | 刺激ありの確認時点 | 刺激による確認時点の差 |
|---|---:|---:|---:|
| 1000 | 1878 | 1865 | −13ステップ |
| 1010 | 4529 | 1454 | −3075ステップ |
| 1014 | 3730 | 2788 | −942ステップ |

残る21シードは刺激前から高活動で、刺激終了後の最初の確認窓で双方が条件を満たした。したがって「24シードすべてで到達が早くなった」とは言えない。

| 閾値 | 全24シードの平均確認遅延差 | 95%区間 | 差が負 / 0 / 正 |
|---|---:|---:|---:|
| 0.80 | −173.54ステップ | [−480.29, 0] | 3 / 21 / 0 |
| 0.90 | −167.92ステップ | [−463.42, 0] | 3 / 21 / 0 |
| 0.95 | −166.04ステップ | [−457.83, 0] | 3 / 21 / 0 |

3閾値で方向は一致するが、平均差の区間上端はいずれも0で、中央値も0である。「この少数の遅い軌跡では到達が早かった」という結果と、母集団全体で確立した効果を区別する。事後的に3本だけを取り出した平均を、独立した推論の主結果に置き換えない。

## 4. 刺激終了時の切断で分かったこと

終盤の各機構内の刺激差は次の通り。

| 機構 | 無刺激の発声率 | 刺激ありの発声率 | 平均刺激差 | 95%区間 |
|---|---:|---:|---:|---:|
| intact | 0.99827604 | 0.99827051 | −0.00000553 | [−0.00002116, +0.00000846] |
| motor_cut | 0.95238737 | 0.95235645 | −0.00003092 | [−0.00032651, +0.00026758] |
| hearing_cut | 0.05720378 | 0.05720378 | 0 | [0,0] |
| both_cut | 0.05720378 | 0.05720378 | 0 | [0,0] |

音に向かう運動を切ると、終盤の発声水準は約0.998から約0.952へ下がり、凸包面積は約4から約29に広がる。この既定モデルでは、音への運動がより密な配置とより高い発声水準に寄与する。ただし、それを切っても高発声自体は残る。高発声の成立を、音に向かう運動だけで説明することはできない。

切断の影響を調べる補助指標は差の差

\[
\mathrm{DID}_{m}=\Delta_{m}-\Delta_{\mathrm{intact}},\qquad
\Delta_m=\bar y_{m,\mathrm{pulse}}-\bar y_{m,\mathrm{none}}
\]

である。motor_cutの終盤発声DIDは **−0.000025391**、95%区間 **[−0.000320964,+0.000276050]**。もとのintactでも刺激固有の差がほぼ消えているため、この終盤窓から「音への運動が刺激固有の別状態を維持した」とは結論できない。主要窓以前の差や絶対活動水準と混同しない。

事前に定めたもう一つの補助指標、刺激差の要因交互作用 `Delta_intact - Delta_motor_cut - Delta_hearing_cut + Delta_both_cut` は、発声個体率で **+0.000025391**、95%区間 **[−0.000276050,+0.000320964]**、面積で **−0.0601795**、95%区間 **[−0.169226,+0.041674]** だった。全切断条件・全窓の差の差と要因交互作用は `audit_result.json`、終盤の要約は `summary.json` の `terminal_cut_effect` と `terminal_factorial_interaction` に保持している。

受音による発声促進を切ると、刺激終了後の発声確率は位置・直前の発声・刺激履歴から独立な `sigmoid(-2.8)` になる。同一シードで同じ一様乱数を使うため、hearing_cut/both_cutの刺激差0は式と乱数の組合せから予測される検算である。実測による独立な機構証拠ではない。motor_cutとboth_cutの面積軌跡が同じになることも、音への運動を切った後は発声が運動に入らないという構造から説明できる。

位置・速度・発声状態を刺激あり・なしの間で交換する介入は実施していない。そのため、履歴を保持する情報がどの状態変数にあるかは、この切断比較だけでは特定できない。

## 5. 実際の配置を固定して発声写像を調べる

intactの各シード・刺激条件について、4時点の位置を取り出し、外部刺激を含まない写像

\[
H_{ij}=e^{-\|x_i-x_j\|/5},\quad H_{ii}=0,\qquad
A=\frac{3}{8}H,\qquad
T(q)=\sigma(-2.8\mathbf 1+Aq)
\]

を解析した。v13の別の二状態平均場モデルを、この配置データに当てはめたものではない。

0ベクトルと1ベクトルから単調反復すると、すべての固定点を挟む下端・上端が得られる。残差許容値は `1e-12`、最大10000反復、端点差の分類閾値は `1e-8`。今回は全192レコードが残差条件を満たし、最大52反復だった。

| 診断 | レコード数 | 内容 |
|---|---:|---|
| 上下端点が数値的に一致 | 188 | `collapsed_bounds` |
| 上下端点が分離 | 4 | `separated_fixed_points`。すべてシード1010 |
| 未解決 | 0 | `unresolved` |

分離した4レコードは、1000時点の刺激あり・なし、無刺激1040、無刺激4000。1000の2レコードは刺激前の同じ配置なので、4独立例ではなく、1シードの3種類の配置である。

| シード1010の配置 | 下端の平均発声確率 | 上端の平均発声確率 | 平均結合行和 |
|---|---:|---:|---:|
| 刺激前1000、両条件共通 | 0.08664 | 0.71031 | 4.79413 |
| 無刺激1040 | 0.08609 | 0.70342 | 4.75639 |
| 無刺激4000 | 0.09015 | 0.75397 | 5.23701 |
| 刺激あり1040 | 0.78928 | 0.78928 | 6.11678 |
| 無刺激16000 | 0.99824 | 0.99824 | 9.20742 |
| 刺激あり16000 | 0.99830 | 0.99830 | 9.24248 |

16000時点では、全24シードの両条件、計48配置で上下端点が数値的に一致した。これらは約0.9983の高い固定点であり、終盤の高発声と整合する。各配置の固定点が互いに厳密に同じという意味ではない。

### この診断から言える範囲

この写像は二値発声の条件付き確率を連続確率へ拡張した近似であり、一般に `E[T(c)] != T(E[c])`。したがって実際の確率過程の期待値を正確に反復したものではない。

厳密な上下極限が一致すれば決定論的写像の固定点一意性を示せるが、ここで得たのは浮動小数点の数値診断である。残差が小さいことだけで誤差保証や固定点存在の厳密証明にはならない。また今回、全域収縮の十分条件 `(3/N) rho(H)<1` を満たした配置はなかった。この条件が不成立でも多重解の証明にはならない。

固定配置・有限パラメータの二値発声過程では、各遷移の確率が正で、有限マルコフ連鎖として定常分布は一意になる。一方で、非常に長く続く準安定状態はあり得る。この有限状態の議論は、連続的な位置と速度を含む移動系の定常分布一意性を証明しない。

よって、今回の結果は「途中の特定配置では数値的に複数の固定点が現れるが、観測した終点の配置では上下端点が重なる」と述べる。移動系の二つの安定吸引状態や、ヒステリシスの実証には置き換えない。

## 6. 実測との接続

8件の限定した検索と一次資料・著者リポジトリの確認では、魚群内の位置または凝集度、発声または刺激時刻、両者の同期情報を持ち、この機構識別へ直ちに使える公開データは確認できなかった。これはデータが存在しないという証明ではない。今回、新たな魚のデータをモデルへ適合していない。

- [van Oosterom et al. (2016)](https://doi.org/10.1038/srep19098) は、連続音響記録と60秒ごとの上方画像を取得した近い実験設計である。公開本文から再利用可能な元データ配布先は確定できなかった。
- [Groneberg et al. (2024)](https://doi.org/10.1242/jeb.247782) は [クリックデータと解析コード](https://github.com/danionella/groneberg_et_al_2024) を公開している。HDF5ファイルの公開エントリは確認したが、本監査では内容のスキーマを調べておらず、同期した位置系列は特定できていない。生音声は著者への依頼による提供とされる。
- [Azofeifa-Solano et al. (2026)](https://doi.org/10.1038/s41598-026-38774-3) は野外の音声と映像を同期する例である。データ提供は著者経由とされ、群れ全体を無発声期間も追跡する公開系列は確定できなかった。補足DOCXは取得できず、その埋め込みリンクも未確認である。

残る候補と正確な確認範囲は [実測データ源監査](V14_EMPIRICAL_SOURCE_AUDIT.md) にまとめた。発声と凝集度が同時に変わる事実だけでは、直接の発声促進、個体内の持越し、音を介する空間フィードバックを分離できない、というのが設計上の課題である。

## 8. 次の問いをどう絞るか

今回の条件では、刺激固有の高発声状態が16000まで分離して残るという予想は支持されなかった。次に検証する価値があるのは、低活動からの移行時間と、その初期配置依存である。ただし同じ24シードから有効例だけを再選択すると結論が偏る。新しい独立シード、低活動にあることを観測時点で定義した開始条件、直接発声促進・個体内持越し・空間効果を分ける介入を、結果を見る前に設計する必要がある。

このv14で確定したのは、選んだ既定条件と24シードでは、v13の大きな有限期間差を無刺激側の遅い到達で説明でき、終盤には発声と面積の刺激差が非常に小さくなった、という範囲である。
