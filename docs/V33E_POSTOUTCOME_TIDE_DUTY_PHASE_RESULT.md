# v33-E：潮汐と移動の関連はGPS観測間隔の制約下でも残る（事後診断）

**2026年10月31日 JST、v33-Dの強い負方向の結果を知った後に固定した、探索的な厳格監査。** 今回の監査は新しい独立実験／事前確認的テストではない。固定前に得ていた結果、GPS source、RWS天文潮、地域半径25km、元の高低25%潮位分位、5～180分原ペア、個体×年・月×UTC時間帯のペアリングは変更していない。

## 最初に必ず通したDの原結果再現

元のv33-D JSONは[元の高低潮位結果](V33D_OBSERVED_TIDE_PHASE_MOVEMENT_RESULT.md)として固定。今回、同じRWS 2008–2014年の完全10分刻み天文潮とZenodo 10053970 v4の同じ全7原GPS gzipをもう一度取得し、完全な source gateを再実行。**v33-Dの36個体、5,422対応階層、全36個体の匿名効果・信頼区間、source品質を含む全結果JSONが許容誤差1e−12以内で一致**してから新しい検証を公開した。

**元の主要観測結果をそのまま保持：** 高水位側 − 低水位側の mean log1p(km/h)速度差 = **-0.215357**、個体対応bootstrap95% **[-0.240182, -0.190023]**、**36/36個体で負**（低水位側が速い）。元の5,422階層に含まれたGPS区間数は**高水位114,603、低水位114,697**でほぼ等しい。

**短いGPS観測間隔でも同じ方向：** 5～30分未満では**28/28個体**で負（平均-0.24186）。30～90分未満でも**27/27個体**で負（平均-0.20086）。90～180分のペアについては支持条件が5個体・173階層しかなく、**事前の20個体／200階層ゲートで停止**。都合のよい5個体の効果やp値を出さない。

**高・低潮位で観測時間間隔が同じか：** 最初の36個体・5422階層内で、GPS隣接fixの経過時間の高水位−低水位平均は **+0.245分**、95% bootstrap **[-0.144, 0.610]**。全体では0をまたぐ。短時間ペアのみに限定した比較では高水位側が平均 0.180分長く（95%区間も正）、中時間ペアでは 0.211分長い（95%区間も正）。したがって**観測間隔の交絡を完全には排除できない**。ただし高／低潮位の単純な大きい採録間隔差や長時間ペアだけで元の36/36負方向が作られたわけではなさそうだ。

**人工的な潮位の位相ずらし：** 元GPSは固定し、RWS天文潮の分類時刻だけ+3時間すると対比は -0.06175、31/37個体で負へ弱まる。+6時間すると **0.21841、36/36個体で正へ反転**。6時間は約12.4時間潮汐周期の半周期に近いので、**潮位の高低ラベルが入れ替わる数学的性質**だけでも符号の反転が予期される。これを生物の体内時計による位相同調の独立証明にはしない。+3時間条件の37鳥と原36鳥は同一コホートですらないため、効果量を同じ集団の対応した因果差として比べない。

## 生態学的な現在地：潮汐による数時間尺度の活動ゲート

[古典的研究](https://doi.org/10.1016/0077-7579(81)90002-8)と[Wadden Seaのミヤコドリ研究](https://doi.org/10.1111/ibi.13035)は、低潮位の干潟餌場利用と高潮位の高台休息地利用を記述している。この既知の自然史を踏まえると、当研究地での**低潮位側でGPSの水平移動が増す**という解析結果は、潮位が資源利用機会と移動状態の時間窓を変える **tidal activity gate（潮汐依存活動ゲート）** の予測と整合する。

ただし今の研究が示したのはあくまで**元GPS2fix間の直線移動速度の水位条件付き相関**である。歩行／飛翔、嘴による餌の捕獲、局所干潟露出面積、他個体との社会相互作用は一切区別していない。2010年以外の調査地・年・分類群での独立確認もない（同じ島の7年記録）。

v33-Cの**日ごとの潮差変化は翌日GPS空間的な広がり予測を改善しなかった**点と、v33-D/Eの**水位の高低に対応する数時間尺度のGPS速度差**は異なる尺度の効果であり、矛盾しない。潮汐と空間利用を接続する物理モデルでは、生息地利用可能性の時間ゲートをまず検討し、Reynoldsの社会的力や認知記憶を無理に因果解釈しない。
