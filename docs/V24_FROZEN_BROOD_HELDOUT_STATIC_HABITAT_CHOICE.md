## Preserve the original primary no-history decision

Original 2026 USGS DOI 10.5066/P13NYGAI, ScienceBase item 68631b39d4be025653d31f22, full source hashes pinned in A2. The 7,699,152-byte Duckling_Habitat_Selection_Dataset.csv (SHA256 e4ac32416e2f013efcca8e40b9916e73c72e2e1891a09f78d865524ee16ea036) contains 2,069 used and 74,000 generated available source locations, **185 brood IDs**, exactly **400 available points per brood**, 1–40 used points per brood. Each generated available point lies within 2.4 km of the original nest; **all 74,000 available rows have original Wetland ID = NA**, and original used rows have identified wetland IDs. Neither actual used-record UTC date nor duckling age is available in this table. The companion 2,039-row original movement table has age and nest-distance but no wetland identity. This makes a time-ordered prior wetland-choice history **NOT_ADMITTED** (source A3); do not convert brood-level matched static alternatives into future events.

This separate NEW exploratory study asks: **Do original wetland habitat attributes predict heldout BROODS' observed used versus generated available sampling points better than uniform chance, and do preferences transfer to new study years?** It does NOT test individual memory/learning/social niche mechanisms, and it is related to the original Peterson et al. Ornithological Applications 2026 published habitat-selection findings. Independent predictive held-out broods/years are a new scoring endpoint, not new field observations.

## Frozen choice-sampling grain

- Original source 12 columns exactly: Species, Used, Weight, Brood ID, Wetland ID, Wetland Type, Dominant Veg Category, Percent Veg of Unit, Salinity Concentration, Wetland Area, Year, Water Map Time Period.
- Original Used=1 rows represent radio-tracked duckling locations, not independent broods. Original Used=0 rows are generated random available spatial points within 2.4km of each brood's nest, not demonstrated to be biologically equivalent choices. Every brood has its own identical-size original 400-point availability sample. Multiple used visits from one brood are correlated; treat **brood** as the independent statistical unit, not 76,069 rows.
- Do NOT use Wetland ID as a model feature because it is missing for all available rows. Do NOT use Brood ID, source Weight, response Used, nest/lat coordinates (none available) as a feature. The FGDC original Weight=1 for used and 1000 for available records is an original analysis-specific weight; this forecast **does not interpret it as independent choice probability or biological frequency**.
- Features for environmental habitat model are Wetland Type (categorical), Dominant Veg Category (categorical), Percent Veg of Unit (continuous proportion /100), Salinity Concentration (nonnegative log1p) and Wetland Area (nonnegative log1p). Actual area unit is original table unit; do not invent unit. Missing numeric values imputed with **training-brood median only**, plus fixed missingness indicators; unseen categories in heldout broods encoded as zeros.
- Primary M1 is fixed L2 logistic regression trained with **each original brood total equal weight**, half of each brood's mass on its used observations and half on its 400 generated available observations (observed used rows each weight 0.5/n_used; available points each 0.5/400). One-hot original categorical habitat classes, training-only median imputation and standardization for numeric predictors; logistic L2 C=1.0, liblinear maximum 400 iterations, deterministic random_state=20261029.
- Exploratory M2 adds original Species × all M1 feature interactions, with exactly the same L2 and preprocessing. The species identity is fixed within each brood; species main effect cannot by itself discriminate chosen/available within brood. No hyperparameter tuning based on heldout preferences.

## Source-blind holdouts and proper support

- Entire original Brood ID is assigned to one of 5 folds using sha256(UTF8(Brood ID)) integer modulo 5. No row/fix/available point from a test brood may be used in training, imputation or fitted habitat coefficients. Every original brood must have >0 used points, exactly 400 available points, one original species and year, and original binary Used label. If not, strict source STOP.
- Primary **brood-equal heldout pairwise AUC**: for each original test brood compare all observed used location scores against all 400 *generated available* point scores. M0 uniform/no environmental information = AUC exactly 0.5; gain AUC(M1)−0.5 must be calculated using all 185 source broods (no cherry-picked species or favorable years). An AUC over all 76,069 rows would be invalid pseudo-replication.
- Secondary matched **pseudo-choice log loss** at every original used location, scoring it as the chosen candidate among itself and the source brood's 400 sampled available points: negative log of exp(score_used)/(exp(score_used)+sum_available exp(score_available)). M0 = ln(401). This is a *sampling-design conditional ranking score*, not a literal observed 401-wetland choice. Average used choices within brood, then original broods equal weight. M1 gain = loss(M0)−loss(M1). M2 both AUC/log-loss versus M1 as a fixed exploratory species-context test.
- 10,000 full-brood bootstrap percentile 95% intervals, seed20261029. Independent unit brood, 185 not 76,069. Report positive broods, neutral broods, all 4 original calendar years and two duckling species separately, never claim independent 4 landscapes or taxon replications.
- Predeclared additional **leave-one-source-year-out** tests, four fits each trained in other 3 original years, testing every brood in heldout year with exact same original metric; no year information as predictor, no target-year training. These quantify temporal generalization without visit order.
- If continuous source variable is not finite or imputable or numeric transforms are negative/uninterpretable, STOP before fitting. Do not alter feature list or training weights based on observed output. Training-only imputation is permitted for original missing markers NA, NaN, blank. No response values redistributed.

## Scientific boundary

The selected dataset has no measured individual prior wetland-choice history and no source-recorded date for an original used location. It therefore **cannot** establish that private memory determines future habitat choice, that birds select prey foraging opportunities, that environment causally controls a niche, or that live birds follow social Boids motor forces. A positive M1 would establish only heldout-brood predictability of **sampled original used vs generated available environmental features** in one Suisun Marsh region, contingent on site-specific availability design. The original published paper already reports habitat selection associations; the new question is out-of-brood and out-of-year predictive transport, not rediscovery of causal ecological selection.

If the environment model does not outperform uniform sampling on heldout brood/year, report a negative original source result without retuning v23 or this source.
