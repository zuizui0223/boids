# v26-D original bank vole simultaneous-social step selection source admission

**Registered 2026-10-29 JST before opening any original animal step choice, spatial neighbor encounter or ecological response values.**

Pohle, Signer, Eccard, Dammhahn & Schlägel (2024), *How to account for behavioral states in step-selection analysis: a model comparison*, [PeerJ DOI 10.7717/peerj.16509](https://doi.org/10.7717/peerj.16509). Data and author code original [Zenodo record `10101651`](https://doi.org/10.5281/zenodo.10101651). Original paper's real case study uses **simultaneously tracked bank voles (*Myodes glareolus*)** to evaluate fine-scale individual interactions and behavioral-state habitat selection. Original authors' underlying raw animal trajectories were previously deposited separately (Dryad DOI `10.5061/dryad.rt535m8`), so the Zenodo case-control data are **derived source observations, not newly collected independent tracking**; preserve this provenance.

## D1 original record-only gate

- Query exact Zenodo record 10101651 via official API, require actual record ID, license, original file list, exact file sizes and original MD5 before downloading. Any source-specific RData/RDS, CSV, ZIP and model code names must come from the provider; do not invent links. Limit each original file to 250 MB and total 400 MB.
- This source may contain an actual matched used-versus-available case dataset with original animal ID, time and source-defined fine-scale conspecific contact/relative positions. Do not assert those variables exist until **exact source schema** is independently verified.
- Source format/independent unit must be source-defined individual voles or enclosures, never independent GPS fixes, steps or simulated alternatives. Require ≥8 unique individual IDs with ≥3 earlier source steps and ≥200 legitimate matched used/available source sets for an eventual predictive test. If fewer groups, present as an observational demonstrator with honest uncertainty, not a cross-population law.
- Confirm original used-case label in code/dictionary, no guessing from row order. Check whether available steps were generated with a movement kernel learned from the full original source (potential heldout/test leakage). Any modeled latent state defined with future trajectories is not a legitimate prior-time predictor.
- A future confirmatory social prediction would require time-matched original partner tracks and no heldout animal leakage. A retrospective step-selection case-control comparison is weaker, and does not establish a unique Reynolds steering force or social niche.
