## New original alternative with improved choice-set geometry

Overton & Casazza (2023), *Movements, used habitats, and available habitats identified using Step Selection Processes for four species of waterfowl in California's Central Valley, 2016–2022*, public USGS [DOI 10.5066/P9ELSUHN](https://doi.org/10.5066/P9ELSUHN), pinned ScienceBase catalog source **item ID `652edfe8d34edd15305a9ab0`**. The original publication [DOI 10.3389/fevo.2023.1232704](https://doi.org/10.3389/fevo.2023.1232704) describes four taxa: *Anser albifrons*, *Anser caerulescens caerulescens*, *Anas platyrhynchos*, *Anas acuta*. Hourly GPS tracks and annual California Central Valley landcover/protected-area context, originally 2016–2022. Source public license listed as US public domain/CC0, but exact release metadata controls its files.

Original USGS source description states **100 randomized candidate movements originated at each OBSERVED step's previous/start location**, using a species-specific two-component lognormal movement distance distribution, then retaining observed steps in a *moving* class. This differs from Masto et al's 19 alternatives centered on actual USED endpoint, and is more suitable for prospective destination choice **provided** the data preserve start-time, start-location, original stratum ID and legally available alternative attributes.

**Strict interpretation:** 100 generated steps are *analyst-produced reachable alternatives*, not 100 options actually perceived by the animal. If movement distribution was estimated using all study movement outcomes, even these candidates incorporate information from the full study period. Thus an original step-availability set has global fitting leakage for strong out-of-sample biological forecasting. Separate conditional/ranking validation may remain feasible but **cannot** be promoted to truly prospective ex ante availability without training-only refitting of the movement kernel and independent environmental time fields.
