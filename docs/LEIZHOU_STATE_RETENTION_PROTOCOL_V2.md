# External shorebird state-retention test v2 (PROSPECTIVE; SOURCE OUTCOME UNOPENED)

Date locked: 2026-11-15. This is an external field test *distinct* from Louisiana, ODSP and batter and supersedes no frozen result. The data and the 2025 publication already established species- and day/night-specific roost selection; that is not our novel claim.

## DOI and source

Zhang & Choi (2026), *Shorebird GPS tracking, survey data and habitat map at Leizhou, China*, Dryad DOI **10.5061/dryad.51c59zwm3** (CC0, deposited 2026-06-04; associated 2025 *Biological Conservation* paper 10.1016/j.biocon.2025.111256). The authors report GPS for 16 tracked birds in four focal shorebird taxa and a categorical single-date habitat GeoTIFF (derived from Sentinel-2 acquired 2020-12-08). Source files are not redistributed. A supplementary `SAGU_23` is not part of the four taxa and is excluded independently of its movement outcomes.

**Critical novelty limit:** This dataset permits only a *static-portfolio, movement-matched* comparison. It has no time-varying water-level habitat raster, experimentally verified accessibility or repeated actual resource states. Do NOT call a static map-derived `C=0` true portfolio exhaustion, seasonal habitat collapse, a response to climate change, or an adaptive benefit. Geographic origin-to-destination movement can be reconstructed from time-stamped consecutive GPS fixes, unlike the California aggregated habitat-profile archive; however, undocumented within-gap moves remain unobserved.

## Stage A: response-blind source admissibility (before model scores)

Fetch the exact original Dryad API dataset version and individual data files anonymously via API; save original file IDs, names, lengths, SHA-256 and request URL. FAIL CLOSED if the archive is not ZIP, the ZIP has duplicates or unsafe traversal names, or the expected tracking GPS CSV, `SN to id.txt`, one-band georeferenced GeoTIFF, and class-mapping scheme are absent or ambiguous. No original habitat-use effect is read at this stage; inspect only the columns, non-identifying counts, declared file relationships and raster metadata/nodata/values needed for source format admissibility. The measured source-specific file checksum is then retained in the receipt; do not claim the checksum was known prospectively before first fetch.

Exact source required GPS fields: `S/N`, `Collecting time`, `Longitude`, `Latitude`, `HorAccuracy`. `Transmitting time` is NOT used to order fixes. The public tag-to-individual mapping supplies species from `CORE`, `GRPL`, `GSPL`, `REKN`; unmapped IDs STOP if in focal data. For each individual sort by source GPS acquisition timestamp (UTC), NOT physical CSV row order, and reject conflicting duplicate acquisition times. Raster must have a declared CRS, `count=1`, class codes and `nodata` settings. WGS84 original GPS coordinates are transformed to raster CRS by a documented geospatial transform; categories are stored as original integer codes, never inferred by color or post-hoc ecological preferences.

## Stage B: exact pre-registered analysis if A passes

**Primary animal cohort:** common redshanks `CORE` (9 in deposit), at least 6 independently eligible individuals each with >=20 eligible consecutive-fix steps. All 4 taxa are shown descriptively, but n=2-3 species are not given stand-alone inferential significance. Only acquisition-time pairs within 10–90 minutes, 50–3000 m displacement, horizontal accuracy <=50 m at both endpoints, exact two different timestamps, and a valid mapped raster class at both endpoints are admitted. A fixed sensitivity uses <=100 m horizontal accuracy, with *identical* step-time/distance constraints. If <6 CORE birds pass, report a scientifically informative `PRIMARY_NOT_ADMITTED`; no threshold rescue. Disallow rows with invalid WGS84, unrecognized class, or non-finite speed/accuracy as required by eligibility; source missingness counts are reported.

For each eligible step `i,s`, let `h0` be map habitat at previous actual GPS fix and `h1` at the next GPS fix. `Y=1(h1=h0)`. Calculate `C_{is}` by generating **32 radial counterfactual endpoints** at the identical *observed step distance* from the true origin at 11.25-degree angular increments; the zero-angle bearing is geographic east, not the observed direction. Endpoints with mapped valid habitat enter the denominator; require **>=24/32 valid angles**; missing nodata/out-of-extent points never count as a state loss. Observed GPS endpoints do not enter the counterfactual count. This is a rotation-based, distance-matched **geometric accessibility benchmark**; it does not incorporate a learned turning-angle kernel, barriers, tides or real animal perception. `C_distance` is the fraction of sampled endpoints with the original class `h0`; per-step `R = Y-C_distance`. **This distance-matched null uses actual realised step length, so R is retrospective and cannot be predicted before an animal moves.** Two *additional*, distinctly named origin-only portfolio fractions `C_500` and `C_1500` use fixed radii 500 m and 1500 m with 32 equal-angle samples. They are knowable at the step origin, before the destination is observed. Repeated fixes and pseudo-endpoints are *not* independent replication units.

**Primary inferential target:** equal-bird CORE mean excess category retention `mean_bird(mean_steps R)` and its 95% individual-resampling percentile interval (10,000 bootstrap draws, fixed seed=20261115). Report per-individual sign counts and exact two-sided sign-test p (interpret with small n), all zero/negative birds, and native map class IDs; do not pool alternate taxa to win a p-value. Missing map classes and different acquisition dates are measurement limitations. Report a robustly positive result only if CORE gate passes, 95% bird-bootstrap interval excludes zero, and a majority of birds have R>0. Weaker/null/negative outcomes stay frozen.

**Mechanism-/prediction-oriented secondary:** full-source leave-one-bird-out `M0` versus `M1` for the same binary stay/replacement label Y. M0: local day flag (UTC+8, day=06:00–17:59) and one-hot original origin habitat class; M1: same + the single pre-defined **origin-only `C_500`**. Realised step distance is deliberately EXCLUDED from M0/M1 because it would be known only after the destination; the `C_distance` used in R is never a predictive feature. The `C_1500` origin-only fraction is retained as descriptive/sensitivity evidence only, not model-selected after outcomes. No used endpoint/habitat-derived indicator except Y is a predictor. Fit L2 logistic regression `C=1.0`, `liblinear`, seed=20261115 on training-bird steps weighted to equal total weight per training bird, preprocessing train only. Test means per held-out bird, equal-bird mean loss gain `G = logloss(M0)-logloss(M1)`; 10,000 bird bootstrap interval. Train/test split by whole individual, not frames; if any train fold has only one label or no valid focal birds, status `FORECAST_NOT_ESTIMABLE` instead of rescue. Animal-stationarity and cross-study transfer are *not* proven by this single-site model.

Secondary day/night contrast: local acquisition time `UTC+8` 06:00-17:59 day versus night. Report per-bird day/night average R only when >=10 eligible steps in both periods; no raw row-level significance. Alternative taxa (`GRPL`, `GSPL`, `REKN`) descriptive with exact original class codes and no pooled cross-taxon p. Class-ID translation from source scheme used *only* for prose, no post-hoc regrouping (e.g. all pond classes as one) to increase signal. Additional sensitivity using accuracy<=100m explicitly labeled **sensitivity only**, never the primary.

## Stop rules

- If original download unavailable or header/class/CRS unmatched, output `SOURCE_STOP` receipt and do not calculate synthetic score disguised as field effect.
- If a source ZIP file carries no source-defined GPS acquisition time, tag-to-animal crosswalk or GIS map, STOP. Do not fabricate or silently join by text-row sequence.
- If area extents fail radial 24/32 availability coverage for most steps, report `PRIMARY_NOT_ADMITTED` as written, never lower 24/32 or widen steps after seeing effects.
- `C_distance=0` or `C_500=0` on a radial sample is *not* literal local habitat-state extinction. For true time-dependent portfolio exhaustion, a different independent repeated, dynamic environment dataset is still needed.
- Existing Louisiana, Serengeti, bat and California results are unchanged. No claim of species niche competition, cognitive habit, evolutionary adaptation, or demonstrated benefit to demographic fitness.
